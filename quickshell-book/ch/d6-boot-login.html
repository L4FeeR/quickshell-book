d6Desktop Ricing 6: Boot and Login

The first thing your computer shows isn't your bar, it's the boot menu, a splash screen and a login screen. Theming them finishes the rice from power button to desktop. This chapter is the overview: how GRUB themes are installed, a Plymouth splash, and a first SDDM login theme in QML. The next two chapters go all the way: Desktop Ricing 9: GRUB Ricing and Desktop Ricing 10: SDDM Ricing.

These need root and can stop your system booting

Keep a live USB at hand, change one thing at a time, and reboot to test before moving on. All three can be undone by switching back to the default theme.

GRUB#

GRUB, the boot menu many Arch installs use, can show a graphical theme with a background, icons, a highlight bar and a countdown. Desktop Ricing 9: GRUB Ricing builds a complete one, generates its pictures and fonts with a script, and previews it in a virtual machine so you never reboot to test. (systemd-boot, used by some installs instead, has no themes: bootctl status tells you which you have.)

Plymouth#

Plymouth shows a graphical splash while the disk is unlocked and the system starts.

sudo pacman -S plymouth
# add "plymouth" to HOOKS in /etc/mkinitcpio.conf (after "udev", before "encrypt" if you use it)
# add "quiet splash" to the kernel parameters (GRUB_CMDLINE_LINUX_DEFAULT in /etc/default/grub)
plymouth-set-default-theme -l                 # installed themes
sudo plymouth-set-default-theme -R spinner    # set one and rebuild the initramfs

Themes like catppuccin-plymouth or the many animated ones in plymouth-themes (AUR) install into /usr/share/plymouth/themes/. Test without rebooting: sudo plymouthd; sudo plymouth --show-splash; sleep 5; sudo plymouth quit.

SDDM: a login screen in QML#

SDDM is the login manager most rices use, and its themes are QML files. Here's a first theme in a single file, to see how SDDM and a theme talk: blurred wallpaper, a big clock, the user, a password field that shakes on a wrong password, session switching and power buttons. Desktop Ricing 10: SDDM Ricing then builds a complete, multi-file theme with a user picker, a Caps Lock warning, a session menu, keyboard layouts and a preview that runs without SDDM.

desktop/sddm/tokyo-login/Main.qmlimport QtQuick
import QtQuick.Effects

// An SDDM theme is a QML file that SDDM loads as the login screen. SDDM
// gives it a few objects by name:
//   sddm          login(user, password, session), powerOff(), reboot(), suspend(),
//                 canPowerOff…, and the signals loginFailed / loginSucceeded
//   userModel     the users (name, realName, icon) and lastUser
//   sessionModel  the sessions (Hyprland, Plasma…) and lastIndex
//   config        the values from theme.conf: config.background, config.accent…
Rectangle {
    id: root
    width: 1920
    height: 1080
    color: "#1a1b26"

    readonly property color accent: config.accent || "#7aa2f7"
    readonly property color text: "#c0caf5"
    readonly property color subtext: "#a9b1d6"
    readonly property color surface: "#1a1b26"
    property int sessionIndex: sessionModel.lastIndex
    property string userName: userModel.lastUser || ""

    // ── background: the image, blurred and darkened ──
    Image {
        id: wall
        anchors.fill: parent
        source: config.background
        fillMode: Image.PreserveAspectCrop
        visible: false
    }
    MultiEffect {
        anchors.fill: wall
        source: wall
        blurEnabled: true
        blur: 0.7
        blurMax: 48
        brightness: -0.2
    }

    // ── clock ──
    Column {
        anchors.horizontalCenter: parent.horizontalCenter
        y: parent.height * 0.18
        Text {
            id: time
            anchors.horizontalCenter: parent.horizontalCenter
            color: root.text
            font.family: config.font
            font.pixelSize: 110
            font.bold: true
            text: Qt.formatTime(new Date(), "hh:mm")
        }
        Text {
            id: date
            anchors.horizontalCenter: parent.horizontalCenter
            color: root.subtext
            font.family: config.font
            font.pixelSize: 20
            text: Qt.formatDate(new Date(), "dddd, d MMMM")
        }
    }
    Timer {
        interval: 1000
        running: true
        repeat: true
        onTriggered: { time.text = Qt.formatTime(new Date(), "hh:mm"); date.text = Qt.formatDate(new Date(), "dddd, d MMMM"); }
    }

    // ── login box ──
    Column {
        anchors.centerIn: parent
        anchors.verticalCenterOffset: 80
        spacing: 16

        // user: click to cycle through the users
        Rectangle {
            anchors.horizontalCenter: parent.horizontalCenter
            width: 84
            height: 84
            radius: 42
            color: root.accent
            Text {
                anchors.centerIn: parent
                text: root.userName ? root.userName[0].toUpperCase() : "?"
                color: root.surface
                font.pixelSize: 36
                font.bold: true
            }
        }
        Text {
            anchors.horizontalCenter: parent.horizontalCenter
            text: root.userName
            color: root.text
            font.family: config.font
            font.pixelSize: 18
            MouseArea {
                anchors.fill: parent
                cursorShape: Qt.PointingHandCursor
                property int i: 0
                onClicked: {
                    // userModel is a list model; data() reads a user's name (role 257 = Qt.UserRole + 1)
                    i = (i + 1) % userModel.rowCount();
                    root.userName = userModel.data(userModel.index(i, 0), 257);
                }
            }
        }

        Rectangle {
            id: field
            anchors.horizontalCenter: parent.horizontalCenter
            width: 320
            height: 48
            radius: 24
            color: Qt.alpha(root.surface, 0.85)
            border.width: 2
            border.color: password.activeFocus ? root.accent : "#414868"

            TextInput {
                id: password
                anchors.fill: parent
                anchors.leftMargin: 22
                anchors.rightMargin: 22
                verticalAlignment: TextInput.AlignVCenter
                horizontalAlignment: TextInput.AlignHCenter
                echoMode: TextInput.Password
                passwordCharacter: "●"
                color: root.text
                font.pixelSize: 16
                focus: true
                onAccepted: sddm.login(root.userName, text, root.sessionIndex)
            }
            Text {
                anchors.centerIn: parent
                visible: password.text === ""
                text: "Password"
                color: "#545c7e"
                font.pixelSize: 15
            }
            SequentialAnimation {
                id: shake
                loops: 2
                NumberAnimation { target: field; property: "anchors.horizontalCenterOffset"; to: -10; duration: 50 }
                NumberAnimation { target: field; property: "anchors.horizontalCenterOffset"; to: 10; duration: 100 }
                NumberAnimation { target: field; property: "anchors.horizontalCenterOffset"; to: 0; duration: 50 }
            }
        }

        Text {
            id: message
            anchors.horizontalCenter: parent.horizontalCenter
            color: "#f7768e"
            font.pixelSize: 13
            text: ""
        }
    }

    Connections {
        target: sddm
        function onLoginFailed() {
            message.text = "Wrong password";
            password.text = "";
            shake.restart();
        }
        function onLoginSucceeded() { message.text = ""; }
    }

    // ── bottom: session on the left, power on the right ──
    Text {
        anchors.left: parent.left
        anchors.bottom: parent.bottom
        anchors.margins: 32
        color: root.subtext
        font.family: config.font
        font.pixelSize: 14
        // role 260 of sessionModel is the session's name (SDDM: Qt.UserRole + 4)
        text: "Session: " + sessionModel.data(sessionModel.index(root.sessionIndex, 0), 260) + "  ›"
        MouseArea {
            anchors.fill: parent
            cursorShape: Qt.PointingHandCursor
            onClicked: root.sessionIndex = (root.sessionIndex + 1) % sessionModel.rowCount()
        }
    }

    Row {
        anchors.right: parent.right
        anchors.bottom: parent.bottom
        anchors.margins: 32
        spacing: 12
        Repeater {
            model: [["Suspend", () => sddm.suspend()], ["Restart", () => sddm.reboot()], ["Shut down", () => sddm.powerOff()]]
            Rectangle {
                required property var modelData
                width: label.implicitWidth + 28
                height: 36
                radius: 18
                color: hover.containsMouse ? "#292e42" : Qt.alpha(root.surface, 0.8)
                Text { id: label; anchors.centerIn: parent; text: parent.modelData[0]; color: root.text; font.pixelSize: 13 }
                MouseArea { id: hover; anchors.fill: parent; hoverEnabled: true; cursorShape: Qt.PointingHandCursor; onClicked: parent.modelData[1]() }
            }
        }
    }
}

metadata.desktop names the theme and its main file; QtVersion=6 tells SDDM to use Qt 6. Install and select it:

sudo cp -r tokyo-login /usr/share/sddm/themes/
sudo cp ~/Pictures/wall.jpg /usr/share/sddm/themes/tokyo-login/background.jpg
printf '[Theme]\nCurrent=tokyo-login\n' | sudo tee /etc/sddm.conf.d/theme.conf
sddm-greeter-qt6 --test-mode --theme /usr/share/sddm/themes/tokyo-login   # preview in a window
Testing a theme without SDDM

The theme was tested for this book by loading it from a small QML file that defines stand-in sddm, userModel, sessionModel and config objects, then running it with qml. You can do the same to work on a theme quickly.

greetd instead of SDDM#

greetd is a tiny login daemon; its "greeters" can be anything, including a Quickshell config (Quickshell.Services.Greetd talks to it). A Quickshell greeter can share your shell's components and theme exactly.
