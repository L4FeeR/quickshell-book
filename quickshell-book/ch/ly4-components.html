ly4lyne-dots 4: The Building Blocks

Before the bar, a handful of small components that everything else is made of: themed text, icons, the concave corner that gives lyne its look, the bar's groups and buttons, the logo and a slider. Each one is short, and each one reads its look from Config, so changing a setting or a theme restyles them everywhere.

They live in components/, which is the qs.components module.

Text and icons#

lyne/components/StyledText.qmlimport QtQuick
import qs.config

// Text in the shell's font and colour. Every label in the shell uses it.
Text {
    color: Config.textColor
    font.family: Config.font
    font.pixelSize: Config.fontSizeNormal
    elide: Text.ElideRight
    verticalAlignment: Text.AlignVCenter
}

Every label in the shell is a StyledText: the theme's text colour, the shell's font and size, long text cut with "…", centred vertically. A label that needs something else overrides it (color: Config.subtextColor).

lyne/components/Glyph.qmlimport QtQuick
import qs.config

// An icon: one Nerd Font glyph, sized like the other icons.
//   Glyph { text: Icons.bell }
StyledText {
    font.pixelSize: Config.fontSizeIconSmall
    horizontalAlignment: Text.AlignHCenter
    elide: Text.ElideNone
}

An icon is a StyledText holding one Nerd Font character, a little bigger and centred: Glyph { text: Icons.bell }. Because it is text, it takes the theme colour and fades with it like any label.

The concave corner#

lyne/components/ConcaveCorner.qmlimport QtQuick
import QtQuick.Shapes

// A square filled everywhere except a quarter circle. Under a docked bar it
// makes the bar flow into the screen with a curve instead of a hard edge.
//
//   ██████            By default it fills the top-left corner of its box.
//   ████              `mirrored` flips it left-right (for the right side),
//   ██                `flipped` upside down (for a bar at the bottom).
//   █
Shape {
    id: root

    property real size: 15
    property color color: "black"
    property bool mirrored: false
    property bool flipped: false

    width: size
    height: size
    preferredRendererType: Shape.CurveRenderer        // smooth, antialiased curve

    transform: Scale {
        origin.x: root.width / 2
        origin.y: root.height / 2
        xScale: root.mirrored ? -1 : 1
        yScale: root.flipped ? -1 : 1
    }

    ShapePath {
        fillColor: root.color
        strokeWidth: -1                                // no outline
        startX: 0
        startY: 0
        PathLine { x: root.size; y: 0 }                // along the top edge
        PathArc {                                      // the curve back to the left edge
            x: 0
            y: root.size
            radiusX: root.size
            radiusY: root.size
            direction: PathArc.Counterclockwise
        }
        PathLine { x: 0; y: 0 }                        // up the left edge, closing the shape
    }
}

lines 4–10What it draws
// A square filled everywhere except a quarter circle. Under a docked bar it
// makes the bar flow into the screen with a curve instead of a hard edge.
//
//   ██████            By default it fills the top-left corner of its box.
//   ████              `mirrored` flips it left-right (for the right side),

A small square whose inside corner is cut by a quarter circle. Put one under each end of a full-width bar and the bar seems to melt into the screen. The same piece joins attached panels to the bar (lyne-dots 6: Panels That Grow Out of the Bar).

lines 14–17Inputs
property real size: 15
property color color: "black"
property bool mirrored: false
property bool flipped: false

Its size, its colour, and two flips so one shape covers all four orientations.

lines 19–21Size and rendering
width: size
height: size
preferredRendererType: Shape.CurveRenderer        // smooth, antialiased curve

A Shape would otherwise size itself to its path, so width and height are set explicitly. The curve renderer draws a smooth, antialiased arc (Shapes and Canvas).

lines 23–28Flipping
transform: Scale {
    origin.x: root.width / 2
    origin.y: root.height / 2
    xScale: root.mirrored ? -1 : 1
    yScale: root.flipped ? -1 : 1
}

A Scale of −1 around the centre mirrors the shape. mirrored flips left-right, for the right end of the bar; flipped flips upside down, for a bar at the bottom.

lines 30–44The path
ShapePath {
    fillColor: root.color
    strokeWidth: -1                                // no outline
    startX: 0
    startY: 0
    PathLine { x: root.size; y: 0 }                // along the top edge
    PathArc {                                      // the curve back to the left edge
        x: 0
        y: root.size
        radiusX: root.size
        radiusY: root.size
        direction: PathArc.Counterclockwise
    }
    PathLine { x: 0; y: 0 }                        // up the left edge, closing the shape
}

Start at the top-left, draw a line along the top edge, then an arc back down to the left edge, curving towards the top-left (counter-clockwise), and close up the left edge. The filled area is the top-left corner minus a quarter circle. strokeWidth: -1 means no outline.

Hide it with size, not visible

lyne's comments warn that a Shape created hidden may not draw when shown later. The bar sets size: 0 to hide its corners (in the "docked" style) instead of visible: false.

The bar button#

lyne/components/BarButton.qmlimport QtQuick
import qs.config

// The base of every clickable thing in the bar: a pill that lights up when
// hovered or active, with left, right and middle click and scroll signals.
//   BarButton { onClicked: …; Glyph { text: Icons.bell } }
Rectangle {
    id: root

    default property alias content: row.data            // what you put inside goes in the row
    property alias spacing: row.spacing
    property bool active: false
    readonly property bool hovered: mouse.containsMouse

    signal clicked
    signal rightClicked
    signal middleClicked
    signal scrolled(int delta)                           // +1 up, -1 down

    implicitWidth: row.implicitWidth + Config.padding * 2
    implicitHeight: Config.barButtonHeight
    radius: height / 2
    color: active || hovered ? Config.surface1Color : Qt.alpha(Config.surface1Color, 0)
    Behavior on color {
        enabled: !Config.themeTransitioning                 // the theme fade animates it already
        ColorAnimation { duration: Config.animDuration }
    }

    Row {
        id: row
        anchors.centerIn: parent
        spacing: Config.padding
    }

    MouseArea {
        id: mouse
        anchors.fill: parent
        hoverEnabled: true
        cursorShape: Qt.PointingHandCursor
        acceptedButtons: Qt.LeftButton | Qt.RightButton | Qt.MiddleButton
        onClicked: m => {
            if (m.button === Qt.RightButton)
                root.rightClicked();
            else if (m.button === Qt.MiddleButton)
                root.middleClicked();
            else
                root.clicked();
        }
        onWheel: w => root.scrolled(w.angleDelta.y > 0 ? 1 : -1)
    }
}

The resting colour is the same colour at zero opacity, not "transparent": fading from transparent black to a light surface would pass through grey, while fading the alpha of one colour stays clean. During a theme fade the Behavior is off, because Config is already animating the colour.

The logo#

lyne/components/LyneMark.qmlimport QtQuick
import QtQuick.Shapes
import qs.config

// The rebuild's logo: a line and a dot (lyne-dots' own logo is drawn the
// same way in its LyneLogo.qml). Two numbers drive the animation:
// `lift` raises the dot, `stretch` makes it tall and thin (+) or flat (-).
Item {
    id: root

    property color dotColor: Config.accentColor
    // the line: the same hue as the dot, less saturated and a bit darker
    property color lineColor: Qt.hsla(Math.max(0, dotColor.hslHue), dotColor.hslSaturation * 0.6, dotColor.hslLightness * 0.85, 1)
    property real lift: 0
    property real stretch: 0

    implicitHeight: Config.fontSizeIcon
    implicitWidth: implicitHeight * 1.2

    // drawn in a 120 × 100 box, scaled to fit
    Shape {
        width: 120
        height: 100
        scale: Math.min(root.width / 120, root.height / 100)
        transformOrigin: Item.TopLeft
        x: (root.width - 120 * scale) / 2
        y: (root.height - 100 * scale) / 2
        preferredRendererType: Shape.CurveRenderer

        ShapePath {                                   // the line: an "L" with a soft corner
            fillColor: "transparent"
            strokeColor: root.lineColor
            strokeWidth: 16
            capStyle: ShapePath.RoundCap
            joinStyle: ShapePath.RoundJoin
            startX: 22
            startY: 14
            PathLine { x: 22; y: 58 }
            PathQuad { x: 50; y: 86; controlX: 22; controlY: 86 }
            PathLine { x: 104; y: 86 }
        }
        ShapePath {                                   // the dot: two half-ellipse arcs
            id: dot
            readonly property real r: 15
            readonly property real rx: r * (1 - root.stretch * 0.5)
            readonly property real ry: r * (1 + root.stretch)
            readonly property real cy: 40 - root.lift
            fillColor: root.dotColor
            strokeColor: "transparent"
            startX: 86 - rx
            startY: cy
            PathArc { x: 86 + dot.rx; y: dot.cy; radiusX: dot.rx; radiusY: dot.ry }
            PathArc { x: 86 - dot.rx; y: dot.cy; radiusX: dot.rx; radiusY: dot.ry }
        }
    }
}

import qs.config

// A thick slider with an icon on the filled part, as in the Quick Settings
// panel. Click or drag to set; scroll to nudge. `moved(v)` reports changes.
Item {
    id: root

    property real value: 0                    // 0..1
    property string icon: ""
    signal moved(real v)
    signal iconClicked

    implicitHeight: 34
    implicitWidth: 240

    Rectangle {                               // track
        anchors.fill: parent
        radius: height / 2
        color: Config.surface1Color

        Rectangle {                           // fill (never narrower than a circle)
            width: Math.max(height, parent.width * Math.min(1, root.value))
            height: parent.height
            radius: height / 2
            color: Config.accentColor
            Behavior on width {

A value from 0 to 1 and an icon. The slider never changes value itself: it emits moved(v) and lets its user decide (set the volume, the brightness…). The value then comes back through the binding. This keeps the slider and the real level from disagreeing.
