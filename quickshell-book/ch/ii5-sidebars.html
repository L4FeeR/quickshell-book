ii5end-4 5: The Left and Right Sidebars

ii has two full-height sidebars. The right sidebar is the control centre: uptime and system buttons, quick toggles, volume and brightness sliders, notifications, and a calendar. The left sidebar is a toolbox with tabs; in the original those are an AI chat, a translator and an image browser.

impulse/services/Notifications.qmlpragma Singleton
import Quickshell
import Quickshell.Services.Notifications
import QtQuick

// Notification server. `list` holds every notification; `popupList` the ones still popping up.
// Opening the right sidebar marks everything as read (see SidebarRight).
Singleton {
    id: root

    property var list: []
    readonly property var popupList: list.filter(n => n.popup)
    property bool silent: false
    property int unread: 0

    function discardAll(): void {
        for (const n of list.slice()) n.notification.dismiss();
    }
    function timeoutAll(): void {
        for (const n of list) n.popup = false;
    }

    NotificationServer {
        keepOnReload: true
        actionsSupported: true
        imageSupported: true
        bodyMarkupSupported: true
        persistenceSupported: true
        onNotification: notif => {
            notif.tracked = true;
            root.list = [wrapper.createObject(root, { notification: notif, popup: !root.silent }), ...root.list];
            root.unread++;
        }
    }

    Component {
        id: wrapper
        NotifWrapper {}
    }

    component NotifWrapper: QtObject {
        id: w
        required property Notification notification
        property bool popup: true
        readonly property date time: new Date()
        readonly property Timer timer: Timer {
            running: w.popup && w.notification.urgency !== NotificationUrgency.Critical
            interval: w.notification.expireTimeout > 0 ? w.notification.expireTimeout * 1000 : 7000
            onTriggered: w.popup = false
        }
        readonly property Connections conn: Connections {
            target: w.notification
            function onClosed(): void {
                root.list = root.list.filter(x => x !== w);
                w.destroy();
            }
        }
    }
}

The service is like Caelestia's (Caelestia 7: Notifications, Sidebar, Session, OSD, Utilities): every notification is wrapped with a popup flag, a timestamp and a timer, popupList is derived from list, and silent (Do Not Disturb) skips popups. ii adds an unread counter, shown on the bar until you open the sidebar.

        wrapMode: TextEdit.Wrap
        color: Appearance.colors.colOnLayer1
        background: Rectangle { radius: Appearance.rounding.small; color: Appearance.colors.colLayer1 }
        onTextChanged: debounce.restart()
    }
    Rectangle {
        Layout.fillWidth: true
        Layout.fillHeight: true
        radius: Appearance.rounding.small
        color: Appearance.colors.colLayer1
        StyledText {
            anchors.fill: parent
            anchors.margins: 10
            verticalAlignment: Text.AlignTop
            wrapMode: Text.Wrap
            text: output.text || "Translation appears here"
            color: output.text ? Appearance.colors.colOnLayer1 : Appearance.colors.colSubtext
        }
    }

    Timer { id: debounce; interval: 600; onTriggered: if (input.text.trim()) trans.running = true }

    }
}

Type in the top box; 600 ms after you stop typing, trans -brief :en "text" (translate-shell) runs and its output appears below. The target language is editable. This "debounce then run a command" pattern is the same as the calculator in the widget gallery.

The clipboard tab#

impulse/modules/sidebarLeft/ClipboardHistory.qmlimport Quickshell
import Quickshell.Io
import QtQuick
import QtQuick.Layouts
import qs.modules.common
import qs.modules.common.widgets

// cliphist entries; click one to copy it again.
ListView {
    id: root
    property bool active: false
    property var entries: []

    clip: true
    spacing: 4
    model: entries
    onActiveChanged: if (active) list.running = true

    Process {
        id: list
        command: ["cliphist", "list"]
        stdout: StdioCollector { onStreamFinished: root.entries = text.split("\n").filter(l => l).slice(0, 100) }
    }

    delegate: RippleButton {
        id: entry
        required property string modelData
        width: ListView.view.width
        height: 44
        colBackground: Appearance.colors.colLayer1
        onClicked: Quickshell.execDetached(["sh", "-c", `printf '%s' "$1" | cliphist decode | wl-copy`, "sh", modelData])
        contentItem: StyledText {
            leftPadding: 10
            text: entry.modelData.replace(/^\d+\t/, "")
            elide: Text.ElideRight
            color: Appearance.colors.colOnLayer1
        }
    }
}

cliphist list prints id<TAB>preview lines. Clicking one pipes it back through cliphist decode into wl-copy. The entry is passed as $1 to sh, never pasted into the command string, so clipboard content with quotes or $ can't break or inject anything.

In the original: the AI chat

ii's left sidebar is best known for its AI chat: services/Ai.qml supports several providers (Gemini, OpenAI-compatible APIs, local Ollama models), streams responses with curl, renders Markdown and LaTeX, and lets the model run a few "tools" (like changing a setting). API keys are stored in the system keyring (services/KeyringStorage.qml). To add one to the rebuild: a ListModel of messages, a TextArea, and a Process running curl with a SplitParser that appends streamed tokens to the last message.
