e4Eye Candy 4: The Music Rice

Everything from the last three chapters, assembled into a desktop built around music: a music corner on the desktop with the cover spinning inside a ring visualizer and lyrics scrolling beside it, floating karaoke lyrics over your windows, a bar chip with tiny bars and the current line, and Spotify and the terminal in matching colours.

The music corner#

eyecandy/modules/MusicDesktop.qmlimport QtQuick
import QtQuick.Layouts
import Quickshell
import Quickshell.Wayland
import Quickshell.Widgets
import qs.services
import qs.widgets

// A music corner on the desktop (behind your windows): the album cover inside
// a pulsing ring visualizer, the scrolling lyrics beside it, and the
// now-playing card under the ring. Everything takes its colours from the cover.
PanelWindow {
    id: root

    anchors { bottom: true; left: true }
    margins { bottom: 60; left: 60 }
    implicitWidth: 980
    implicitHeight: 560
    exclusionMode: ExclusionMode.Ignore
    color: "transparent"
    visible: Player.active !== null
    WlrLayershell.layer: WlrLayer.Bottom              // on the desktop, under windows
    WlrLayershell.namespace: "eyecandy_music"
    mask: Region {}                                  // decoration only: clicks go to the desktop

    RowLayout {
        anchors.fill: parent
        spacing: 40

        ColumnLayout {
            Layout.preferredWidth: 420
            Layout.fillWidth: false
            spacing: 16

            // ── the ring, with the cover in the middle ──
            Item {
                Layout.alignment: Qt.AlignHCenter
                implicitWidth: 380
                implicitHeight: 380

                VisualizerRing {
                    anchors.fill: parent
                    radius: 120
                    barWidth: 5
                    colorFrom: ArtColors.accent
                    colorTo: Qt.lighter(ArtColors.accent, 1.5)
                }
                // ClippingRectangle clips its content to the rounded shape
                // (plain `clip` would only clip to the square bounding box)
                ClippingRectangle {
                    anchors.centerIn: parent
                    width: 220
                    height: 220
                    radius: 110
                    color: ArtColors.background
                    Image {
                        id: cover
                        anchors.fill: parent
                        source: Player.artUrl
                        fillMode: Image.PreserveAspectCrop
                        asynchronous: true
                        // the cover slowly spins while playing, like a record
                        RotationAnimation on rotation {
                            running: Player.playing
                            from: cover.rotation
                            to: cover.rotation + 360
                            duration: 30000
                            loops: Animation.Infinite
                        }
                    }
                }
            }
            NowPlayingCard { Layout.fillWidth: true }
        }

        // ── lyrics ──
        LyricsView {
            Layout.fillWidth: true
            Layout.fillHeight: true
            accent: ArtColors.accent
            fontSize: 24
        }
    }
}

Floating lyrics#

eyecandy/modules/LyricsOverlay.qmlimport QtQuick
import QtQuick.Effects
import Quickshell
import Quickshell.Io
import Quickshell.Wayland
import qs.services
import qs.widgets

// Floating lyrics over everything, like a karaoke subtitle: the current line
// big and filling with colour, the next line small under it. It never takes
// clicks, so it can sit over your windows. Toggle: qs ipc call overlay toggle
PanelWindow {
    id: root

    anchors.bottom: true
    margins.bottom: 90
    implicitWidth: 1100
    implicitHeight: 110
    exclusionMode: ExclusionMode.Ignore
    color: "transparent"
    property bool enabled: true
    visible: enabled && Lyrics.lines.length > 0 && Player.playing
    IpcHandler { target: "overlay"; function toggle(): void { root.enabled = !root.enabled; } }
    WlrLayershell.layer: WlrLayer.Overlay
    WlrLayershell.namespace: "eyecandy_lyrics"
    mask: Region {}

    Column {
        anchors.centerIn: parent
        spacing: 6

        Item {
            id: line
            anchors.horizontalCenter: parent.horizontalCenter
            width: base.implicitWidth
            height: base.implicitHeight

            Text {
                id: base
                text: Lyrics.currentText
                color: "white"
                font.family: "Inter"
                font.pixelSize: 34
                font.bold: true
            }
            // the sung part in the accent, clipped by progress
            Item {
                width: base.width * Lyrics.lineProgress
                height: base.height
                clip: true
                Text { text: base.text; color: ArtColors.accent; font: base.font }
            }
            // a dark glow makes it readable on any background
            layer.enabled: true
            layer.effect: MultiEffect {
                shadowEnabled: true
                shadowColor: "black"
                shadowBlur: 0.8
                shadowOpacity: 0.9
            }
        }
        Text {
            anchors.horizontalCenter: parent.horizontalCenter
            text: Lyrics.nextText
            color: Qt.alpha("white", 0.65)
            font.family: "Inter"
            font.pixelSize: 18
            style: Text.Outline
            styleColor: Qt.alpha("black", 0.6)
        }
    }
}

A chip for your bar#

eyecandy/modules/MusicChip.qmlimport QtQuick
import QtQuick.Layouts
import qs.services
import qs.widgets

// For your bar: tiny live bars and the current lyric (or the song title when
// there are no lyrics). Click to play/pause, scroll to skip.
//   in any bar's RowLayout:  MusicChip {}
Rectangle {
    id: root

    visible: Player.active !== null
    implicitWidth: row.implicitWidth + 20
    implicitHeight: 28
    radius: height / 2
    color: Qt.alpha(ArtColors.accent, 0.18)
    Behavior on implicitWidth { NumberAnimation { duration: 250; easing.type: Easing.OutCubic } }

    RowLayout {
        id: row
        anchors.centerIn: parent
        spacing: 8
        VisualizerBars {
            implicitWidth: 34
            implicitHeight: 16
            Layout.preferredWidth: 34
            Layout.preferredHeight: 16
            mirrored: true
            spacing: 2
            colorFrom: ArtColors.accent
            colorTo: Qt.lighter(ArtColors.accent, 1.4)
        }
        LyricsLine {
            Layout.preferredWidth: Math.min(360, implicitWidth)
            visible: Lyrics.currentText !== ""
        }
        Text {
            visible: Lyrics.currentText === ""
            text: Player.title + (Player.artist ? "  ·  " + Player.artist : "")
            color: "white"
            font.pixelSize: 13
            elide: Text.ElideRight
            Layout.maximumWidth: 300
        }
    }
    TapHandler { onTapped: Player.active.togglePlaying() }
    WheelHandler { onWheel: e => e.angleDelta.y > 0 ? Player.active.previous() : Player.active.next() }
}

A pill tinted with the cover's accent: tiny mirrored bars, then the current lyric, or the title and artist when the song has no synced lyrics. Its width animates as the lyric changes. Click to play or pause, scroll to skip. Drop it into any bar's RowLayout: the gallery shell (Gallery: Build a Whole Shell from the Gallery) or the lyne rebuild (lyne-dots 5: The Bar) for example.

The demo shell#

eyecandy/shell.qml//@ pragma UseQApplication
import QtQuick
import Quickshell
import qs.services
import qs.modules

// The eye-candy demo: a music desktop, floating lyrics, a weather card and a
// small top bar with the music chip. Each module also works on its own:
// copy the module, the widgets it uses and the services into your shell.
ShellRoot {
    MusicDesktop {}
    LyricsOverlay {}
    WeatherCard {}

    // a minimal bar, just to show the chip in context
    PanelWindow {
        anchors { top: true; left: true; right: true }
        implicitHeight: 40
        color: "transparent"
        Rectangle {
            anchors.fill: parent
            anchors.margins: 6
            radius: 14
            color: Qt.alpha("#1a1b26", 0.9)
            MusicChip { anchors.centerIn: parent }
        }
    }

    // video wallpaper: uncomment and point it at a video
    // AnimatedWallpaper { source: Quickshell.env("HOME") + "/Videos/wallpaper.mp4" }
}

All of it running together, with a minimal bar to show the chip. Run it with qs -p examples/eyecandy while some music plays.

Matching the rest of the desktop#

A music rice looks best when Spotify and the terminal join in:

  • Spotify: a spicetify theme in your palette (Desktop Ricing 7: Browser, Spotify and Discord). For colours that follow each album, spicetify's "Dynamic" themes (like DribbblishDynamic) tint Spotify from the cover, just as ArtColors does for the shell.
  • The terminal: cava with the same gradient (Desktop Ricing 2: Shell, Prompt, Fetch and Terminal Apps) in a small floating kitty window makes a classic screenshot. A Hyprland rule floats it: class = "cava" with kitty --class cava cava.
  • The dynamic island from Gallery: Dynamic Islands, Popups and OSDs can show the track and a progress ring at the top of the screen.
  • Hyprland: blur behind the overlay and the music corner (layerrule = blur, eyecandy_.*) gives them a glassy look.

Exercise 2PracticeShow only while playing
