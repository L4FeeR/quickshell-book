d10Desktop Ricing 10: SDDM Ricing

SDDM is the login screen most Linux rices use, and its themes are QML, the same language as your Quickshell shell. Everything you've learned applies: components, bindings, models, animations. This chapter builds a complete theme in several files: a blurred background, a big clock, a row of users with avatars, a password box with a Caps Lock warning and a show-password button, a session menu, the keyboard layout, power buttons, and settings in theme.conf. It also ships a preview that runs the theme without SDDM.

The theme as preview.sh shows it, with stand-in users.

What SDDM gives a theme#

SDDM loads the theme's main QML file once per monitor and makes five objects available by name:

Object What it has
sddm login(user, password, sessionIndex), powerOff(), reboot(), suspend(), hibernate(); canPowerOff, canReboot, canSuspend…; signals loginFailed() and loginSucceeded()
userModel a list model of users with roles name (login name), realName, icon (avatar path), needsPassword; plus lastIndex and lastUser
sessionModel a list model of sessions with roles name, comment, file; plus lastIndex
keyboard capsLock, numLock, layouts (each with shortName and longName) and currentLayout (settable)
config every key=value from the [General] section of theme.conf, as text

There's no Quickshell here: SDDM runs the theme in plain Qt Quick, so only QtQuick (and modules like QtQuick.Effects) are available. The theme also runs before anyone is logged in, as the sddm user, so it can't read files in your home folder; everything it needs (the wallpaper too) lives in the theme folder.

MainScript=Main.qml

MainScript and ConfigFile name the two files SDDM loads, and QtVersion=6 makes SDDM use its Qt 6 greeter (Qt 5 is the default on some versions). Screenshot is shown by theme pickers like KDE's settings.

desktop/sddm/tokyo-night/theme.conf[General]
# A picture next to Main.qml, or an absolute path
background=background.jpg
# 0 = sharp, 1 = fully blurred
blur=0.6
# darken the picture so text stays readable (0..1)
dim=0.15
accent=#7aa2f7
font=Inter
clockFormat=hh:mm
dateFormat=dddd, d MMMM
# show the row of users (false: only the last one who logged in)
showUsers=true

The settings a user can change without touching QML. SDDM also reads theme.conf.user next to it, if it exists, and its values win: that's how settings tools save changes without editing your file.

Theme: colours and settings#

desktop/sddm/tokyo-night/components/Theme.qmlimport QtQuick

// The theme's colours and the settings from theme.conf, in one object the
// other components receive. SDDM hands config values over as text, so the
// numbers and booleans are converted here.
QtObject {
    property var conf                                   // SDDM's `config`

    readonly property color accent: conf.accent || "#7aa2f7"
    readonly property color base: "#1a1b26"
    readonly property color surface: "#24283b"
    readonly property color raised: "#292e42"
    readonly property color border: "#414868"
    readonly property color text: "#c0caf5"
    readonly property color subtext: "#a9b1d6"
    readonly property color muted: "#545c7e"
    readonly property color error: "#f7768e"
    readonly property color warning: "#e0af68"

    readonly property string font: conf.font || "Inter"
    readonly property real blur: Number(conf.blur ?? 0.6)
    readonly property real dim: Number(conf.dim ?? 0.15)
    readonly property string clockFormat: conf.clockFormat || "hh:mm"
    readonly property string dateFormat: conf.dateFormat || "dddd, d MMMM"
    readonly property bool showUsers: String(conf.showUsers ?? "true") === "true"
}

config values are always text. Number(...) turns "0.6" into 0.6; String(...) === "true" turns "true" into a real boolean (otherwise the text "false" would count as true). Each has a default, in case the line is missing.

The screen#

desktop/sddm/tokyo-night/Main.qmlimport QtQuick
import QtQuick.Effects
import "components"

// SDDM loads this file as the login screen, once per monitor, and gives it:
//   sddm          login(), powerOff(), reboot(), suspend(), canPowerOff…, loginFailed/loginSucceeded
//   userModel     the users: roles name, realName, icon; lastIndex, lastUser
//   sessionModel  the sessions: roles name, comment; lastIndex
//   keyboard      capsLock, numLock, layouts (shortName, longName), currentLayout
//   config        the [General] values of theme.conf
Rectangle {
    id: root
    width: 1920
    height: 1080
    color: theme.base

    Theme { id: theme; conf: config }

    // ── background: picture, blurred and dimmed ──
    Image {
        id: wall
        anchors.fill: parent
        source: config.background
        fillMode: Image.PreserveAspectCrop
        asynchronous: true
        visible: false
    }
    MultiEffect {
        anchors.fill: parent
        source: wall
        blurEnabled: theme.blur > 0
        blur: theme.blur
        blurMax: 64
        brightness: -theme.dim
    }

    // ── clock ──
    Clock {
        theme: theme
        anchors.horizontalCenter: parent.horizontalCenter
        y: parent.height * 0.12
    }

    // ── who and password ──
    Column {
        anchors.horizontalCenter: parent.horizontalCenter
        y: parent.height * 0.42
        spacing: 22

        UserList {
            id: users
            theme: theme
            model: userModel
            visible: theme.showUsers
            anchors.horizontalCenter: parent.horizontalCenter
        }
        Text {                                       // with the user row off: just the last user
            visible: !theme.showUsers
            anchors.horizontalCenter: parent.horizontalCenter
            text: userModel.lastUser
            color: theme.text
            font.family: theme.font
            font.pixelSize: 22
        }

        PasswordBox {
            id: password
            theme: theme
            anchors.horizontalCenter: parent.horizontalCenter
            capsLock: keyboard.capsLock
            onSubmitted: pw => sddm.login(theme.showUsers ? users.selectedName : userModel.lastUser, pw, session.currentIndex)
        }
    }

    // SDDM answers a login attempt with one of these
    Connections {
        target: sddm
        function onLoginFailed() { password.fail("Wrong password, try again"); }
        function onLoginSucceeded() { password.busy = false; }
    }

    // ── bottom left: session and keyboard layout ──
    Row {
        anchors.left: parent.left
        anchors.bottom: parent.bottom
        anchors.margins: 32
        spacing: 10

        SessionPicker { id: session; theme: theme; sessions: sessionModel }

        Rectangle {                                  // keyboard layout: click for the next one
            visible: keyboard.layouts.length > 1
            width: layoutText.implicitWidth + 28
            height: 36
            radius: 18
            color: Qt.alpha(theme.base, 0.8)
            Text {
                id: layoutText
                anchors.centerIn: parent
                text: keyboard.layouts[keyboard.currentLayout]?.shortName.toUpperCase() ?? ""
                color: theme.text
                font.family: theme.font
                font.pixelSize: 13
            }
            MouseArea {
                anchors.fill: parent
                cursorShape: Qt.PointingHandCursor
                onClicked: keyboard.currentLayout = (keyboard.currentLayout + 1) % keyboard.layouts.length
            }
        }
    }

    // ── bottom right: power ──
    PowerBar {
        theme: theme
        power: sddm
        anchors.right: parent.right
        anchors.bottom: parent.bottom
        anchors.margins: 32
    }

    Component.onCompleted: password.focusField()
}

The users#

desktop/sddm/tokyo-night/components/UserList.qmlimport QtQuick

// A row of users with their avatars; the selected one is bigger and has an
// accent ring. Arrow keys or clicks change it. `selectedName` is the login
// name of the selected user.
ListView {
    id: root
    required property var theme
    property string selectedName: ""

    orientation: ListView.Horizontal
    implicitHeight: 150
    implicitWidth: Math.min(count, 5) * 120
    spacing: 12
    clip: true
    interactive: false
    highlightMoveDuration: 200
    currentIndex: model.lastIndex >= 0 ? model.lastIndex : 0
    // keep the selected user in the middle
    highlightRangeMode: ListView.StrictlyEnforceRange
    preferredHighlightBegin: width / 2 - 54
    preferredHighlightEnd: width / 2 + 54

    delegate: Item {
        id: user
        required property int index
        required property string name          // login name
        required property string realName      // full name, may be empty
        required property string icon          // avatar file, may be empty
        readonly property bool current: ListView.isCurrentItem

        width: 108
        height: root.height

        // publish the selected user's name to the list
        Binding { target: root; property: "selectedName"; value: user.name; when: user.current }

        Rectangle {                                    // accent ring + avatar
            id: ring
            anchors.horizontalCenter: parent.horizontalCenter
            y: user.current ? 4 : 16
            width: user.current ? 96 : 72
            height: width
            radius: width / 2
            color: user.current ? root.theme.accent : root.theme.border
            Behavior on width { NumberAnimation { duration: 200; easing.type: Easing.OutCubic } }
            Behavior on y { NumberAnimation { duration: 200 } }

            Rectangle {
                anchors.centerIn: parent
                width: parent.width - 8
                height: width
                radius: width / 2
                color: root.theme.surface
                clip: true
                Text {                                 // initial, under the picture
                    anchors.centerIn: parent
                    text: (user.realName || user.name).charAt(0).toUpperCase()
                    color: root.theme.text
                    font.family: root.theme.font
                    font.pixelSize: parent.width * 0.42
                    font.weight: Font.Bold
                }
                Image {
                    anchors.fill: parent
                    source: user.icon ? "file://" + user.icon : ""
                    fillMode: Image.PreserveAspectCrop
                    asynchronous: true
                    visible: status === Image.Ready
                }
            }
        }
        Text {
            anchors.horizontalCenter: parent.horizontalCenter
            anchors.top: ring.bottom
            anchors.topMargin: 10
            width: parent.width
            horizontalAlignment: Text.AlignHCenter
            elide: Text.ElideRight
            text: user.realName || user.name
            color: user.current ? root.theme.text : root.theme.muted
            font.family: root.theme.font
            font.pixelSize: 15
            font.weight: user.current ? Font.DemiBold : Font.Normal
        }
        MouseArea { anchors.fill: parent; cursorShape: Qt.PointingHandCursor; onClicked: root.currentIndex = user.index }
    }
}

desktop/sddm/tokyo-night/preview.sh#!/usr/bin/env bash
# Run the theme without SDDM, with stand-in users and sessions.
#   ./preview.sh            opens it in a window (enter "secret" to "log in")
#   ./preview.sh shot.png   saves a 1920x1080 screenshot instead (the window
#                           opens for a moment: the blur needs a real GPU
#                           surface, and an offscreen run would leave it out)
set -euo pipefail
cd "$(dirname "$0")"
qml=$(command -v qml6 || command -v qml || echo /usr/lib/qt6/bin/qml)
if [ $# -ge 1 ]; then
    "$qml" preview/Preview.qml -- "$(realpath -m "$1")"
else
    "$qml" preview/Preview.qml
fi
./preview.sh                 # a window: type "secret", or anything else to see the failure
./preview.sh shot.png        # a screenshot

The screenshot mode opens a window for a moment on purpose: the blur needs a real GPU surface, and an offscreen run leaves it out (the background comes out flat). SDDM's own test mode works too, once SDDM is installed:

sddm-greeter-qt6 --test-mode --theme /path/to/tokyo-night

Installing#

sudo cp -r tokyo-night /usr/share/sddm/themes/
sudo mkdir -p /etc/sddm.conf.d
printf '[Theme]\nCurrent=tokyo-night\n' | sudo tee /etc/sddm.conf.d/theme.conf

Then log out (or sudo systemctl restart sddm, which ends your session). If the theme has an error, SDDM falls back to a plain built-in screen, so you can still log in; journalctl -b -u sddm shows the QML error. To use your own wallpaper, copy it into the theme folder (SDDM can't read your home folder) and set background= in theme.conf.
