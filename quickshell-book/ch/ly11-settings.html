ly11lyne-dots 11: The Settings App

lyne-dots' big promise is "no config files to edit": almost everything is set from its own Settings window, applied live. Thanks to lyne-dots 2: One File for Every Setting, that's simpler than it sounds. Every setting is a key in state.json, and every row in the Settings app is a control bound to one key. This chapter builds the row types and the window.

Why it's easy#

A Settings row needs to do three things: show the current value, change it, and update when it changes elsewhere. With StateService:

value: StateService.get("bar.height", 33)       // show, and stay in sync
onMoved: v => StateService.set("bar.height", v) // change: saved, and the bar follows

So each row type only needs to know its key path. The rest of the shell already reads the same keys through Config, so a change in Settings appears everywhere the moment you make it.

The row frame#

lyne/modules/settings/SettingRow.qmlimport QtQuick
import QtQuick.Layouts
import qs.config
import qs.services

// The frame shared by every setting: a title, an optional description,
// the control on the right, and a "reset" button that appears once the
// value differs from defaults.json. `path` is the state.json key.
Rectangle {
    id: root

    property string path
    property string title
    property string description: ""
    default property alias control: slot.data
    readonly property var value: StateService.get(path, null)

    Layout.fillWidth: true
    implicitHeight: Math.max(56, labels.implicitHeight + Config.spacing * 2)
    radius: Config.radius
    color: Config.cardColor

    RowLayout {
        anchors.fill: parent
        anchors.leftMargin: Config.spacing * 2
        anchors.rightMargin: Config.spacing
        spacing: Config.spacing
        ColumnLayout {
            id: labels
            Layout.fillWidth: true
            spacing: 1
            StyledText { Layout.fillWidth: true; text: root.title; font.pixelSize: Config.fontSizeNormal }
            StyledText { Layout.fillWidth: true; visible: text !== ""; text: root.description; font.pixelSize: Config.fontSizeSmall; color: Config.mutedColor; wrapMode: Text.Wrap }

lyne/modules/settings/SliderRow.qmlimport QtQuick
import qs.config
import qs.services
import qs.components

// A number in a range:
//   SliderRow { path: "geometry.radius"; from: 0; to: 24; step: 1; unit: " px" }
SettingRow {
    id: root
    property real from: 0
    property real to: 100
    property real step: 1
    property string unit: ""
    property real factor: 1                        // shown value = stored value × factor (e.g. 100 for %)

    Row {
        spacing: Config.spacing
        StyledText {
            width: 56
            anchors.verticalCenter: parent.verticalCenter
            horizontalAlignment: Text.AlignRight
            text: Math.round(root.value * root.factor * 100) / 100 + root.unit
            font.pixelSize: Config.fontSizeSmall
            color: Config.subtextColor
        }
        Item {
            width: 180
            height: 26
            Rectangle {
                anchors.verticalCenter: parent.verticalCenter
                width: parent.width
                height: 6
                radius: 3
                color: Config.surface2Color
                Rectangle {
                    width: parent.width * (root.value - root.from) / (root.to - root.from)
                    height: parent.height
                    radius: 3
                    color: Config.accentColor
                }
            }
            Rectangle {                              // the handle
                x: (parent.width - width) * (root.value - root.from) / (root.to - root.from)
                anchors.verticalCenter: parent.verticalCenter
                width: 18
                height: 18
                radius: 9
                color: Config.textColor
            }
            MouseArea {
                anchors.fill: parent
                cursorShape: Qt.PointingHandCursor
                function setFrom(x) {
                    const raw = root.from + Math.max(0, Math.min(1, x / width)) * (root.to - root.from);
                    StateService.set(root.path, Number((Math.round(raw / root.step) * root.step).toFixed(4)));   // toFixed: no 0.30000000000000004
                }
                onPressed: m => setFrom(m.x)
                onPositionChanged: m => { if (pressed) setFrom(m.x); }
            }
        }
    }
}

Adding a setting, start to finish#

Every new setting follows the same four steps. Here's "bar height when floating":

  1. Default: add it to defaults.json → "bar": { …, "floatingHeight": 30 }.
  2. Token: read it in Config → readonly property int barFloatingHeight: getState("bar.floatingHeight", 30).
  3. Use: use the token where it matters → height: Config.barFloating ? Config.barFloatingHeight : Config.barHeight.
  4. Row: add a row → SliderRow { path: "bar.floatingHeight"; title: "Floating height"; from: 24; to: 48; step: 1; unit: " px" }.

That's how lyne grew to 27 pages without becoming hard to maintain.

In the original

lyne's modules/settings/ has 27 pages, a search over every row (each row registers its title and keywords), live previews of bar, launcher, OSD and lock templates, a monitor arrangement map with a "keep these settings?" countdown, a keybind editor that records keys, and a theme creator with an OKLCH colour picker. Hyprland settings are written to ~/.config/hypr/local/settings.lua, which the Lua config loads.
