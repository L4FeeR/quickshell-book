ly9lyne-dots 9: Lock Screen, Power Menu and Idle

Three pieces that deal with the session: a lock screen that checks your real password and can't be bypassed, lyne's power menu with a key for every action and a countdown before restarting, and idle handling that locks the screen and turns the displays off when you walk away.

The lock state#

lyne/services/LockService.qmlpragma Singleton
import QtQuick
import Quickshell
import qs.services
import Quickshell.Io
import Quickshell.Services.Pam

// Whether the session is locked, what has been typed, and checking it.
// Every monitor's lock surface edits the same `buffer`, so typing works
// whichever monitor has the keyboard.
Singleton {
    id: root

    property bool locked: false
    // the lock windows exist a little longer than `locked`, so the
    // compositor is told "unlocked" before the windows are destroyed
    property bool surfaceActive: false
    property string buffer: ""
    property bool checking: false
    property bool failed: false

    function lock() { buffer = ""; failed = false; surfaceActive = true; locked = true; }

    function submit() {
        if (checking || buffer === "")
            return;
        checking = true;
        failed = false;
        pam.start();
    }

    PamContext {
        id: pam
        // PAM asks for the password: answer with what was typed
        onPamMessage: if (responseRequired) respond(root.buffer)
        onCompleted: result => {
            root.checking = false;
            root.buffer = "";
            if (result === PamResult.Success) {
                root.locked = false;
                release.restart();
            }
            else
                root.failed = true;
        }
    }

    Timer { id: release; interval: 500; onTriggered: root.surfaceActive = false }

    IpcHandler {
        target: "lock"
        function lock(): void { root.lock(); }
    }
}
Code walkthrough · piece by piece
lines 8–10One buffer for every screen
// Whether the session is locked, what has been typed, and checking it.
// Every monitor's lock surface edits the same `buffer`, so typing works
// whichever monitor has the keyboard.

Each monitor gets a lock surface, and you might type on any of them. So what you type is kept here, in one place, and every surface edits and shows the same buffer.

lines 14–20State
property bool locked: false

// compositor is told "unlocked" before the windows are destroyed
property bool surfaceActive: false
property string buffer: ""
property bool checking: false
property bool failed: false

Locked or not; whether the lock windows exist (below); the typed text; whether PAM is checking; whether the last try failed.

lines 15–17Why surfaceActive?
// the lock windows exist a little longer than `locked`, so the
// compositor is told "unlocked" before the windows are destroyed
property bool surfaceActive: false

If the lock windows were destroyed at the same moment the compositor is told to unlock, the two could race and leave the screen locked. So locked turns false first (the compositor unlocks), and the windows go half a second later.

line 22Locking
function lock() { buffer = ""; failed = false; surfaceActive = true; locked = true; }

Clear any old input and errors, create the lock windows and lock.

lines 24–30Submitting
function submit() {
    if (checking || buffer === "")
        return;
    checking = true;
    failed = false;
    pam.start();
}

Ignore Enter while already checking or with nothing typed, then start a PAM conversation.

lines 32–46PAM
PamContext {
    id: pam

    onCompleted: result => {

PamContext runs the same authentication as your login screen (the login PAM service by default), so your normal password works, and so do fingerprint readers if PAM is set up for them. When PAM asks a question that needs an answer, the typed text is the answer. On success, unlock; otherwise mark the failure. The text is cleared either way.

line 48Removing the windows
Timer { id: release; interval: 500; onTriggered: root.surfaceActive = false }

Half a second after a successful unlock, surfaceActive turns false and shell.qml destroys the lock windows.

The lock screen#

lyne/modules/lock/LockScreen.qmlimport QtQuick
import QtQuick.Layouts
import QtQuick.Effects
import Quickshell
import Quickshell.Wayland
import Quickshell.Hyprland
import Quickshell.Services.Mpris
import Quickshell.Services.UPower
import qs.config
import qs.services
import qs.components

// The lock screen (lyne's "center" template). Every monitor gets the blurred
// wallpaper; the monitor that was focused when locking also gets the clock,
// the password field, the player and the power buttons.
//
// Security comes from ext-session-lock: while locked, the compositor shows
// only these surfaces and sends them all input. If the shell crashed, the
// screen would stay locked.
WlSessionLock {
    id: root

    locked: LockService.locked
    readonly property string mainScreen: Hyprland.focusedMonitor?.name ?? ""
    readonly property MprisPlayer player: Mpris.players.values.find(p => p.isPlaying) ?? null

    WlSessionLockSurface {
        id: surface
        readonly property bool isMain: screen?.name === root.mainScreen || Quickshell.screens.length === 1
        color: Config.backgroundColor

        // ── the blurred wallpaper ──
        Image {
            id: wall
            anchors.fill: parent
            source: WallpaperService.current ? "file://" + WallpaperService.current : ""
            fillMode: Image.PreserveAspectCrop
            sourceSize: Qt.size(surface.width / 2, surface.height / 2)     // blur hides the detail anyway
            visible: false
        }
        MultiEffect {
            anchors.fill: wall
            source: wall
            blurEnabled: true
            blur: 1
            blurMax: 64
            brightness: -0.15
        }

        SystemClock { id: clock; precision: SystemClock.Seconds }

        // every surface has an input: whichever has the keyboard edits the shared buffer
        TextInput {
            id: hidden
            opacity: 0                       // not visible: false (invisible items get no keyboard)
            focus: true
            text: LockService.buffer
            onTextEdited: { LockService.buffer = text; LockService.failed = false; }
            Keys.onReturnPressed: LockService.submit()
            Keys.onEnterPressed: LockService.submit()
            Keys.onEscapePressed: LockService.buffer = ""
        }

        // ── centre: clock, user, password ──
        ColumnLayout {
            anchors.centerIn: parent
            spacing: Config.spacing * 2

            StyledText {
                Layout.alignment: Qt.AlignHCenter
                text: Qt.formatDateTime(clock.date, "hh:mm")
                font.pixelSize: 110
                font.bold: true
            }
            StyledText {
                Layout.alignment: Qt.AlignHCenter
                text: Qt.formatDateTime(clock.date, "dddd, d MMMM")
                font.pixelSize: Config.fontSizeLarge + 2
                color: Config.subtextColor
            }

            ColumnLayout {
                visible: surface.isMain
                Layout.alignment: Qt.AlignHCenter
                Layout.topMargin: Config.spacing * 4
                spacing: Config.spacing * 2

                Rectangle {                               // avatar: ~/.face, or the first letter
                    Layout.alignment: Qt.AlignHCenter
                    implicitWidth: 72
                    implicitHeight: 72
                    radius: 36
                    color: Config.accentColor
                    clip: true
                    StyledText { anchors.centerIn: parent; text: (Quickshell.env("USER") || "?")[0].toUpperCase(); font.pixelSize: 32; font.bold: true; color: Config.textReverseColor }
                    Image { anchors.fill: parent; source: "file://" + Quickshell.env("HOME") + "/.face"; fillMode: Image.PreserveAspectCrop; asynchronous: true }
                }

                Rectangle {                               // the field: one dot per character
                    id: field
                    Layout.alignment: Qt.AlignHCenter
                    implicitWidth: 300
                    implicitHeight: 46
                    radius: height / 2
                    color: Config.backgroundTransparentColor
                    border.width: 2
                    border.color: LockService.failed ? Config.errorColor : LockService.checking ? Config.warningColor : Config.surface2Color

                    transform: Translate { id: shake }
                    SequentialAnimation {
                        id: shakeAnim
                        loops: 2
                        NumberAnimation { target: shake; property: "x"; to: -10; duration: 50 }
                        NumberAnimation { target: shake; property: "x"; to: 10; duration: 100 }
                        NumberAnimation { target: shake; property: "x"; to: 0; duration: 50 }
                    }
                    Connections {
                        target: LockService
                        function onFailedChanged() { if (LockService.failed) shakeAnim.restart(); }
                    }

                    Row {
                        anchors.centerIn: parent
                        spacing: 6
                        Repeater {
                            model: LockService.buffer.length
                            Rectangle { width: 10; height: 10; radius: 5; color: Config.textColor }
                        }
                    }
                    StyledText {
                        anchors.centerIn: parent
                        visible: LockService.buffer.length === 0
                        text: LockService.checking ? "Checking…" : LockService.failed ? "Wrong password" : "Enter password"
                        color: LockService.failed ? Config.errorColor : Config.mutedColor
                    }
                    MouseArea { anchors.fill: parent; onClicked: hidden.forceActiveFocus() }
                }
            }
        }

        // ── bottom left: battery and keyboard hint ──
        Row {
            visible: surface.isMain && (UPower.displayDevice?.isLaptopBattery ?? false)
            anchors.left: parent.left
            anchors.bottom: parent.bottom
            anchors.margins: Config.spacing * 4
            spacing: Config.padding
            Glyph { text: UPower.onBattery ? Icons.battery : Icons.batteryCharging }
            StyledText { text: Math.round((UPower.displayDevice?.percentage ?? 0) * 100) + "%" }
        }

        // ── bottom centre: the player ──
        Rectangle {
            visible: surface.isMain && root.player !== null
            anchors.horizontalCenter: parent.horizontalCenter
            anchors.bottom: parent.bottom
            anchors.bottomMargin: Config.spacing * 4
            implicitWidth: playerRow.implicitWidth + Config.spacing * 4
            implicitHeight: 48
            radius: height / 2
            color: Config.backgroundTransparentColor
            RowLayout {
                id: playerRow
                anchors.centerIn: parent
                spacing: Config.spacing
                Glyph { text: Icons.music; color: Config.accentColor }
                StyledText { Layout.maximumWidth: 260; text: (root.player?.trackTitle ?? "") + (root.player?.trackArtist ? "  ·  " + root.player.trackArtist : "") }
                BarButton { onClicked: root.player.previous(); Glyph { text: Icons.previous } }
                BarButton { onClicked: root.player.togglePlaying(); Glyph { text: root.player?.isPlaying ? Icons.pause : Icons.play } }
                BarButton { onClicked: root.player.next(); Glyph { text: Icons.next } }
            }
        }

        // ── bottom right: suspend, restart, shut down ──
        Row {
            visible: surface.isMain
            anchors.right: parent.right
            anchors.bottom: parent.bottom
            anchors.margins: Config.spacing * 4
            spacing: Config.spacing
            Repeater {
                model: [[Icons.sleep, ["systemctl", "suspend"]], [Icons.restart, ["systemctl", "reboot"]], [Icons.power, ["systemctl", "poweroff"]]]
                Rectangle {
                    required property var modelData
                    width: 44
                    height: 44
                    radius: 22
                    color: pMouse.containsMouse ? Config.surface1Color : Config.backgroundTransparentColor
                    Glyph { anchors.centerIn: parent; text: parent.modelData[0] }
                    MouseArea { id: pMouse; anchors.fill: parent; hoverEnabled: true; cursorShape: Qt.PointingHandCursor; onClicked: Quickshell.execDetached(parent.modelData[1]) }
                }
            }
        }
    }
}
Code walkthrough · piece by piece
lines 17–19Why it's secure
// Security comes from ext-session-lock: while locked, the compositor shows
// only these surfaces and sends them all input. If the shell crashed, the
// screen would stay locked.

WlSessionLock uses the ext-session-lock protocol. While locked, the compositor shows only the lock surfaces and sends them all input; no window, shortcut or notification can appear above them. If the shell crashed while locked, the compositor would keep the session locked (showing a solid colour) instead of revealing your desktop.

import QtQuick

// The power menu: a list of actions, each with its own key, and a short
// countdown before the dangerous ones run (any key or click cancels it).
Singleton {
    id: root

    property bool visible: false
    property int selected: 0
    property int countdown: 0                 // seconds left, 0 = not counting
    property int pending: -1                  // action waiting for the countdown

    readonly property int countdownLength: StateService.get("power.countdown", 3)
    readonly property var actions: [
        { id: "lock",     key: "L", label: "Lock",      icon: Icons.lock,    confirm: false, command: [] },
        { id: "suspend",  key: "S", label: "Suspend",   icon: Icons.sleep,   confirm: false, command: ["systemctl", "suspend"] },
        { id: "logout",   key: "E", label: "Log out",   icon: Icons.logout,  confirm: true,  command: [] },
        { id: "reboot",   key: "R", label: "Restart",   icon: Icons.restart, confirm: true,  command: ["systemctl", "reboot"] },
        { id: "shutdown", key: "P", label: "Shut down", icon: Icons.power,   confirm: true,  command: ["systemctl", "poweroff"] }
    ]

    function open() {
        WindowManagerService.openExclusive("Power", () => {
            selected = 0;
            cancel();
            visible = true;
        });
    }
    function close() { cancel(); visible = false; }
    function toggle() { visible ? close() : open(); }

    function run(index) {
        const a = actions[index];
        if (!a)
            return;
        if (a.confirm && countdownLength > 0) {   // start the countdown first
            pending = index;
            selected = index;
            countdown = countdownLength;
            tick.restart();
            return;
        }
        _execute(a);
    }
    function cancel() { tick.stop(); countdown = 0; pending = -1; }

    function _execute(a) {
        visible = false;
        cancel();
        if (a.id === "lock")
            LockService.lock();
        else if (a.id === "logout")
            Hypr.exit();                          // Lua or classic, see Hypr.qml
        else
            Quickshell.execDetached(a.command);
    }

    Timer {
        id: tick
        interval: 1000
        repeat: true
        onTriggered: {
            if (--root.countdown <= 0)
                root._execute(root.actions[root.pending]);
        }
    }

    Connections {
        target: WindowManagerService
        function onCloseRequested(except) { if (except !== "Power") root.close(); }
    }
    onVisibleChanged: visible ? WindowManagerService.registerOpen("Power") : WindowManagerService.registerClose("Power")

    IpcHandler {
        target: "power"
        function toggle(): void { root.toggle(); }
    }
}

Idle#

lyne/services/IdleService.qmlpragma Singleton
import QtQuick
import Quickshell
import qs.services
import Quickshell.Io

// Idle settings, caffeine, and the actions the idle monitors in shell.qml run.
Singleton {
    id: root

    readonly property int lockTimeout: StateService.get("idle.lockTimeout", 300)   // seconds, 0 = never
    readonly property int dpmsTimeout: StateService.get("idle.dpmsTimeout", 600)
    readonly property bool caffeine: StateService.get("idle.caffeine", false)

    function toggleCaffeine() { StateService.set("idle.caffeine", !caffeine); }
    function lock() { LockService.lock(); }
    function dpmsOff() { Hypr.dpms(false); }
    function dpmsOn() { Hypr.dpms(true); }

    IpcHandler {
        target: "idle"
        function toggleCaffeine(): void { root.toggleCaffeine(); }
    }
}

The idle settings come from the state: lock after 5 minutes, screens off after 10, both 0 for never, and caffeine, which pauses both. The actions themselves are tiny. The idle monitors live in shell.qml (lyne-dots 12: Assembling the Shell and Configuring Hyprland):

IdleMonitor {
    timeout: IdleService.lockTimeout
    enabled: IdleService.lockTimeout > 0 && !IdleService.caffeine && !StateService.isLoading
    respectInhibitors: true
    onIsIdleChanged: if (isIdle) IdleService.lock()
}

An IdleMonitor becomes idle after timeout seconds without input and stops being idle at the first key or movement. respectInhibitors honours apps that ask the compositor not to go idle: video players, games, a browser playing a video. It waits for the state to load, so it doesn't start counting with the wrong timeout.
