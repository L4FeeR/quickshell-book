g9Gallery: System Pieces

The parts that turn a bar into a desktop shell: a notification daemon with popups and a notification center, a lock screen, a polkit agent, battery warnings, an idle manager, a launcher, a dock, a wallpaper with a picker, a workspace OSD and a region selector. With these, the shell can replace mako/dunst, hyprlock, hypridle, hyprpolkitagent, swww, slurp and rofi.

The files are in galleryshell/system/, plus two small singletons in galleryshell/services/ that several pieces share.

Only one of each

Some of these take over a system role that only one program can hold: the notification server, the polkit agent and the session lock. Stop mako/dunst/swaync, polkit-gnome/hyprpolkitagent and hyprlock/hypridle from autostarting before using these, or the shell will log that the role is already taken (and keep trying in the background).

The Notification Service#

What it is. The notification daemon itself: it receives every notification apps send, keeps the open ones, and decides which to show as popups. It's a singleton, so the popups, the notification center and any bell or island in your bar all share it.

Kind: service (singleton) · Needs: nothing extra (no other notification daemon running)

galleryshell/services/Notifs.qmlpragma Singleton
import Quickshell
import Quickshell.Io
import Quickshell.Services.Notifications
import QtQuick

// The notification daemon. Only ONE NotificationServer may exist, so it lives in a singleton
// and every notification widget (popups, center, bell, island) reads from here.
Singleton {
    id: root
    property bool dnd: false
    // every notification still open, oldest first (the history / notification center)
    readonly property var list: server.trackedNotifications.values
    readonly property int count: list.length
    // the ones currently shown as popups (a subset of `list`)
    property var popups: []

    signal arrived(Notification n)                   // for extra reactions (sounds, the dynamic island…)

    NotificationServer {
        id: server
        keepOnReload: true                           // survive config reloads
        actionsSupported: true
        imageSupported: true
        bodyMarkupSupported: true
        persistenceSupported: true

        onNotification: n => {
            n.tracked = true                         // keep it: without this it is dropped immediately
            n.closed.connect(() => root.hidePopup(n))
            if (!root.dnd || n.urgency === NotificationUrgency.Critical)
                root.popups = root.popups.concat([n])
            root.arrived(n)
        }
    }

    function hidePopup(n: var): void { popups = popups.filter(x => x !== n) }
    function clearAll(): void { for (const n of list.slice()) n.dismiss() }

    IpcHandler {
        target: "notifs"
        function toggleDnd(): void { root.dnd = !root.dnd }
        function clear(): void { root.clearAll() }
        function count(): int { return root.count }
    }
}

keepOnReload keeps notifications across config reloads. The …Supported flags tell apps what the shell can show; apps then send actions, images and simple markup.

lines 28–34A new notification
onNotification: n => {
    n.tracked = true                         // keep it: without this it is dropped immediately
    n.closed.connect(() => root.hidePopup(n))
    if (!root.dnd || n.urgency === NotificationUrgency.Critical)
        root.popups = root.popups.concat([n])
    root.arrived(n)
}

Setting tracked is essential: an untracked notification is discarded as soon as this handler returns. When it closes later (dismissed, expired, or closed by the app), it's removed from the popups. In do-not-disturb mode only critical notifications pop up; the rest go quietly into the list.

lines 37–38Helpers

function clearAll(): void { for (const n of list.slice()) n.dismiss() }

hidePopup removes a notification from the popups but keeps it in the list. clearAll dismisses everything; slice() copies the list first, because dismissing changes it while we loop.

And a tiny second service for session state:

galleryshell/services/Session.qmlpragma Singleton
import Quickshell
import Quickshell.Io
import QtQuick

// Small shared state for session things: is the screen locked, should idle be ignored.
Singleton {
    id: root
    property bool locked: false
    property bool caffeine: false                    // true = never dim, lock or suspend on idle

    function lock(): void { locked = true }

    IpcHandler {
        target: "session"
        function lock(): void { root.lock() }
        function toggleCaffeine(): void { root.caffeine = !root.caffeine }
    }
}

Session.locked drives the lock screen and Session.caffeine pauses the idle manager. Any widget, keybind or script can lock the screen with Session.lock() or qs ipc call session lock.

Notification Popups#

What it is. Popups in the top-right corner. Each shows the image or app icon, title, body, action buttons, and a thin line counting down its time. Hovering holds a popup open; clicking runs its default action. Critical notifications get a red outline and stay until dismissed.

Kind: own window · Needs: the notification service above

import Quickshell.Wayland
import Quickshell.Widgets
import Quickshell.Services.Notifications
import QtQuick
import QtQuick.Layouts
import qs.services

    margins { top: 8; right: 8 }
    implicitWidth: 380

    visible: Notifs.popups.length > 0
    exclusionMode: ExclusionMode.Ignore
    color: "transparent"
    WlrLayershell.layer: WlrLayer.Overlay
    WlrLayershell.namespace: "quickshell:notifications"

    ColumnLayout {
        id: stack
        width: parent.width
        spacing: 8

        Repeater {
            model: Notifs.popups
            Rectangle {
                id: card
                required property Notification modelData
                readonly property bool critical: modelData.urgency === NotificationUrgency.Critical

                    id: life

                    id: body

// A real lock screen: ext-session-lock (the compositor guarantees nothing else is shown)
// and PAM (your normal login password). Lock with: qs ipc call session lock
Scope {
    id: root
    property string password: ""
    property string error: ""
    property bool busy: false

    function tryUnlock(): void {
        if (busy || password === "") return
        busy = true; error = ""

// Warns once at 15% and again at 5% while discharging; at 3% it suspends the machine.
Scope {
    id: root
    property real warnAt: 0.15
    property real criticalAt: 0.05
    property real suspendAt: 0.03

What it is. Drag a rectangle on any screen; the rest of the screen darkens and the size is shown. Then the region is screenshotted, screen-recorded, or printed for scripts. A themed replacement for slurp.

// Drag a rectangle on any screen; the region is then screenshotted (or handed to any command).
// A slurp replacement that matches your shell.  qs ipc call region screenshot
Scope {

    property bool active: false
    property string mode: "screenshot"                // "screenshot" | "record" | "geometry"

    IpcHandler {
        target: "region"
        function screenshot(): void { root.mode = "screenshot"; root.active = true }
        function record(): void { root.mode = "record"; root.active = true }
        function geometry(): void { root.mode = "geometry"; root.active = true }
    }

        else
            console.log(geo)
    }

        model: root.active ? Quickshell.screens : []
        PanelWindow {
            id: win
            required property var modelData
            screen: modelData
            anchors { top: true; bottom: true; left: true; right: true }

// A keyboard-first app launcher. Matches names, generic names and keywords,
// ranks prefix matches first, and remembers how often you launch each app.
Scope {
    id: root
    property bool open: false
    IpcHandler { target: "launcher"; function toggle(): void { root.open = !root.open } }

    // launch counts, saved between sessions: { "firefox.desktop": 12, … }
    FileView {
        path: Quickshell.statePath("launcher.json")
        onAdapterUpdated: writeAdapter()
        onLoadFailed: writeAdapter()
        JsonAdapter { id: stats; property var counts: ({}) }
    }

    function score(e: var, q: string): int {
        const name = e.name.toLowerCase()
        if (q === "") return 1
        if (name.startsWith(q)) return 100
        if (name.split(/[\s-]/).some(w => w.startsWith(q))) return 60
        if (name.includes(q)) return 40
        if ((e.genericName ?? "").toLowerCase().includes(q)) return 20
        if (e.keywords.some(k => k.toLowerCase().startsWith(q))) return 15
        return 0
    }
    function results(q: string): var {
        q = q.trim().toLowerCase()
        return DesktopEntries.applications.values
            .filter(e => !e.noDisplay)
            .map(e => ({ e, s: score(e, q) + Math.min(30, (stats.counts[e.id] ?? 0) * 3) }))   // frequent apps float up
            .filter(r => r.s > Math.min(30, (stats.counts[r.e.id] ?? 0) * 3))                   // must match the query itself
            .sort((a, b) => b.s - a.s || a.e.name.localeCompare(b.e.name))
            .slice(0, 50)
            .map(r => r.e)
    }
    function launch(e: var): void {
        const c = Object.assign({}, stats.counts)        // copy, change, assign: so the adapter notices
        c[e.id] = (c[e.id] ?? 0) + 1
        stats.counts = c
        e.execute()
        open = false
    }

        active: root.open
        PanelWindow {
            id: win
            implicitWidth: 560; implicitHeight: 480
            exclusionMode: ExclusionMode.Ignore
            color: "transparent"
            WlrLayershell.layer: WlrLayer.Overlay
            WlrLayershell.keyboardFocus: WlrKeyboardFocus.Exclusive
            readonly property var shown: root.results(search.text)

            Rectangle {
                anchors.fill: parent
                radius: 24; color: "#1e1e2e"; border.color: "#313244"
                ColumnLayout {
                    anchors { fill: parent; margins: 14 }
                    spacing: 10
                    Rectangle {
                        Layout.fillWidth: true; implicitHeight: 48; radius: 24; color: "#313244"
                        RowLayout {
                            anchors { fill: parent; leftMargin: 18; rightMargin: 18 }
                            spacing: 10
                            Text { text: "search"; font.family: "Material Symbols Rounded"; font.pixelSize: 22; color: "#a6adc8" }

lines 23–32Scoring a match
function score(e: var, q: string): int {
    const name = e.name.toLowerCase()
    if (q === "") return 1
    if (name.startsWith(q)) return 100
    if (name.split(/[\s-]/).some(w => w.startsWith(q))) return 60
    if (name.includes(q)) return 40
    if ((e.genericName ?? "").toLowerCase().includes(q)) return 20
    if (e.keywords.some(k => k.toLowerCase().startsWith(q))) return 15
    return 0
}

Higher is better: the name starts with the query (100), a word in the name does ("code" in "Visual Studio Code", 60), the name contains it (40), then the generic name ("Web Browser", 20) and keywords (15). An empty query matches everything.

lines 33–42Building the result list
function results(q: string): var {
    q = q.trim().toLowerCase()
    return DesktopEntries.applications.values
        .filter(e => !e.noDisplay)
        .map(e => ({ e, s: score(e, q) + Math.min(30, (stats.counts[e.id] ?? 0) * 3) }))   // frequent apps float up
        .filter(r => r.s > Math.min(30, (stats.counts[r.e.id] ?? 0) * 3))                   // must match the query itself
        .sort((a, b) => b.s - a.s || a.e.name.localeCompare(b.e.name))
        .slice(0, 50)
        .map(r => r.e)
}

Hidden entries (noDisplay) are dropped. Each app gets its match score plus a frequency bonus of up to 30. The second filter keeps only apps whose match score is above zero, so a frequently used app doesn't show up for an unrelated query. Then: sort by score, then by name, keep the top 50.

Idle Manager#

What it is. Replaces hypridle: the screen dims after 4 minutes, locks after 5, turns off after 6, and the machine suspends after 15. Video players and games that ask for no idle are respected, and the caffeine toggle pauses everything.

Kind: background service · Needs: a compositor with ext-idle-notify (Hyprland, Sway, niri…)

galleryshell/system/IdleManager.qmlimport Quickshell
import Quickshell.Wayland
import QtQuick
import qs.services

// Replaces hypridle: dim after 4 min, lock after 5, screen off after 6, suspend after 15.
// Apps that inhibit idle (video players, games) are respected; so is Session.caffeine.
Scope {
    id: root

    component Stage: IdleMonitor {
        enabled: !Session.caffeine
        respectInhibitors: true
    }

    // 1. dim: a black, half-transparent overlay that fades in
    Stage { id: dim; timeout: 240 }
    Variants {
        model: dim.isIdle && !Session.locked ? Quickshell.screens : []
        PanelWindow {
            required property var modelData
            screen: modelData
            anchors { top: true; bottom: true; left: true; right: true }
            exclusionMode: ExclusionMode.Ignore
            WlrLayershell.layer: WlrLayer.Overlay
            color: "transparent"
            mask: Region {}                                  // never takes input; moving the mouse ends idle anyway
            Rectangle {
                anchors.fill: parent
                color: "black"
                NumberAnimation on opacity { from: 0; to: 0.6; duration: 4000 }
            }
        }
    }

    // 2. lock
    Stage { timeout: 300; onIsIdleChanged: if (isIdle) Session.locked = true }

    // 3. screens off, and back on when you return
    Stage {
        timeout: 360
        onIsIdleChanged: Quickshell.execDetached(["hyprctl", "dispatch", "dpms", isIdle ? "off" : "on"])
    }

    // 4. suspend (lock first so the machine wakes up locked)
    Stage {
        timeout: 900
        onIsIdleChanged: if (isIdle) { Session.locked = true; Quickshell.execDetached(["systemctl", "suspend"]) }
    }
}
