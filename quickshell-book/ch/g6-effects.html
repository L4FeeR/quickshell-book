g6Gallery: Effects, Decorations and Interactions

The polish layer: rounded screen corners, glass, animated borders, hot corners, auto-hide, crossfading wallpapers, ripples. These are the details that make a rice feel finished.

Rounded Screen Corners#

What it is. Black rounded corners drawn over the four screen corners, so the screen looks rounded like a phone or laptop panel. They're completely click-through.

Kind: its own window (one per screen) · Needs: nothing extra

galleryshell/effects/ScreenCorners.qmlimport Quickshell
import Quickshell.Wayland
import QtQuick
import QtQuick.Shapes

Scope {
    property int radius: 18
    property color cornerColor: "black"

    component Corner: Shape {
        id: c
        property int r
        property color tint
        width: r; height: r
        preferredRendererType: Shape.CurveRenderer
        ShapePath {
            fillColor: c.tint; strokeWidth: -1
            startX: 0; startY: 0
            PathLine { x: c.r; y: 0 }
            PathArc { x: 0; y: c.r; radiusX: c.r; radiusY: c.r; direction: PathArc.Counterclockwise }
            PathLine { x: 0; y: 0 }
        }
    }

    Variants {
        model: Quickshell.screens
        PanelWindow {
            required property ShellScreen modelData
            screen: modelData
            anchors { top: true; bottom: true; left: true; right: true }
            exclusionMode: ExclusionMode.Ignore
            color: "transparent"
            mask: Region {}                                    // never blocks input
            WlrLayershell.layer: WlrLayer.Overlay
            WlrLayershell.namespace: "quickshell:corners"

            Corner { anchors.top: parent.top; anchors.left: parent.left; r: radius; tint: cornerColor; rotation: 0 }
            Corner { anchors.top: parent.top; anchors.right: parent.right; r: radius; tint: cornerColor; rotation: 90 }
            Corner { anchors.bottom: parent.bottom; anchors.right: parent.right; r: radius; tint: cornerColor; rotation: 180 }
            Corner { anchors.bottom: parent.bottom; anchors.left: parent.left; r: radius; tint: cornerColor; rotation: 270 }
        }
    }
}

lines 6–8Settings
Scope {
    property int radius: 18
    property color cornerColor: "black"

The corner size and color, shared by every corner on every monitor.

lines 10–23One corner shape
component Corner: Shape {
    id: c
    property int r
    property color tint
    width: r; height: r
    preferredRendererType: Shape.CurveRenderer
    ShapePath {
        fillColor: c.tint; strokeWidth: -1
        startX: 0; startY: 0
        PathLine { x: c.r; y: 0 }
        PathArc { x: 0; y: c.r; radiusX: c.r; radiusY: c.r; direction: PathArc.Counterclockwise }
        PathLine { x: 0; y: 0 }
    }
}

A square r × r with a quarter circle cut out. The path starts at the top-left, goes right along the top edge, then PathArc curves back down to the left edge counter-clockwise (bulging toward the top-left), then closes. The filled area is the little "triangle with a curved side" that hides the screen's square corner. strokeWidth: -1 disables the outline.

lines 25–29One window per monitor
Variants {
    model: Quickshell.screens
    PanelWindow {
        required property ShellScreen modelData
        screen: modelData

Variants creates a copy of the window for each screen in Quickshell.screens, and gives it modelData (the ShellScreen). Plug in a monitor and a new copy appears.

lines 30–35A fullscreen, invisible, click-through window
anchors { top: true; bottom: true; left: true; right: true }
exclusionMode: ExclusionMode.Ignore
color: "transparent"
mask: Region {}                                    // never blocks input
WlrLayershell.layer: WlrLayer.Overlay
WlrLayershell.namespace: "quickshell:corners"

Anchored to all four edges = covers the whole screen. Transparent, ignores exclusive zones, and mask: Region {} means it receives no input: you can click right through it. Overlay keeps corners on top of everything, even fullscreen apps.

lines 37–40Four rotated corners
Corner { anchors.top: parent.top; anchors.left: parent.left; r: radius; tint: cornerColor; rotation: 0 }
Corner { anchors.top: parent.top; anchors.right: parent.right; r: radius; tint: cornerColor; rotation: 90 }
Corner { anchors.bottom: parent.bottom; anchors.right: parent.right; r: radius; tint: cornerColor; rotation: 180 }
Corner { anchors.bottom: parent.bottom; anchors.left: parent.left; r: radius; tint: cornerColor; rotation: 270 }

The same shape, anchored to each corner and rotated 0°, 90°, 180° and 270°. Rotation happens around the item's center, which for a square is exactly what we need.

Customize - Match your bar color and offset the top corners below the bar for the "bar melts into the screen" look.

Exercise 1PracticeOnly the top corners

Add property bool bottomCorners: true and hide the two bottom corners when it's false (useful with a bottom bar).

Frosted Glass Bar#

What it is. A translucent bar that blurs the wallpaper and windows behind it, with a thin light border for a glassy edge.

Kind: bar window · Needs: a compositor with layer blur (Hyprland), or BackgroundEffect support

galleryshell/effects/GlassBar.qmlimport Quickshell
import Quickshell.Wayland
import QtQuick

PanelWindow {
    anchors { top: true; left: true; right: true }
    margins { top: 8; left: 10; right: 10 }
    implicitHeight: 40
    color: "transparent"
    WlrLayershell.namespace: "quickshell:glass"          // matched by the layerrule below
    // compositor-independent alternative where supported:
    BackgroundEffect.blurRegion: Region { item: glass; radius: 14 }

    Rectangle {
        id: glass
        anchors.fill: parent
        radius: 14
        color: Qt.rgba(0.12, 0.12, 0.18, 0.45)           // translucent: the blur shows through
        border.width: 1
        border.color: Qt.rgba(1, 1, 1, 0.18)             // light rim
        Rectangle {                                      // subtle top highlight
            anchors { left: parent.left; right: parent.right; top: parent.top; margins: 1 }
            height: parent.height / 2; radius: parent.radius
            gradient: Gradient {
                GradientStop { position: 0; color: Qt.rgba(1, 1, 1, 0.08) }
                GradientStop { position: 1; color: "transparent" }
            }
        }
        Text { anchors.centerIn: parent; text: "glass"; color: "white"; font.bold: true }
    }
}
hyprland.conflayerrule = blur, quickshell:glass
layerrule = ignorealpha 0.1, quickshell:glass       # don't blur fully transparent pixels around the bar
decoration {
    blur { enabled = true; size = 8; passes = 3; vibrancy = 0.2 }
}
Code walkthrough · piece by piece
lines 5–10A floating bar with a namespace
PanelWindow {
    anchors { top: true; left: true; right: true }
    margins { top: 8; left: 10; right: 10 }
    implicitHeight: 40
    color: "transparent"
    WlrLayershell.namespace: "quickshell:glass"          // matched by the layerrule below

A floating bar (margins from the edges) with a transparent window. The namespace quickshell:glass is the name the compositor's layer rule targets for blur.

lines 11–12Blur through the protocol
// compositor-independent alternative where supported:

BackgroundEffect.blurRegion asks the compositor (where it supports the background-effect protocol) to blur behind a region, here the rounded glass rectangle. On Hyprland, the layerrule below does the same.

lines 14–20The glass
Rectangle {
    id: glass
    anchors.fill: parent
    radius: 14
    color: Qt.rgba(0.12, 0.12, 0.18, 0.45)           // translucent: the blur shows through
    border.width: 1
    border.color: Qt.rgba(1, 1, 1, 0.18)             // light rim

A dark color at 45% opacity: enough to tint and keep text readable, transparent enough to show the blurred wallpaper. A 1 px white border at 18% gives the "edge of a glass pane" highlight.

lines 21–28Top shine
Rectangle {                                      // subtle top highlight
    anchors { left: parent.left; right: parent.right; top: parent.top; margins: 1 }
    height: parent.height / 2; radius: parent.radius
    gradient: Gradient {
        GradientStop { position: 0; color: Qt.rgba(1, 1, 1, 0.08) }
        GradientStop { position: 1; color: "transparent" }
    }
}

A second rectangle over the top half with a gradient from 8% white to transparent imitates light reflecting on glass. Subtle, but it's what makes glass look like glass.

Make the bar more opaque (0.8) while hovered so text is easier to read, animating the change.

Animated Gradient Border#

What it is. A card whose border is a slowly rotating rainbow gradient, an eye-catching frame for a media card or an active panel.

Kind: reusable item · Needs: nothing extra

galleryshell/effects/GradientBorder.qmlimport QtQuick
import QtQuick.Shapes

Item {
    id: root
    property real radius: 24
    property real borderWidth: 3
    property color fill: "#1e1e2e"
    property real angle: 0
    default property alias content: inner.data

    NumberAnimation on angle { from: 0; to: 360; duration: 4000; loops: Animation.Infinite; running: root.visible }

    Shape {                                               // gradient-filled rounded rect = the border
        anchors.fill: parent
        preferredRendererType: Shape.CurveRenderer
        ShapePath {
            strokeWidth: -1
            fillGradient: ConicalGradient {
                centerX: root.width / 2; centerY: root.height / 2
                angle: root.angle
                GradientStop { position: 0.00; color: "#cba6f7" }
                GradientStop { position: 0.33; color: "#89b4fa" }
                GradientStop { position: 0.66; color: "#94e2d5" }
                GradientStop { position: 1.00; color: "#cba6f7" }
            }
            PathRectangle { x: 0; y: 0; width: root.width; height: root.height; radius: root.radius }   // Qt 6.8+
        }
    }
    Rectangle {                                           // inner surface
        id: inner
        anchors.fill: parent
        anchors.margins: root.borderWidth
        radius: root.radius - root.borderWidth
        color: root.fill
    }
}

Use it: GradientBorder { width: 300; height: 110; Text { anchors.centerIn: parent; text: "Now Playing"; color: "white" } }

Qt versions before 6.8

PathRectangle needs Qt 6.8. On older Qt, draw the rounded rectangle with PathLine + PathArc segments, or use a Rectangle with a ConicalGradient from Qt5Compat.GraphicalEffects masked by an OpacityMask.

A slightly smaller rectangle (inset by borderWidth) covers the center with the fill color. Only a thin rim of the gradient stays visible: the "border". Its radius is reduced by the border width so the curves stay parallel.

Hover-Expand Icon Row#

What it is. A row of status icons where hovering an icon makes it grow into a pill with a label (Wi-Fi name, volume %, battery %). It's minimal at rest and informative on hover.

Kind: bar module · Needs: nothing extra (bind labels to your services)

galleryshell/effects/ExpandIcon.qmlimport QtQuick

Rectangle {
    id: root
    property string icon: "wifi"
    property string label: "Home-5G"
    readonly property bool open: hover.hovered

    implicitWidth: open ? row.implicitWidth + 18 : 28
    implicitHeight: 28
    radius: height / 2
    color: open ? "#45475a" : "transparent"
    clip: true
    Behavior on implicitWidth { NumberAnimation { duration: 260; easing.type: Easing.OutCubic } }
    Behavior on color { ColorAnimation { duration: 160 } }

    Row {
        id: row
        x: 6
        anchors.verticalCenter: parent.verticalCenter
        spacing: 6
        Text { text: root.icon; font.family: "Material Symbols Rounded"; font.pixelSize: 17; color: "#cdd6f4"
               font.variableAxes: ({ "FILL": root.open ? 1 : 0 }) }
        Text {
            text: root.label; color: "#cdd6f4"; font.pixelSize: 12
            anchors.verticalCenter: parent.verticalCenter
            opacity: root.open ? 1 : 0
            Behavior on opacity { NumberAnimation { duration: 200 } }
        }
    }
    HoverHandler { id: hover }
}

Use it: Row { spacing: 2; ExpandIcon { icon: "wifi"; label: "Home-5G" } ExpandIcon { icon: "volume_up"; label: "62%" } ExpandIcon { icon: "battery_5_bar"; label: "81%" } }

Hot Corner#

What it is. Push the mouse into the top-left corner of the screen and something happens (open the overview, like GNOME), after a short delay so it doesn't trigger by accident.

Kind: its own window (one per screen) · Needs: nothing extra

galleryshell/effects/HotCorner.qmlimport Quickshell
import Quickshell.Wayland
import QtQuick

Scope {
    id: root
    signal triggered()                          // connect this to anything
    property int delay: 250                     // ms the pointer must stay in the corner

    Variants {
        model: Quickshell.screens
        PanelWindow {
            required property ShellScreen modelData
            screen: modelData
            anchors { top: true; left: true }
            implicitWidth: 3; implicitHeight: 3          // a tiny invisible target
            exclusionMode: ExclusionMode.Ignore
            color: "transparent"
            WlrLayershell.layer: WlrLayer.Overlay
            WlrLayershell.namespace: "quickshell:hotcorner"

            HoverHandler {
                id: hh
                onHoveredChanged: hovered ? wait.restart() : wait.stop()
            }
            Timer { id: wait; interval: root.delay; onTriggered: root.triggered() }
        }
    }
}

Use it: HotCorner { onTriggered: Hyprland.dispatch("hyprexpo:expo toggle") } or onTriggered: GlobalStates.toggle("overview").

Auto-Hide Bar (Edge Reveal)#

What it is. The bar hides above the screen and slides down when you touch the top edge (or when no window is open), and windows get the full screen while it's hidden.

Kind: bar window · Needs: nothing extra

galleryshell/effects/AutoHideBar.qmlimport Quickshell
import Quickshell.Wayland
import QtQuick

PanelWindow {
    id: bar
    property int barHeight: 40
    readonly property bool revealed: hover.hovered || ToplevelManager.activeToplevel === null || pinned
    property bool pinned: false                      // e.g. while a popup from the bar is open

    anchors { top: true; left: true; right: true }
    implicitHeight: barHeight + 10
    exclusiveZone: 0                                 // never pushes windows: it overlays
    color: "transparent"

    // when hidden, only a 3 px strip at the very top catches the mouse
    mask: Region { item: bar.revealed ? content : trigger }
    Item { id: trigger; width: parent.width; height: 3 }
    HoverHandler { id: hover }

    // a short delay before hiding avoids flicker when the pointer briefly leaves
    property bool shown: revealed
    onRevealedChanged: revealed ? (shown = true) : hideDelay.restart()
    Timer { id: hideDelay; interval: 400; onTriggered: if (!bar.revealed) bar.shown = false }

    Rectangle {
        id: content
        x: 10; width: parent.width - 20; height: bar.barHeight
        y: bar.shown ? 6 : -height - 4
        Behavior on y { NumberAnimation { duration: 260; easing.type: Easing.OutCubic } }
        radius: 14
        color: "#1e1e2e"; border.color: "#313244"
        Text { anchors.centerIn: parent; text: "auto-hide bar"; color: "#cdd6f4" }
    }
}

Wallpaper Slideshow with Crossfade#

What it is. Quickshell draws the wallpaper itself and changes it every N minutes from a folder, crossfading between images. No swww or hyprpaper needed.

Kind: its own window (one per screen) · Needs: a folder of images

galleryshell/effects/Slideshow.qmlimport Quickshell
import Quickshell.Io
import Quickshell.Wayland
import QtQuick

Scope {
    id: root
    property string folder: Quickshell.env("HOME") + "/Pictures/Wallpapers"
    property int minutes: 15
    property var files: []
    property int index: 0
    readonly property string current: files.length ? "file://" + files[index % files.length] : ""

    Process {
        running: true
        command: ["sh", "-c", `find "$1" -maxdepth 1 -type f \\( -iname '*.jpg' -o -iname '*.png' -o -iname '*.webp' \\) | shuf`, "sh", root.folder]
        stdout: StdioCollector { onStreamFinished: root.files = text.trim().split("\n").filter(f => f) }
    }
    Timer { interval: root.minutes * 60000; running: root.files.length > 1; repeat: true; onTriggered: root.index++ }
    IpcHandler { target: "slideshow"; function next(): void { root.index++ } }

    Variants {
        model: Quickshell.screens
        PanelWindow {
            id: bg
            required property ShellScreen modelData
            screen: modelData
            anchors { top: true; bottom: true; left: true; right: true }
            exclusionMode: ExclusionMode.Ignore
            color: "black"
            WlrLayershell.layer: WlrLayer.Background

            property bool aOnTop: true
            Connections {
                target: root
                function onCurrentChanged() { (bg.aOnTop ? b : a).source = root.current }   // load into the hidden one
            }
            component Wall: Image {
                anchors.fill: parent
                fillMode: Image.PreserveAspectCrop
                asynchronous: true; cache: false
                sourceSize: Qt.size(bg.width * bg.modelData.devicePixelRatio, bg.height * bg.modelData.devicePixelRatio)
                Behavior on opacity { NumberAnimation { duration: 1200; easing.type: Easing.InOutQuad } }
            }
            Wall { id: a; opacity: bg.aOnTop ? 1 : 0; onStatusChanged: if (status === Image.Ready && source == root.current) bg.aOnTop = true }
            Wall { id: b; opacity: bg.aOnTop ? 0 : 1; onStatusChanged: if (status === Image.Ready && source == root.current) bg.aOnTop = false }
            Component.onCompleted: a.source = root.current
        }
    }
}

Click Ripple#

What it is. A Material-style ripple that spreads from exactly where you clicked inside a button.

Kind: reusable item · Needs: nothing extra

galleryshell/effects/RippleButton.qmlimport QtQuick

Rectangle {
    id: root
    property string text: "Click me"
    signal clicked()

    implicitWidth: label.implicitWidth + 40; implicitHeight: 44
    radius: 16
    color: "#313244"
    clip: true                                      // keep the ripple inside (rectangular clip)

    Rectangle {
        id: ripple
        width: 0; height: width; radius: width / 2
        color: "#cdd6f4"; opacity: 0
        x: cx - width / 2; y: cy - height / 2
        property real cx: 0
        property real cy: 0
    }
    ParallelAnimation {
        id: spread
        NumberAnimation { target: ripple; property: "width"; from: 0; to: Math.hypot(root.width, root.height) * 2; duration: 450; easing.type: Easing.OutCubic }
        NumberAnimation { target: ripple; property: "opacity"; from: 0.3; to: 0; duration: 500 }
    }
    Text { id: label; anchors.centerIn: parent; text: root.text; color: "#cdd6f4"; font.bold: true }

    TapHandler {
        onTapped: (point) => {
            ripple.cx = point.position.x
            ripple.cy = point.position.y
            spread.restart()
            root.clicked()
        }
    }
}
Rounded clipping

clip: true clips to a rectangle, so the ripple may show in the corners of a very round button. Wrap the content in a ClippingRectangle for perfectly rounded clipping.

Rainbow Active Workspace#

What it is. The active-workspace pill filled with a slowly shifting rainbow gradient, a fun twist on the standard indicator.

Kind: bar module piece · Needs: nothing extra (combine with Workspace Dots)

galleryshell/effects/RainbowPill.qmlimport QtQuick

Rectangle {
    id: root
    width: 34; height: 12; radius: 6
    property real shift: 0
    NumberAnimation on shift { from: 0; to: 1; duration: 3000; loops: Animation.Infinite; running: root.visible }
    gradient: Gradient {
        orientation: Gradient.Horizontal
        GradientStop { position: 0.0; color: Qt.hsla((root.shift + 0.00) % 1, 0.75, 0.75, 1) }
        GradientStop { position: 0.5; color: Qt.hsla((root.shift + 0.33) % 1, 0.75, 0.75, 1) }
        GradientStop { position: 1.0; color: Qt.hsla((root.shift + 0.66) % 1, 0.75, 0.75, 1) }
    }
}

Each gradient stop computes its color with Qt.hsla(hue, saturation, lightness, alpha). The hues are shift, shift + 0.33 and shift + 0.66 (one third of the color wheel apart), wrapped with % 1. As shift grows, all three hues rotate together, so the rainbow flows along the pill. Saturation and lightness stay fixed, so the colors keep a consistent pastel feel.
