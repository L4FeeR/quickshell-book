g10Gallery: Build a Whole Shell from the Gallery

Every widget in this gallery is a separate file in examples/galleryshell/, and the folder is also a complete, runnable Quickshell config. This chapter shows how the pieces are put together: a bar made of chips, notifications, a launcher, a dock, a lock screen, an idle manager, a polkit agent, OSDs, a wallpaper and a dozen pickers, all wired up in one 80-line shell.qml.

Use it three ways:

  1. Run it as it is, to try every widget at once.
  2. Copy it as a starting point and delete what you don't want.
  3. Read it as a recipe for combining widgets in your own shell.

The assembled shell: bar, a notification popup, the launcher, a desktop clock and the dock.

The folder#

galleryshell/
├── shell.qml           the entry point (this chapter)
├── hyprland.conf       keybinds to source from your Hyprland config
├── services/           Notifs, Session (shared singletons)
├── bar/                Bar.qml + every bar chip (g1, g2, g7)
├── popups/             chips with popups, overlays, OSDs (g3, g8)
├── panels/             quick settings, app grid, power menu, pickers (g4)
├── desktop/            desktop-layer widgets (g5)
├── effects/            corners, glass, hot corners… (g6)
└── system/             notifications, lock, polkit, idle, dock, launcher, wallpaper (g9)

Each folder is a QML module: import qs.bar makes every file in bar/ available as a type (NetworkChip, Tray…), import qs.services gives the Notifs and Session singletons. That's the whole mechanism; no registration or build step (Project Layout of a Real Shell).

Installing it#

cp -r examples/galleryshell ~/.config/quickshell/galleryshell
qs -c galleryshell

Then add the keybinds to your Hyprland config:

galleryshell/hyprland.conf# Keybinds for the gallery shell. Add to hyprland.conf:  source = ~/.config/quickshell/galleryshell/hyprland.conf
exec-once = qs -c galleryshell
exec-once = wl-paste --watch cliphist store

# global shortcuts (shell.qml)
bind = SUPER, Space, global, quickshell:launcher
bind = SUPER, N, global, quickshell:notifications
bind = SUPER, A, global, quickshell:quicksettings
bind = SUPER, Escape, global, quickshell:power
bind = SUPER, L, global, quickshell:lock
bind = SUPER, slash, global, quickshell:cheatsheet

# IPC targets (each panel has its own)
bind = SUPER, D, exec, qs -c galleryshell ipc call appgrid toggle
bind = SUPER, V, exec, qs -c galleryshell ipc call clipboard toggle
bind = SUPER, period, exec, qs -c galleryshell ipc call emoji toggle
bind = SUPER, C, exec, qs -c galleryshell ipc call calc toggle
bind = SUPER, W, exec, qs -c galleryshell ipc call wallpicker toggle
bind = , Print, exec, qs -c galleryshell ipc call screenshot toggle
bind = SHIFT, Print, exec, qs -c galleryshell ipc call region screenshot

# Alt+Tab
bind  = ALT, Tab, exec, qs -c galleryshell ipc call alttab next
bind  = ALT SHIFT, Tab, exec, qs -c galleryshell ipc call alttab prev
bindr = ALT, ALT_L, exec, qs -c galleryshell ipc call alttab commit

# blur behind the bar, panels and notifications
layerrule = blur, quickshell:.*
layerrule = ignorezero, quickshell:.*

Install what the widgets call out to (Arch package names; most are optional and only the widget that uses one needs it):

sudo pacman -S --needed ttf-material-symbols-variable-git brightnessctl cliphist wl-clipboard grim slurp jq wf-recorder hyprsunset libnotify pavucontrol blueman

(ttf-material-symbols-variable-git is from the AUR; any package that installs the Material Symbols Rounded font works.)

Turn off what it replaces

The shell runs its own notification daemon, polkit agent, lock screen, idle manager and wallpaper. Remove mako/dunst/swaync, hyprpolkitagent/polkit-gnome, hypridle, hyprlock and swww/hyprpaper from your exec-once lines, or the shell will report that a role is already taken.

The entry point#

galleryshell/shell.qml//@ pragma UseQApplication
//@ pragma Env QS_NO_RELOAD_POPUP=1
import Quickshell
import Quickshell.Hyprland
import QtQuick
import qs.bar
import qs.popups
import qs.panels
import qs.system
import qs.desktop
import qs.effects
import qs.services

// A complete desktop shell built only from gallery pieces.
// Run it with:  qs -p ~/.config/quickshell/galleryshell   (or -c galleryshell)
ShellRoot {
    // ── background ───────────────────────────────────────────
    Wallpaper { id: wallpaper }
    WallpaperPicker { target: wallpaper }
    ScreenCorners {}

    // ── the bar, one per screen ──────────────────────────────
    Variants {
        model: Quickshell.screens
        Bar {
            notifCenter: notifCenter
            quickSettings: quickSettings
            powerMenu: powerMenu
            launcher: launcher
        }
    }

    // ── notifications ────────────────────────────────────────
    NotificationPopups {}
    NotificationCenter { id: notifCenter }

    // ── panels and pickers ───────────────────────────────────
    Launcher { id: launcher }
    AppGrid {}
    QuickSettings {
        id: quickSettings
        // keep the quick-settings toggles and the shared services in sync, both ways
        onDndChanged: Notifs.dnd = dnd
        onCaffeineChanged: Session.caffeine = caffeine
    }
    Connections { target: Notifs; function onDndChanged(): void { quickSettings.dnd = Notifs.dnd } }
    Connections { target: Session; function onCaffeineChanged(): void { quickSettings.caffeine = Session.caffeine } }
    PowerBubbles { id: powerMenu }
    WifiPicker {}
    Calculator {}
    EmojiPicker {}
    ClipboardHistory {}
    ScreenshotMenu {}
    RegionSelector {}
    AltTabSwitcher {}
    ConfirmDialog {}
    Cheatsheet {}

    // ── on-screen displays ───────────────────────────────────
    VerticalOsd {}
    WorkspaceOsd {}
    ChargingPopup {}
    BatteryWarning {}

    // ── desktop ──────────────────────────────────────────────
    Dock {}
    DesktopClock {}

    // ── session ──────────────────────────────────────────────
    LockScreen {}
    IdleManager {}
    PolkitAgent {}

    // ── keybinds: bind = SUPER, Space, global, quickshell:launcher (see hyprland.conf) ──
    GlobalShortcut { name: "launcher"; onPressed: launcher.open = !launcher.open }
    GlobalShortcut { name: "notifications"; onPressed: notifCenter.open = !notifCenter.open }
    GlobalShortcut { name: "quicksettings"; onPressed: quickSettings.open = !quickSettings.open }
    GlobalShortcut { name: "power"; onPressed: powerMenu.open = !powerMenu.open }
    GlobalShortcut { name: "lock"; onPressed: Session.lock() }
}

The quick settings panel from Gallery: Panels and Menus has its own dnd and caffeine toggles, while the shell's services keep theirs. Two handlers copy panel → service, and two Connections copy service → panel. Assigning a value a property already has doesn't emit a change, so this can't loop. This is the usual way to connect a self-contained widget to shared state without editing the widget.

The bar#

import Quickshell.Wayland
import QtQuick
import QtQuick.Layouts

import qs.popups

// The assembled bar: gallery chips in three groups. One instance per screen (see shell.qml).
PanelWindow {
    id: bar
    required property ShellScreen modelData
    // windows elsewhere in the shell that bar buttons open (passed in by shell.qml)
    property var notifCenter: null
    property var quickSettings: null
    property var powerMenu: null
    property var launcher: null

    screen: modelData
    anchors { top: true; left: true; right: true }
    implicitHeight: 42
    color: "transparent"
    WlrLayershell.namespace: "quickshell:bar"

    Rectangle {
        anchors { fill: parent; topMargin: 6; leftMargin: 8; rightMargin: 8 }
        radius: 14
        color: "#1e1e2e"
        border.color: "#313244"

        // ── left ─────────────────────────────────────────────
        RowLayout {
            anchors { left: parent.left; leftMargin: 6; verticalCenter: parent.verticalCenter }
            spacing: 6
            Rectangle {                                          // launcher button
                implicitWidth: 30; implicitHeight: 26; radius: 13
                color: launchHover.hovered ? "#cba6f7" : "#313244"
                Text { anchors.centerIn: parent; text: "apps"; font.family: "Material Symbols Rounded"; font.pixelSize: 18; color: launchHover.hovered ? "#1e1e2e" : "#cba6f7" }
                HoverHandler { id: launchHover; cursorShape: Qt.PointingHandCursor }
                TapHandler { onTapped: if (bar.launcher) bar.launcher.open = !bar.launcher.open }
            }
            WorkspaceList { screen: bar.screen }
            SubmapIndicator {}
            ActiveWindow { maxWidth: 260 }
        }

        // ── centre ───────────────────────────────────────────
        RowLayout {
            anchors.centerIn: parent
            spacing: 6
            CalendarPopup {}
            MediaMarquee {}
        }

        // ── right ────────────────────────────────────────────
        RowLayout {
            anchors { right: parent.right; rightMargin: 6; verticalCenter: parent.verticalCenter }
            spacing: 6

            MicChip {}

                count: Notifs.count
                dnd: Notifs.dnd
                TapHandler { onTapped: if (bar.notifCenter) bar.notifCenter.open = !bar.notifCenter.open }
            }
            Rectangle {                                          // quick settings + power
                implicitWidth: 56; implicitHeight: 26; radius: 13

                    anchors.centerIn: parent

                    }
                }
            }
        }
    }
}

Changing it#

Swap a widget. Replace WorkspaceList { screen: bar.screen } with WorkspaceDots {}, or MediaMarquee {} with MediaPill {}. Chips are interchangeable because they all have the same height and pill shape.

Remove a widget. Delete its line. Nothing else refers to it unless it has an id used elsewhere (only the four windows the bar opens, and the wallpaper).

Add a widget. Put any file from the gallery into the right folder and add one line: a chip in Bar.qml, anything else in shell.qml.

Move the bar. Change anchors to { bottom: true; left: true; right: true }, swap topMargin for bottomMargin, and change the popups' anchor.edges from Edges.Bottom to Edges.Top (and anchor.margins.top to anchor.margins.bottom).

Theme it. The gallery uses Catppuccin Mocha hex colours so each file stands alone. To make the whole shell switchable, copy services/Theme.qml from the theming kit, then replace the colours with roles as Theming 4: Making Widgets Themeable describes; grep -rn '"#' galleryshell/ finds them all.

What was tested#

Every file passes qmllint. The whole shell loads and runs under Quickshell, and the bar, tray, dock, launcher and notification center were checked on screen. Hyprland-specific parts (workspaces, submaps, global shortcuts, focus grabs, hyprctl calls) need a Hyprland session; on other compositors they log a warning and do nothing.
