a6Animations: Ripples, Stretch and Snow

Three effects ricers ask for again and again: a ripple that spreads from where you click or type, a squash-and-stretch "jelly" press, and snow falling over the desktop. This chapter builds each as a small reusable component, then shows every place you can use them: buttons, password and search fields, tabs, shell events like a volume change, and the desktop itself.

The code is in examples/ripples/, a runnable Quickshell config with a showcase window (qs -p examples/ripples; the demo password is secret). The components use only Qt Quick, so they also work outside Quickshell, for example in an SDDM theme (Desktop Ricing 10: SDDM Ricing).

One ripple#

ripples/components/Ripple.qmlimport QtQuick

// One ripple: a circle that grows from a point and fades out, then removes
// itself. RippleLayer creates these; you rarely use it directly.
Rectangle {
    id: root

    property real centerX: 0
    property real centerY: 0
    property real endSize: 200            // diameter at the end
    property int duration: 600
    property real startOpacity: 0.35
    property bool ring: false             // true: an outline that expands, false: a filled circle
    property color tint: "white"

    width: endSize
    height: endSize
    radius: endSize / 2
    x: centerX - endSize / 2
    y: centerY - endSize / 2
    color: ring ? "transparent" : tint
    border.width: ring ? 3 : 0
    border.color: tint
    scale: 0
    opacity: startOpacity

    // grow and fade at the same time; when both are done, destroy the ripple
    ParallelAnimation {
        running: true
        NumberAnimation { target: root; property: "scale"; from: 0; to: 1; duration: root.duration; easing.type: Easing.OutCubic }
        NumberAnimation { target: root; property: "opacity"; from: root.startOpacity; to: 0; duration: root.duration; easing.type: Easing.InQuad }
        onFinished: root.destroy()
    }
}

A layer to spawn them#

ripples/components/RippleLayer.qmlimport QtQuick

// A layer that spawns ripples anywhere on it. Put it over (or under) any
// content and call burst():
//   RippleLayer { id: ripples; anchors.fill: parent }
//   ripples.burst(x, y)                                   // a default ripple
//   ripples.burst(x, y, { tint: "red", ring: true, endSize: 400, duration: 900 })
// Each ripple is created on demand and removes itself, so the layer costs
// nothing while idle.
Item {
    id: root

    property color tint: "white"
    property real endSize: 200
    property int duration: 600
    property real startOpacity: 0.35
    property int maxRipples: 24           // keep fast typing from piling up hundreds

    Component { id: rippleComponent; Ripple {} }

    function burst(x, y, options) {
        if (root.children.length >= root.maxRipples)
            root.children[0].destroy();   // drop the oldest
        const o = options ?? {};
        rippleComponent.createObject(root, {
            centerX: x,
            centerY: y,
            tint: o.tint ?? root.tint,
            endSize: o.endSize ?? root.endSize,
            duration: o.duration ?? root.duration,
            startOpacity: o.startOpacity ?? root.startOpacity,
            ring: o.ring ?? false
        });
    }

    // a ripple from the middle, big enough to cover the whole layer
    function flood(options) {
        const o = Object.assign({ endSize: Math.hypot(width, height) * 2 }, options ?? {});
        burst(width / 2, height / 2, o);
    }
}

Click ripples on anything#

ripples/components/ClickRipple.qmlimport QtQuick
import QtQuick.Effects

// Click ripples for any item, clipped to its rounded shape. Put it inside the
// item as the last child:
//   Rectangle { radius: 14; …; ClickRipple { radius: 14; onClicked: … } }
// It takes the clicks itself (and passes them on through `clicked`), and adds
// a soft hover highlight.
Item {
    id: root

    property real radius: 0
    property color tint: "white"
    property bool hoverHighlight: true
    signal clicked(var mouse)

    anchors.fill: parent

    // the ripples live in a layer masked by a rounded rectangle, so they
    // never spill past the corners (plain `clip` would only cut a square)
    Item {
        id: content
        anchors.fill: parent
        layer.enabled: true
        layer.effect: MultiEffect {
            maskEnabled: true
            maskSource: mask
        }
        Rectangle {                        // hover highlight
            anchors.fill: parent
            color: root.tint
            opacity: root.hoverHighlight && area.containsMouse ? 0.06 : 0
            Behavior on opacity { NumberAnimation { duration: 150 } }
        }
        RippleLayer {
            id: ripples
            anchors.fill: parent
            tint: root.tint
            endSize: Math.hypot(root.width, root.height) * 2.2   // always reaches the far corner
        }
    }
    Rectangle {                            // the mask's shape
        id: mask
        anchors.fill: parent
        radius: root.radius
        visible: false
        layer.enabled: true
    }

    MouseArea {
        id: area
        anchors.fill: parent
        hoverEnabled: true
        cursorShape: Qt.PointingHandCursor
        onPressed: m => ripples.burst(m.x, m.y)
        onClicked: m => root.clicked(m)
    }
}

Ripples for typing#

ripples/components/TypingRipple.qmlimport QtQuick

// Ripples for typing: attach it to a TextInput (or TextField) and every key
// sends a ripple out from the caret. Deleting sends a smaller ring; Enter a
// big one; call shake("red") for a failure shockwave.
//   Item {
//       TextInput { id: field; … }
//       TypingRipple { target: field; anchors.fill: parent }
//   }
// The ripple layer fills the TypingRipple; place it where the effect may spread.
Item {
    id: root

    required property var target           // a TextInput, TextField, or anything with text and cursorRectangle
    property color tint: "#7aa2f7"
    property color deleteTint: "#bb9af7"
    property real keySize: 90
    property bool randomTints: false       // a different colour from `tints` per key
    property var tints: ["#7aa2f7", "#bb9af7", "#7dcfff", "#9ece6a", "#e0af68", "#f7768e"]

    property int lastLength: target.text.length

    RippleLayer { id: ripples; anchors.fill: parent }

    // the caret's centre, in this item's coordinates
    function caret() {
        const r = target.cursorRectangle;
        return target.mapToItem(root, r.x + r.width / 2, r.y + r.height / 2);
    }

    // Inside textChanged, Qt hasn't laid out the new text yet, so the caret
    // position is still stale (an empty rectangle). Qt.callLater runs the
    // ripple a moment later, once the caret has moved.
    function _typed(deleted) {
        const p = root.caret();
        if (deleted) {
            ripples.burst(p.x, p.y, { tint: root.deleteTint, endSize: root.keySize * 0.6, ring: true, duration: 400 });
        } else {
            const t = root.randomTints ? root.tints[Math.floor(Math.random() * root.tints.length)] : root.tint;
            ripples.burst(p.x, p.y, { tint: t, endSize: root.keySize, duration: 500 });
        }
    }

    Connections {
        target: root.target
        function onTextChanged() {
            const now = root.target.text.length;
            if (now !== root.lastLength)
                Qt.callLater(root._typed, now < root.lastLength);
            root.lastLength = now;
        }
        function onAccepted() {                   // Enter
            const p = root.caret();
            ripples.burst(p.x, p.y, { tint: root.tint, endSize: Math.max(root.width, root.height) * 2.5, ring: true, duration: 800, startOpacity: 0.6 });
        }
    }

    // a red shockwave over the whole area, for "wrong password" and the like
    function shake(colour) {
        ripples.flood({ tint: colour ?? "#f7768e", ring: true, duration: 700, startOpacity: 0.8 });
        ripples.flood({ tint: colour ?? "#f7768e", duration: 500, startOpacity: 0.25 });
    }
}

    ripples.flood({ tint: colour ?? "#f7768e", ring: true, duration: 700, startOpacity: 0.8 });
    ripples.flood({ tint: colour ?? "#f7768e", duration: 500, startOpacity: 0.25 });
}

shake() floods the area with a red ring and a faint red wash at once: the feedback for a wrong password.

Squash and stretch#

ripples/components/Stretch.qmlimport QtQuick

// A squash-and-stretch "jelly" effect for any item. Put it inside the item:
//   Rectangle { …; Stretch { id: jelly } }       then call jelly.press() / jelly.release()
// or let it handle the mouse itself with `handleMouse: true`.
// Pressing squashes the item (wider and flatter); releasing makes it spring
// back past its size and wobble to rest. poke() does a quick squash and
// release in one go, for keys and events.
Item {
    id: root

    property Item item: parent             // the item to deform
    property real amount: 0.12             // how far it squashes (0.12 = 12%)
    property bool handleMouse: false
    signal clicked

    anchors.fill: parent

    // Two scales: x and y. Squash makes x bigger and y smaller, so the area
    // looks constant, like something soft being pressed.
    Scale {
        id: deform
        origin.x: root.item.width / 2
        origin.y: root.item.height / 2
        xScale: 1
        yScale: 1
    }
    Component.onCompleted: root.item.transform = [deform]

    function press() {
        spring.stop();
        squash.restart();
    }
    function release() {
        squash.stop();
        spring.restart();
    }
    function poke(strength) {               // a quick squash-and-release
        const a = root.amount * (strength ?? 0.6);
        squash.stop();
        deform.xScale = 1 + a;
        deform.yScale = 1 - a;
        spring.restart();
    }

    // press: squash over 90 ms
    ParallelAnimation {
        id: squash
        NumberAnimation { target: deform; property: "xScale"; to: 1 + root.amount; duration: 90; easing.type: Easing.OutQuad }
        NumberAnimation { target: deform; property: "yScale"; to: 1 - root.amount; duration: 90; easing.type: Easing.OutQuad }
    }
    // release: spring back. OutElastic overshoots and wobbles, like jelly.
    ParallelAnimation {
        id: spring
        NumberAnimation { target: deform; property: "xScale"; to: 1; duration: 700; easing.type: Easing.OutElastic; easing.amplitude: 1.2; easing.period: 0.35 }
        NumberAnimation { target: deform; property: "yScale"; to: 1; duration: 700; easing.type: Easing.OutElastic; easing.amplitude: 1.2; easing.period: 0.35 }
    }

    MouseArea {
        anchors.fill: parent
        enabled: root.handleMouse
        cursorShape: Qt.PointingHandCursor
        onPressed: root.press()
        onReleased: root.release()
        onCanceled: root.release()
        onClicked: root.clicked()
    }
}

ripples/components/StretchPill.qmlimport QtQuick

// The stretchy pill from the workspace indicators: it moves between targets
// with its two edges travelling at different speeds, so it stretches across
// and snaps back. Set `target` to any item in the same parent.
//   StretchPill { target: tabs.currentItem }
Rectangle {
    id: root

    property Item target: null
    property int fast: 140                 // the edge in front
    property int slow: 320                 // the edge behind
    property real padding: 0

    readonly property real goalLeft: target ? target.x - padding : 0
    readonly property real goalRight: target ? target.x + target.width + padding : 0
    property real leftEdge: goalLeft
    property real rightEdge: goalRight
    property int direction: 0

    x: leftEdge
    width: Math.max(0, rightEdge - leftEdge)
    radius: height / 2

    onGoalLeftChanged: direction = goalLeft > leftEdge ? 1 : -1
    // moving right: the right edge leads; moving left: the left edge leads
    Behavior on leftEdge { NumberAnimation { duration: root.direction < 0 ? root.fast : root.slow; easing.type: Easing.OutCubic } }
    Behavior on rightEdge { NumberAnimation { duration: root.direction > 0 ? root.fast : root.slow; easing.type: Easing.OutCubic } }
}

The elastic tab or workspace pill from lyne-dots 5: The Bar, as a general component: point target at any item in the same parent and the pill slides to it with its leading edge fast and its trailing edge slow, so it stretches across and snaps back.

Snow#

ripples/components/Snow.qmlimport QtQuick
import QtQuick.Particles

// Falling snow over whatever this item covers. Qt's particle system does the
// work: an emitter along the top edge creates flakes, gravity pulls them
// down, and a random "wander" makes them drift like real snow.
//   Snow { anchors.fill: parent; intensity: 1; wind: 20 }
// burst(x, y) throws a puff of flakes from a point (for clicks and keys).
Item {
    id: root

    property real intensity: 1             // 0 = none, 1 = steady, 3 = blizzard
    property real wind: 15                 // sideways drift, pixels per second (negative = left)
    property color tint: "white"
    property bool running: true

    ParticleSystem {
        id: system
        anchors.fill: parent
        running: root.running

        // what a flake looks like: a soft round dot, drawn by the GPU
        ItemParticle {
            groups: ["flake", "puff"]
            delegate: Rectangle {
                readonly property real size: 3 + Math.random() * 5
                width: size
                height: size
                radius: size / 2
                color: root.tint
                opacity: 0.4 + Math.random() * 0.5
            }
        }

        // steady snow: born along the top edge, falling
        Emitter {
            group: "flake"
            width: parent.width
            height: 1
            y: -10
            emitRate: 40 * root.intensity * (parent.width / 1920)   // the same density on any width
            lifeSpan: 12000
            lifeSpanVariation: 3000
            velocity: AngleDirection { angle: 90; angleVariation: 12; magnitude: 45; magnitudeVariation: 25 }
            enabled: root.intensity > 0
        }

        // the puff for burst(): a short blast in every direction
        Emitter {
            id: puffs
            group: "puff"
            enabled: false
            emitRate: 0
            lifeSpan: 1600
            lifeSpanVariation: 400
            velocity: AngleDirection { angle: 0; angleVariation: 180; magnitude: 140; magnitudeVariation: 80 }
        }

        // wind pushes everything sideways; gravity pulls the puffs back down
        Gravity { groups: ["flake", "puff"]; angle: 0; magnitude: root.wind }
        Gravity { groups: ["puff"]; angle: 90; magnitude: 160 }
        // drifting: each flake wanders a little left and right
        Wander { groups: ["flake"]; xVariance: 40; pace: 40 }
    }

    // a puff of flakes from a point
    function burst(x, y, count) {
        puffs.burst(count ?? 18, x, y);
    }
}

Where to use them#

The demo shell puts all of it together:

//   password field with typing ripples and a failure shockwave, a search

            WlrLayershell.namespace: "ripples_snow"

Here is every use, and how it's wired:

Where How
Buttons of any shape ClickRipple { radius: … } inside the button
Jelly buttons Stretch { handleMouse: true } inside it
Tabs, workspaces StretchPill { target: currentTab } behind the row
Password field (lock screen, SDDM, polkit) TypingRipple { target: field } around it; on a wrong password typing.shake() and jelly.poke(1.4)
Search fields (launcher, clipboard) TypingRipple { randomTints: true } for a colour per key; plus Snow.burst() from the caret
Correct password a celebration: several snow puffs across the window
Shell events a RippleLayer that bursts from a Connections: here on every volume change (an OSD with a pulse); the same works for a notification arriving, a workspace switch or a charger plugged in
Scripts and keybinds an IpcHandler that calls burst(): qs -p examples/ripples ipc call ripple at 180 180
The desktop Snow in a full-screen window on the bottom layer with an empty input mask: snow on the wallpaper, behind your windows, never taking clicks
Over everything the same window on the overlay layer: snow (or ripples) over your windows, still click-through

To use them in your own shell, copy examples/ripples/components/ into your config (for example as components/effects/) and import it.

Ripples for keys typed into other apps?

On Wayland, a shell only receives keys typed into its own windows; keys typed into your terminal or browser go only to them. That's a security feature: no program can watch what you type elsewhere. So typing ripples belong in the shell's own fields: the lock screen, launcher, search and login screen. (Reading raw keyboard devices would need special permissions and amounts to a keylogger, so don't.)

Performance#

  • Ripples cost nothing at rest: they exist only while animating, and the cap stops them piling up.
  • Snow runs continuously. In a full-screen window, 40 flakes a second is light, but turn it off on battery or when a window is fullscreen (running: !UPower.onBattery), as the video wallpaper does in Eye Candy 5: Video Wallpapers and Live Weather.
  • Masked layers (ClickRipple) render the button into a texture; that's fine for buttons, but don't wrap huge panels in one.
