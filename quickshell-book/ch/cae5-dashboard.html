cae5Caelestia 5: The Dashboard

Touch the top edge of the screen and Caelestia's dashboard drops out of the frame: a tabbed panel with your profile, a big clock, a calendar, media and system resources. It's a good model for any large panel: tabs, cards and a panel that resizes to fit.

modules/dashboard/  Content  Card  Dash  Calendar  Media  Performance

The drawer itself was set up in Caelestia 3: The Frame and the Drawer System (Panels.qml puts Dashboard.Content in a top-edge DrawerWrapper). This chapter builds what goes inside.

Module 1: Tabs and a resizing panel#

cae/modules/dashboard/Content.qmlimport QtQuick
import QtQuick.Layouts
import qs.config
import qs.services
import qs.components

// The dashboard: three tabs (Dashboard, Media, Performance) with a sliding indicator.
// The panel resizes smoothly to fit the current tab.
Item {
    id: root

    required property ScreenState screenState
    property bool shown: false
    property int current: 0
    readonly property list<Item> pages: [dash, media, performance]

    implicitWidth: Math.max(tabs.implicitWidth, pages[current].implicitWidth) + Tokens.padding.large * 2
    implicitHeight: tabs.implicitHeight + Tokens.spacing.medium + pages[current].implicitHeight + Tokens.padding.large * 2

    Behavior on implicitWidth { Anim {} }
    Behavior on implicitHeight { Anim {} }

    // poll CPU/RAM only while the dashboard is visible
    onShownChanged: SysInfo.refCount += shown ? 1 : -1

    Row {
        id: tabs

        anchors.horizontalCenter: parent.horizontalCenter
        y: Tokens.padding.large
        spacing: Tokens.spacing.small

        Repeater {
            id: tabButtons
            model: [["dashboard", "Dashboard"], ["queue_music", "Media"], ["speed", "Performance"]]

            Item {
                required property var modelData
                required property int index
                implicitWidth: tabRow.implicitWidth + Tokens.padding.large * 2
                implicitHeight: tabRow.implicitHeight + Tokens.padding.medium * 2

                Row {
                    id: tabRow
                    anchors.centerIn: parent
                    spacing: Tokens.spacing.small
                    MaterialIcon {
                        text: modelData[0]
                        fill: root.current === index ? 1 : 0
                        color: root.current === index ? Colours.palette.m3primary : Colours.palette.m3onSurfaceVariant
                    }
                    StyledText {
                        anchors.verticalCenter: parent.verticalCenter
                        text: modelData[1]
                        color: root.current === index ? Colours.palette.m3primary : Colours.palette.m3onSurfaceVariant
                    }
                }
                StateLayer {
                    radius: Tokens.rounding.full
                    onClicked: root.current = index
                }
            }
        }
    }

    // the indicator under the selected tab
    StyledRect {
        readonly property Item tab: tabButtons.count > root.current ? tabButtons.itemAt(root.current) : null
        x: tabs.x + (tab?.x ?? 0) + Tokens.padding.large
        y: tabs.y + tabs.height
        width: (tab?.width ?? 0) - Tokens.padding.large * 2
        height: 3
        radius: Tokens.rounding.full
        color: Colours.palette.m3primary

        Behavior on x { Anim { type: Anim.FastSpatial } }
        Behavior on width { Anim { type: Anim.FastSpatial } }
    }

    Item {
        anchors.top: tabs.bottom
        anchors.topMargin: Tokens.spacing.medium
        anchors.horizontalCenter: parent.horizontalCenter
        width: root.pages[root.current].implicitWidth
        height: root.pages[root.current].implicitHeight

        Dash { id: dash; visible: root.current === 0; opacity: visible ? 1 : 0; Behavior on opacity { Anim { type: Anim.Effects } } }
        Media { id: media; visible: root.current === 1; opacity: visible ? 1 : 0; Behavior on opacity { Anim { type: Anim.Effects } } }
        Performance { id: performance; visible: root.current === 2; opacity: visible ? 1 : 0; Behavior on opacity { Anim { type: Anim.Effects } } }
    }
}
Code walkthrough · piece by piece
lines 12–15State
required property ScreenState screenState
property bool shown: false
property int current: 0
readonly property list<Item> pages: [dash, media, performance]

current is the selected tab; pages lists the three page items so the panel can read the current one's size.

lines 17–21The panel fits the page
implicitWidth: Math.max(tabs.implicitWidth, pages[current].implicitWidth) + Tokens.padding.large * 2
implicitHeight: tabs.implicitHeight + Tokens.spacing.medium + pages[current].implicitHeight + Tokens.padding.large * 2

Behavior on implicitWidth { Anim {} }
Behavior on implicitHeight { Anim {} }

The panel is as large as the current page plus the tab row and padding. Both sizes have a Behavior, so switching tabs morphs the drawer, and because the frame background follows the drawer's size, the whole shape flows to the new size.

lines 23–24Only poll when visible
// poll CPU/RAM only while the dashboard is visible
onShownChanged: SysInfo.refCount += shown ? 1 : -1

SysInfo reads CPU and memory every 2 seconds, but only while someone needs it. The dashboard adds itself to refCount when shown and removes itself when hidden, so a closed dashboard costs nothing. shown comes from the wrapper's visible (set in Panels.qml).

Things worth noticing:

  • The avatar reads ~/.face (the standard profile picture path, also used by login managers) inside a round ClippingRectangle.
  • The big clock is vertical, like the bar's clock: hours, three dots, minutes, then the date.

  • The media art spins slowly while music plays, like a record, and stops where it is when paused.

Code walkthrough · piece by piece
lines 10–12The month to show
property int monthOffset: 0
readonly property date first: new Date(Time.date.getFullYear(), Time.date.getMonth() + monthOffset, 1)
readonly property int lead: (first.getDay() + 6) % 7          // Monday-first

monthOffset moves months forward and back. first is the 1st of the shown month, and lead is how many cells come before it in a Monday-first week (getDay() is 0 for Sunday, so (day + 6) % 7 makes Monday 0).

lines 38–5842 day cells
Repeater {
    model: 42

    StyledRect {
        required property int index
        readonly property date day: new Date(root.first.getFullYear(), root.first.getMonth(), index - root.lead + 1)

Six weeks × seven days always covers any month. Each cell computes its date as "first of month + index - lead"; Date handles overflow, so index -2 becomes the end of the previous month and 35 the next month's start. Days outside the month are dimmed; today gets a filled circle.

lines 61–63Scroll to change month
WheelHandler {
    onWheel: event => root.monthOffset += event.angleDelta.y > 0 ? -1 : 1
}

A wheel up goes back a month, down goes forward.

A large cover, title, artist and album, a seek slider (only enabled when the player supports seeking), controls with a big play/pause button, and a row of chips for every MPRIS player. Clicking a chip sets Players.manual, which makes that player "active" everywhere: the dashboard, the bar and the lock screen.

import QtQuick.Shapes
import qs.config

// The performance tab: four rings (CPU, memory, temperature, disk).
Row {
    spacing: Tokens.spacing.large

    Ring { value: SysInfo.cpu; icon: "memory"; label: "CPU"; text: Math.round(SysInfo.cpu * 100) + "%" }
    Ring { value: SysInfo.mem; icon: "memory_alt"; label: "Memory"; text: SysInfo.memUsedGb.toFixed(1) + " / " + Math.round(SysInfo.memTotalGb) + "G" }
    Ring { value: Math.min(1, SysInfo.temp / 100); icon: "thermostat"; label: "Temp"; text: Math.round(SysInfo.temp) + "°C" }
    Ring { value: SysInfo.disk; icon: "hard_drive"; label: "Disk"; text: Math.round(SysInfo.disk * 100) + "%" }

    component Ring: Column {
        id: ring
        property real value
        property string icon
        property string label
        property string text
        property real shown: value
        spacing: Tokens.spacing.small

        Behavior on shown { Anim { type: Anim.SlowSpatial } }

        Item {
            width: 120; height: 120
            Shape {
                anchors.fill: parent
                preferredRendererType: Shape.CurveRenderer
                ShapePath {
                    strokeColor: Colours.palette.m3surfaceContainerHighest; strokeWidth: 10; fillColor: "transparent"; capStyle: ShapePath.RoundCap
                    PathAngleArc { centerX: 60; centerY: 60; radiusX: 52; radiusY: 52; startAngle: 135; sweepAngle: 270 }
                }
                ShapePath {
                    strokeColor: ring.value > 0.85 ? Colours.palette.m3error : Colours.palette.m3primary
                    strokeWidth: 10; fillColor: "transparent"; capStyle: ShapePath.RoundCap
                    PathAngleArc { centerX: 60; centerY: 60; radiusX: 52; radiusY: 52; startAngle: 135; sweepAngle: 270 * Math.min(1, ring.shown) }
                }
            }
            MaterialIcon { anchors.centerIn: parent; text: ring.icon; font.pixelSize: 30; color: Colours.palette.m3primary }
        }
        StyledText { anchors.horizontalCenter: parent.horizontalCenter; text: ring.text; font.weight: 600 }
        StyledText { anchors.horizontalCenter: parent.horizontalCenter; text: ring.label; color: Colours.palette.m3outline }
    }
}

Four 270° rings (open at the bottom, like a speedometer). startAngle: 135 starts the arc at the bottom-left; sweepAngle: 270 * value fills it clockwise. Each ring animates through a shown property with the slow spatial curve, so the arcs glide instead of jumping every two seconds.
