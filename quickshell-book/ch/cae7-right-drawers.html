cae7Caelestia 7: Notifications, Sidebar, Session, OSD, Utilities

The right side of Caelestia's frame is busy: notification popups in the top-right corner, a notification centre below them, the session menu and the OSD sliders in the middle, and quick toggles in the bottom-right corner. All of them are drawers from Caelestia 3: The Frame and the Drawer System; this chapter fills them.

Module 1: The notification server#

cae/services/Notifs.qmlpragma Singleton
import Quickshell
import Quickshell.Services.Notifications
import QtQuick
import qs.config

// The notification server. `list` is the history (newest first); `popups` the ones still on screen.
Singleton {
    id: root

    property var list: []
    readonly property var popups: list.filter(n => n.popup)
    property bool dnd: false

    function clearAll(): void {
        for (const n of list.slice())
            n.notification.dismiss();
    }

    NotificationServer {
        keepOnReload: true
        actionsSupported: true
        bodyMarkupSupported: true
        bodyHyperlinksSupported: true
        imageSupported: true
        persistenceSupported: true

        onNotification: notif => {
            notif.tracked = true;
            const n = notifComp.createObject(root, { notification: notif, popup: !root.dnd });
            root.list = [n, ...root.list];
        }
    }

    Component {
        id: notifComp
        Notif {}
    }

    component Notif: QtObject {
        id: n

        required property Notification notification
        property bool popup: true
        readonly property date time: new Date()

        readonly property Timer timer: Timer {
            running: n.popup && n.notification.urgency !== NotificationUrgency.Critical
            interval: n.notification.expireTimeout > 0 ? n.notification.expireTimeout * 1000 : Config.notifs.defaultExpire
            onTriggered: n.popup = false
        }

        readonly property Connections conn: Connections {
            target: n.notification
            function onClosed(): void {
                root.list = root.list.filter(x => x !== n);
                n.destroy();
            }
        }
    }
}
Code walkthrough · piece by piece
lines 11–13History, popups and DND
property var list: []
readonly property var popups: list.filter(n => n.popup)
property bool dnd: false

list holds every notification since login, newest first. popups is derived from it: the ones whose popup flag is still on. Turning on Do Not Disturb (dnd) makes new notifications skip the popup stage and go straight to the history.

lines 20–26Becoming the server
NotificationServer {
    keepOnReload: true
    actionsSupported: true
    bodyMarkupSupported: true
    bodyHyperlinksSupported: true
    imageSupported: true
    persistenceSupported: true

Only one program on your system can be the notification server. Each …Supported flag tells apps what the server can show (action buttons, markup in the body, images…), so they can send richer notifications.

lines 28–32A new notification
onNotification: notif => {
    notif.tracked = true;
    const n = notifComp.createObject(root, { notification: notif, popup: !root.dnd });
    root.list = [n, ...root.list];
}

tracked = true tells Quickshell to keep the notification alive (otherwise it's dropped as soon as the handler ends). Each one is wrapped in a Notif object that adds a popup flag and a timestamp, and is put at the front of the list.

lines 40–51The wrapper and its timer
component Notif: QtObject {
    id: n

    required property Notification notification
    property bool popup: true
    readonly property date time: new Date()

    readonly property Timer timer: Timer {
        running: n.popup && n.notification.urgency !== NotificationUrgency.Critical
        interval: n.notification.expireTimeout > 0 ? n.notification.expireTimeout * 1000 : Config.notifs.defaultExpire
        onTriggered: n.popup = false
    }

Inline components can contain other objects as property values: the wrapper owns a Timer that turns popup off after the app's requested timeout (expireTimeout is in seconds, or -1 for "server default"). Critical notifications never time out.

lines 53–59Cleaning up
readonly property Connections conn: Connections {
    target: n.notification
    function onClosed(): void {
        root.list = root.list.filter(x => x !== n);
        n.destroy();
    }
}

When an app (or you) closes the notification, it emits closed; the wrapper removes itself from the list and destroys itself.

Module 2: A notification card#

cae/modules/notifications/NotificationCard.qmlimport Quickshell
import Quickshell.Widgets
import Quickshell.Services.Notifications
import QtQuick
import QtQuick.Layouts
import qs.config
import qs.services
import qs.components

// One notification: app icon or image, summary, body, actions. Click to run the default
// action; the ✕ dismisses it. Critical notifications are tinted with the error colour.
StyledRect {
    id: root

    required property var notif
    readonly property Notification n: notif.notification
    readonly property bool critical: n?.urgency === NotificationUrgency.Critical

    implicitHeight: layout.implicitHeight + Tokens.padding.medium * 2
    radius: Tokens.rounding.large
    color: critical ? Colours.palette.m3errorContainer : Colours.palette.m3surfaceContainer

    RowLayout {
        id: layout
        anchors.fill: parent
        anchors.margins: Tokens.padding.medium
        spacing: Tokens.spacing.medium

        ClippingRectangle {
            Layout.alignment: Qt.AlignTop
            implicitWidth: 42; implicitHeight: 42
            radius: Tokens.rounding.full
            color: Colours.palette.m3secondaryContainer

            Image {
                anchors.fill: parent
                visible: (root.n?.image ?? "") !== ""
                source: root.n?.image ?? ""
                fillMode: Image.PreserveAspectCrop
                sourceSize: Qt.size(84, 84)
            }
            IconImage {
                anchors.centerIn: parent
                visible: !root.n?.image
                implicitSize: 26
                source: Quickshell.iconPath(root.n?.appIcon || "dialog-information", "dialog-information")
            }
        }

        ColumnLayout {
            Layout.fillWidth: true
            spacing: 2

            RowLayout {
                StyledText {
                    Layout.fillWidth: true
                    text: root.n?.summary ?? ""
                    elide: Text.ElideRight
                    font.weight: 600
                    color: root.critical ? Colours.palette.m3onErrorContainer : Colours.palette.m3onSurface
                }
                StyledText {
                    text: Qt.formatTime(root.notif.time, "hh:mm")
                    color: Colours.palette.m3outline
                    font.pixelSize: Tokens.font.size.small
                }
                MaterialIcon {
                    text: "close"
                    font.pixelSize: Tokens.font.size.normal
                    TapHandler { onTapped: root.n.dismiss() }
                }
            }
            StyledText {
                Layout.fillWidth: true
                visible: text !== ""
                text: root.n?.body ?? ""
                textFormat: Text.StyledText
                wrapMode: Text.Wrap
                maximumLineCount: 4
                elide: Text.ElideRight
                color: root.critical ? Colours.palette.m3onErrorContainer : Colours.palette.m3onSurfaceVariant
            }
            Flow {
                Layout.fillWidth: true
                Layout.topMargin: Tokens.spacing.extraSmall
                spacing: Tokens.spacing.small
                visible: (root.n?.actions.length ?? 0) > 0

                Repeater {
                    model: root.n?.actions ?? []
                    StyledRect {
                        required property NotificationAction modelData
                        implicitWidth: label.implicitWidth + Tokens.padding.large * 2
                        implicitHeight: 30
                        radius: Tokens.rounding.full
                        color: Colours.palette.m3secondaryContainer
                        StyledText { id: label; anchors.centerIn: parent; text: parent.modelData.text; color: Colours.palette.m3onSecondaryContainer }
                        StateLayer { onClicked: parent.modelData.invoke() }
                    }
                }
            }
        }
    }

    TapHandler {
        onTapped: root.n?.actions.find(a => a.identifier === "default")?.invoke()
    }
    // hovering keeps a popup on screen
    HoverHandler {
        onHoveredChanged: root.notif.timer.running = !hovered && root.notif.popup
    }
}

The card shows the image if the notification has one (chat apps send avatars), otherwise the app icon. Critical notifications use the errorContainer colours. The body supports simple HTML (Text.StyledText) and is limited to four lines. Each action becomes a pill button; clicking the card itself runs the action named "default" (for most apps: open the conversation). The HoverHandler at the end pauses the popup timer while you're reading.

Module 5: The session menu#

cae/modules/session/Content.qmlimport Quickshell
import QtQuick
import qs.config
import qs.services
import qs.components

// The session drawer on the right edge: a column of big buttons. Arrow keys move, Enter runs.
Column {
    id: root

    required property ScreenState screenState

    readonly property var actions: [
        { icon: "logout", cmd: ["loginctl", "terminate-user", Quickshell.env("USER")] },
        { icon: "power_settings_new", cmd: ["systemctl", "poweroff"] },
        { icon: "bedtime", cmd: ["systemctl", "suspend"] },
        { icon: "restart_alt", cmd: ["systemctl", "reboot"] }
    ]
    property int current: 1

    padding: Tokens.padding.large
    spacing: Tokens.spacing.large

    // take the keyboard when the drawer opens (the window has keyboard focus while it's open)
    Connections {
        target: root.screenState
        function onSessionChanged(): void {
            if (root.screenState.session) root.forceActiveFocus();
        }
    }

    Keys.onUpPressed: current = Math.max(0, current - 1)
    Keys.onDownPressed: current = Math.min(actions.length - 1, current + 1)
    Keys.onEscapePressed: screenState.session = false
    Keys.onReturnPressed: run(current)

    function run(i: int): void {
        screenState.session = false;
        Quickshell.execDetached(actions[i].cmd);
    }

    Repeater {
        model: root.actions

        StyledRect {
            required property var modelData
            required property int index
            readonly property bool selected: root.current === index

            width: Tokens.sizes.sessionButton
            height: Tokens.sizes.sessionButton
            radius: selected ? Tokens.rounding.large : Tokens.rounding.extraLarge
            color: selected ? Colours.palette.m3secondaryContainer : Colours.palette.m3surfaceContainer

            Behavior on radius { Anim { type: Anim.FastSpatial } }

            MaterialIcon {
                anchors.centerIn: parent
                text: parent.modelData.icon
                font.pixelSize: 28
                fill: parent.selected ? 1 : 0
                color: parent.selected ? Colours.palette.m3onSecondaryContainer : Colours.palette.m3onSurface
            }
            StateLayer {
                onEntered: root.current = parent.index
                onClicked: root.run(parent.index)
            }
        }
    }
}

cae/modules/osd/Content.qmlimport Quickshell
import QtQuick
import qs.config
import qs.services
import qs.components

// Volume and brightness as two vertical sliders on the right edge. They appear when the value
// changes (keys, scripts) or when you hover the right edge, and hide after a delay.
Row {
    id: root

    required property ScreenState screenState
    required property ShellScreen screen
    property bool armed: false

    function flash(): void {
        if (!armed) return;
        screenState.osd = true;
        hide.restart();
    }

Code walkthrough · piece by piece
lines 16–20Flashing the OSD
function flash(): void {
    if (!armed) return;
    screenState.osd = true;
    hide.restart();
}

When the volume or brightness changes, the OSD opens and a hide timer restarts. Keeping the key held keeps restarting it, so the OSD stays while you adjust.

lines 25–28Startup and hover
// ignore the values services report at startup
Timer { running: true; interval: 1500; onTriggered: root.armed = true }
Timer { id: hide; interval: Config.osd.hideDelay; onTriggered: if (!hover.hovered) root.screenState.osd = false }
HoverHandler { id: hover }

At startup, PipeWire and the backlight report their initial values; armed ignores those. The hide timer doesn't close the OSD while you're hovering it, so you can grab a slider.

Connections to the two services. Any change, from your keys, a script or another app, shows the OSD.

In the original

modules/utilities/ contains cards for screen recording (with a recordings list), idle inhibition and toggles, plus the toasts system (small status messages like "Wallpaper changed"). modules/sidebar/ groups notifications by app with expandable groups and swipe-to-dismiss. modules/osd/ also shows the microphone and can be pinned open.
