g2Gallery: System Monitors and Live Stats

Live numbers about your machine: network speed, CPU, memory, temperature, GPU, disk. Most read Linux's /proc and /sys files directly with FileView, which is far cheaper than running commands.

Put the reading logic in a service

Each example is self-contained for easy testing. In your real shell, move the FileView + Timer parts into one services/SystemStats.qml singleton (Singletons and Global State) so the bar, a dashboard and desktop widgets share one reader.

Live Network Speed#

What it is. Live download and upload speed, updated every second, with automatic units (B/s, KB/s, MB/s). Hover to see the interface name and totals since boot.

Kind: bar module · Needs: nothing extra (reads /proc/net/dev)

galleryshell/bar/NetSpeed.qmlimport Quickshell
import Quickshell.Io
import QtQuick
import QtQuick.Layouts

Rectangle {
    id: root
    property real down: 0              // bytes per second
    property real up: 0
    property real totalDown: 0
    property real totalUp: 0
    property string iface: ""
    property var last: null            // previous sample { rx, tx, t }

    function fmt(bps: real): string {
        const units = ["B/s", "KB/s", "MB/s", "GB/s"]
        let i = 0
        while (bps >= 1024 && i < units.length - 1) { bps /= 1024; i++ }
        return (bps >= 100 || i === 0 ? Math.round(bps) : bps.toFixed(1)) + " " + units[i]
    }
    function fmtBytes(b: real): string {
        const u = ["B", "KB", "MB", "GB", "TB"]; let i = 0
        while (b >= 1024 && i < u.length - 1) { b /= 1024; i++ }
        return b.toFixed(1) + " " + u[i]
    }

    FileView { id: netdev; path: "/proc/net/dev" }

    Timer {
        interval: 1000; running: true; repeat: true; triggeredOnStart: true
        onTriggered: {
            netdev.reload()
            // lines look like: "  wlan0: 123456 789 0 0 0 0 0 0 654321 ..."
            let rx = 0, tx = 0, names = []
            for (const line of netdev.text().split("\n").slice(2)) {
                const m = line.trim().match(/^([^:]+):\s*(.*)$/)
                if (!m) continue
                const name = m[1]
                if (name === "lo" || name.startsWith("veth") || name.startsWith("docker") || name.startsWith("br-") || name.startsWith("virbr")) continue
                const f = m[2].split(/\s+/).map(Number)
                rx += f[0]; tx += f[8]               // field 0 = received bytes, field 8 = sent bytes
                if (f[0] > 0) names.push(name)
            }
            const now = Date.now()
            if (root.last) {
                const dt = (now - root.last.t) / 1000
                root.down = Math.max(0, (rx - root.last.rx) / dt)
                root.up = Math.max(0, (tx - root.last.tx) / dt)
            }
            root.last = { rx, tx, t: now }
            root.totalDown = rx; root.totalUp = tx
            root.iface = names.join(", ")
        }
    }

    implicitWidth: row.implicitWidth + 24
    implicitHeight: 26
    radius: height / 2
    color: "#313244"

    RowLayout {
        id: row
        anchors.centerIn: parent
        spacing: 10
        RowLayout {
            spacing: 3
            Text { text: "↓"; color: "#89b4fa"; font.pixelSize: 13; font.bold: true }
            Text { text: root.fmt(root.down); color: "#cdd6f4"; font.pixelSize: 12; font.features: ({ "tnum": 1 })
                   Layout.preferredWidth: 64 }            // fixed width: the bar doesn't jump around
        }
        RowLayout {
            spacing: 3
            Text { text: "↑"; color: "#a6e3a1"; font.pixelSize: 13; font.bold: true }
            Text { text: root.fmt(root.up); color: "#cdd6f4"; font.pixelSize: 12; font.features: ({ "tnum": 1 })
                   Layout.preferredWidth: 64 }
        }
        Text {
            visible: hover.hovered
            text: root.iface + " · ↓" + root.fmtBytes(root.totalDown) + " ↑" + root.fmtBytes(root.totalUp)
            color: "#a6adc8"; font.pixelSize: 11
        }
    }
    HoverHandler { id: hover }
}
Code walkthrough · piece by piece

The idea: the kernel keeps a running total of bytes sent and received per network interface. Read it once a second; the difference between two readings is the speed.

lines 6–13State
Rectangle {

    property real up: 0
    property real totalDown: 0
    property real totalUp: 0
    property string iface: ""
    property var last: null            // previous sample { rx, tx, t }

down/up are the current speeds in bytes per second, totalDown/totalUp the totals since boot, iface the active interface names. last remembers the previous sample (rx bytes, tx bytes, time t) so we can compute differences.

lines 15–20Human-readable speed
function fmt(bps: real): string {
    const units = ["B/s", "KB/s", "MB/s", "GB/s"]
    let i = 0
    while (bps >= 1024 && i < units.length - 1) { bps /= 1024; i++ }
    return (bps >= 100 || i === 0 ? Math.round(bps) : bps.toFixed(1)) + " " + units[i]
}

Divide by 1024 until the number is small enough, moving to the next unit each time. Numbers of 100 or more are rounded (123 KB/s); smaller ones keep one decimal (4.2 MB/s). Plain bytes are never shown with decimals.

lines 21–25Human-readable totals
function fmtBytes(b: real): string {
    const u = ["B", "KB", "MB", "GB", "TB"]; let i = 0
    while (b >= 1024 && i < u.length - 1) { b /= 1024; i++ }
    return b.toFixed(1) + " " + u[i]
}

Same loop for totals, always with one decimal.

line 27The source file
FileView { id: netdev; path: "/proc/net/dev" }

FileView reads /proc/net/dev. This "file" is generated by the kernel each time it's read, so we must reload() it to get fresh numbers.

lines 29–32Every second

    interval: 1000; running: true; repeat: true; triggeredOnStart: true
    onTriggered: {
        netdev.reload()

A repeating timer re-reads the file. triggeredOnStart takes the first sample immediately.

lines 34–43Parsing the lines
let rx = 0, tx = 0, names = []
for (const line of netdev.text().split("\n").slice(2)) {
    const m = line.trim().match(/^([^:]+):\s*(.*)$/)
    if (!m) continue
    const name = m[1]
    if (name === "lo" || name.startsWith("veth") || name.startsWith("docker") || name.startsWith("br-") || name.startsWith("virbr")) continue
    const f = m[2].split(/\s+/).map(Number)
    rx += f[0]; tx += f[8]               // field 0 = received bytes, field 8 = sent bytes
    if (f[0] > 0) names.push(name)
}

The first two lines are headers (slice(2)). Each other line is name: numbers…. The regex splits the name from the numbers. Virtual interfaces are skipped: lo (loopback, your own machine), Docker, VM bridges; otherwise local traffic would inflate the numbers. Field 0 is received bytes and field 8 sent bytes. Totals of all real interfaces are summed, so it works on Wi-Fi and Ethernet at the same time.

lines 44–50Speed = difference ÷ time
const now = Date.now()
if (root.last) {
    const dt = (now - root.last.t) / 1000
    root.down = Math.max(0, (rx - root.last.rx) / dt)
    root.up = Math.max(0, (tx - root.last.tx) / dt)
}
root.last = { rx, tx, t: now }

With a previous sample, (rx - last.rx) / dt is bytes per second. We divide by the measured elapsed time instead of assuming exactly 1 s, because timers can be a little late. Math.max(0, …) protects against counters resetting (an interface reconnecting). Then the current sample becomes the new last.

A blue arrow and the formatted speed. Layout.preferredWidth: 64 gives the number a fixed slot, so the bar doesn't shift every second as digit counts change.

CPU Usage with Sparkline#

What it is. CPU usage percentage plus a tiny live graph of the last 30 seconds.

Kind: bar module · Needs: nothing extra (reads /proc/stat)

galleryshell/bar/CpuSpark.qmlimport Quickshell.Io
import QtQuick
import QtQuick.Layouts

Rectangle {
    id: root
    property real usage: 0             // 0..1
    property var history: []           // last N samples
    property var last: null
    property int samples: 30

    FileView { id: stat; path: "/proc/stat" }
    Timer {
        interval: 1000; running: true; repeat: true; triggeredOnStart: true
        onTriggered: {
            stat.reload()
            // first line: "cpu  user nice system idle iowait irq softirq steal ..."
            const f = stat.text().split("\n")[0].trim().split(/\s+/).slice(1).map(Number)
            const idle = f[3] + f[4]
            const total = f.reduce((a, b) => a + b, 0)
            if (root.last) {
                const dTotal = total - root.last.total
                root.usage = dTotal > 0 ? 1 - (idle - root.last.idle) / dTotal : 0
                root.history = [...root.history, root.usage].slice(-root.samples)
            }
            root.last = { total, idle }
        }
    }

    implicitWidth: row.implicitWidth + 24
    implicitHeight: 26
    radius: height / 2
    color: "#313244"

    RowLayout {
        id: row
        anchors.centerIn: parent
        spacing: 8
        Text { text: "CPU"; color: "#cba6f7"; font.pixelSize: 11; font.bold: true }
        Text { text: Math.round(root.usage * 100) + "%"; color: root.usage > 0.85 ? "#f38ba8" : "#cdd6f4"
               font.pixelSize: 12; font.bold: true; font.features: ({ "tnum": 1 }); Layout.preferredWidth: 32 }
        Canvas {
            id: spark
            implicitWidth: 70; implicitHeight: 16
            onPaint: {
                const ctx = getContext("2d")
                ctx.reset()
                const h = root.history
                if (h.length < 2) return
                const step = width / (root.samples - 1)
                const x0 = width - (h.length - 1) * step
                ctx.beginPath()
                h.forEach((v, i) => { const x = x0 + i * step, y = height - v * height; i ? ctx.lineTo(x, y) : ctx.moveTo(x, y) })
                ctx.strokeStyle = "#cba6f7"; ctx.lineWidth = 1.5; ctx.lineJoin = "round"
                ctx.stroke()
                ctx.lineTo(width, height); ctx.lineTo(x0, height); ctx.closePath()
                ctx.fillStyle = "#33cba6f7"; ctx.fill()
            }
            Connections { target: root; function onHistoryChanged() { spark.requestPaint() } }
        }
    }
}

lines 20–26Usage over the last second
const total = f.reduce((a, b) => a + b, 0)

Memory Bar#

What it is. Used RAM as a bar plus "used/total" in GB; hover shows swap.

Kind: bar module · Needs: nothing extra (reads /proc/meminfo)

galleryshell/bar/MemoryBar.qmlimport Quickshell.Io
import QtQuick
import QtQuick.Layouts

Rectangle {
    id: root
    property real totalKb: 1
    property real usedKb: 0
    property real swapTotalKb: 0
    property real swapUsedKb: 0
    readonly property real ratio: usedKb / totalKb

    function field(text, key) {
        const m = text.match(new RegExp("^" + key + ":\\s+(\\d+)", "m"))
        return m ? parseInt(m[1]) : 0
    }

    FileView { id: mem; path: "/proc/meminfo" }
    Timer {
        interval: 3000; running: true; repeat: true; triggeredOnStart: true
        onTriggered: {
            mem.reload()
            const t = mem.text()
            root.totalKb = root.field(t, "MemTotal") || 1
            root.usedKb = root.totalKb - root.field(t, "MemAvailable")      // "available" counts reclaimable cache
            root.swapTotalKb = root.field(t, "SwapTotal")
            root.swapUsedKb = root.swapTotalKb - root.field(t, "SwapFree")
        }
    }

    implicitWidth: row.implicitWidth + 24
    implicitHeight: 26
    radius: height / 2
    color: "#313244"

    RowLayout {
        id: row
        anchors.centerIn: parent
        spacing: 8
        Text { text: "RAM"; color: "#94e2d5"; font.pixelSize: 11; font.bold: true }
        Rectangle {
            implicitWidth: 60; implicitHeight: 6; radius: 3; color: "#45475a"
            Rectangle {
                width: parent.width * root.ratio; height: parent.height; radius: 3
                color: root.ratio > 0.9 ? "#f38ba8" : root.ratio > 0.75 ? "#f9e2af" : "#94e2d5"
                Behavior on width { NumberAnimation { duration: 400 } }
            }
        }
        Text {
            text: hover.hovered && root.swapTotalKb > 0
                  ? "swap " + (root.swapUsedKb / 1048576).toFixed(1) + "G"
                  : (root.usedKb / 1048576).toFixed(1) + "/" + Math.round(root.totalKb / 1048576) + "G"
            color: "#cdd6f4"; font.pixelSize: 12; font.features: ({ "tnum": 1 })
        }
    }
    HoverHandler { id: hover }
}

    text: "⚡ " + (root.charging ? "+" : "−") + Math.abs(root.watts).toFixed(1) + " W"
          + (root.secs > 0 ? " · " + Math.floor(root.secs / 3600) + "h " + Math.round(root.secs % 3600 / 60) + "m" + (root.charging ? " to full" : " left") : "")
    color: Math.abs(root.watts) > 20 && !root.charging ? "#fab387" : "#cdd6f4"
    font.pixelSize: 12
    font.features: ({ "tnum": 1 })
}

Math.abs hides driver differences in the sign, and we add our own +/− based on the charging state. Time is appended only when UPower knows it (> 0). Drawing more than 20 W on battery turns the text orange: something is working hard.
