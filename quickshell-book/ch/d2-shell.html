d2Desktop Ricing 2: Shell, Prompt, Fetch and Terminal Apps

Inside the terminal: zsh with autosuggestions, syntax highlighting and fuzzy completion; a two-line starship prompt; fastfetch greeting you with a boxed system summary; and btop and cava dressed in the same colours.

zsh#

desktop/zsh/.zshrc# ~/.zshrc: a fast, good-looking zsh without a framework.
# Plugins are three git clones; the prompt is starship.

# ── History ──────────────────────────────────────────────────────────────
HISTFILE=~/.zsh_history
HISTSIZE=50000
SAVEHIST=50000
setopt share_history hist_ignore_all_dups hist_reduce_blanks inc_append_history

# ── Behaviour ────────────────────────────────────────────────────────────
setopt auto_cd                 # type a folder name to cd into it
setopt interactive_comments    # allow # comments on the command line
bindkey -e                     # emacs-style keys (Ctrl+A, Ctrl+E…)

# ── Completion ───────────────────────────────────────────────────────────
autoload -Uz compinit && compinit -C
zstyle ':completion:*' menu select                       # arrow through matches
zstyle ':completion:*' matcher-list 'm:{a-z}={A-Za-z}'   # case-insensitive
zstyle ':completion:*' list-colors "${(s.:.)LS_COLORS}"  # colours like ls

# ── Plugins (cloned once, sourced every start) ─────────────────────────────
ZPLUGINS=${XDG_DATA_HOME:-$HOME/.local/share}/zsh-plugins
plug() {
    local name=${1:t}
    [[ -d $ZPLUGINS/$name ]] || git clone --depth 1 "https://github.com/$1" "$ZPLUGINS/$name"
    source "$ZPLUGINS/$name/$2"
}
plug zsh-users/zsh-autosuggestions     zsh-autosuggestions.zsh
plug zsh-users/zsh-syntax-highlighting zsh-syntax-highlighting.zsh
plug Aloxaf/fzf-tab                     fzf-tab.plugin.zsh

# suggestions in a muted colour that fits the theme
ZSH_AUTOSUGGEST_HIGHLIGHT_STYLE='fg=#545c7e'

# ── Modern replacements (only if installed) ────────────────────────────────
if (( $+commands[eza] )); then
    alias ls='eza --icons --group-directories-first'
    alias ll='eza -l --icons --git --group-directories-first'
    alias tree='eza --tree --icons'
fi
(( $+commands[bat] ))    && alias cat='bat --style=plain --paging=never'
(( $+commands[zoxide] )) && eval "$(zoxide init zsh --cmd cd)"
(( $+commands[fzf] ))    && source <(fzf --zsh)

# fzf in the theme's colours
export FZF_DEFAULT_OPTS="--height 40% --layout reverse --border rounded \
  --color=bg+:#283457,bg:-1,spinner:#7dcfff,hl:#7aa2f7,fg:#c0caf5,header:#7aa2f7 \
  --color=info:#bb9af7,pointer:#7dcfff,marker:#9ece6a,fg+:#c0caf5,prompt:#7aa2f7,hl+:#7dcfff"

# ── Prompt ───────────────────────────────────────────────────────────────
(( $+commands[starship] )) && eval "$(starship init zsh)"

# ── Greeting: system info once per terminal ────────────────────────────────
[[ -o interactive ]] && (( $+commands[fastfetch] )) && fastfetch

History: 50,000 lines, shared between open terminals, without duplicates. Behaviour: type a folder name to enter it; Emacs-style line editing.

Completion: compinit turns on zsh's completion system (-C skips a slow security check on every start). The zstyle lines give an arrow-key menu, case-insensitive matching and coloured file names.

Plugins without a framework: Oh My Zsh is popular but slow to start. The plug function clones a plugin from GitHub the first time and sources it every time after. Three plugins do most of the visible work:

Plugin What you see
zsh-autosuggestions a faded suggestion from your history as you type; → accepts it
zsh-syntax-highlighting commands turn cyan when valid, red when not, before you press Enter
fzf-tab Tab completion in an fzf window you can type to filter

Modern tools, each only if installed: eza (ls with icons and git status), bat (cat with colours), zoxide (cd that learns your folders: cd rice jumps to ~/src/rice), fzf (Ctrl+R searches history, Ctrl+T finds files). FZF_DEFAULT_OPTS gives fzf the palette's colours and a rounded border.

Prompt and greeting: starship draws the prompt; fastfetch runs once when a terminal opens.

sudo pacman -S zsh starship fzf eza bat zoxide fastfetch
chsh -s /usr/bin/zsh

The prompt: starship#

desktop/starship/starship.toml# ~/.config/starship.toml: a two-line "pill" prompt in Tokyo Night.
#
#  ╭─ ~/src/rice  main ✓      󰅐 14:58
#  ╰─❯

"$schema" = 'https://starship.rs/config-schema.json'
add_newline = true

format = """
[╭─](fg:#414868)\
$os\
$directory\
$git_branch$git_status\
$fill\
$cmd_duration\
$python$nodejs$rust\
$time
[╰─](fg:#414868)$character"""

palette = "tokyonight"

[palettes.tokyonight]
bg = "#1a1b26"
surface = "#292e42"
blue = "#7aa2f7"
cyan = "#7dcfff"
green = "#9ece6a"
yellow = "#e0af68"
red = "#f7768e"
magenta = "#bb9af7"
muted = "#545c7e"

[os]
disabled = false
style = "fg:blue"
format = "[$symbol ]($style)"

[os.symbols]
Arch = ""
CachyOS = ""
EndeavourOS = ""
Linux = ""

[directory]
style = "bold fg:blue"
format = "[$path]($style)[$read_only]($read_only_style) "
truncation_length = 3
truncation_symbol = "…/"
read_only = " 󰌾"

[git_branch]
symbol = " "
style = "fg:magenta"
format = "[$symbol$branch]($style) "

[git_status]
style = "fg:yellow"
format = "[$all_status$ahead_behind]($style) "

[fill]
symbol = " "

[cmd_duration]
min_time = 2000
style = "fg:yellow"
format = "[󰔛 $duration]($style) "

[python]
symbol = " "
style = "fg:yellow"
format = "[$symbol$version]($style) "

[nodejs]
symbol = " "
style = "fg:green"
format = "[$symbol$version]($style) "

[rust]
symbol = " "
style = "fg:red"
format = "[$symbol$version]($style) "

[time]
disabled = false
style = "fg:muted"
format = "[󰅐 $time]($style)"
time_format = "%H:%M"

[character]
success_symbol = "[❯](bold fg:green)"
error_symbol = "[❯](bold fg:red)"

starship is one fast program that draws the prompt for any shell, configured in TOML.

  • format lays out the whole prompt: a corner glyph, the OS icon, the folder, git branch and status, then $fill pushes the rest (command duration, language versions, time) to the right edge. The second line holds the ❯.
  • palette names colours once (blue, muted…) and every module refers to them: switching palettes recolours the whole prompt.
  • Modules: directory shortens deep paths to the last three folders; git_branch and git_status show where you are; cmd_duration appears only for commands over 2 seconds; python/nodejs/rust appear only inside such projects; character turns the ❯ red after a failed command.
  • Symbols are Nerd Font glyphs. Browse them at nerdfonts.com/cheat-sheet; starship preset nerd-font-symbols -o ~/.config/starship.toml writes a full set.

Test a change with starship explain (it lists every module in the current prompt and how long it took).

fastfetch#

desktop/fastfetch/config.jsonc// ~/.config/fastfetch/config.jsonc: a boxed, coloured fetch in Tokyo Night.
// Run `fastfetch --print-logos` for logo names, or put an image path in
// "source" with "type": "kitty" to show a picture in kitty.
{
    "$schema": "https://github.com/fastfetch-cli/fastfetch/raw/dev/doc/json_schema.json",
    "logo": {
        "source": "arch_small",
        "color": { "1": "blue", "2": "cyan" },
        "padding": { "top": 1, "left": 2, "right": 3 }
    },
    "display": {
        "separator": "  ",
        "color": { "keys": "blue", "title": "magenta" },
        "key": { "width": 12 }
    },
    "modules": [
        { "type": "custom", "format": "\u001b[90m╭──────────────────────────────────────╮" },
        { "type": "title", "key": "  󰀄 user", "format": "{user-name}@{host-name}" },
        { "type": "os",       "key": "  󰌽 os" },
        { "type": "kernel",   "key": "  󰘚 kernel" },
        { "type": "wm",       "key": "  󰟀 wm" },
        { "type": "terminal", "key": "  󰆍 term" },
        { "type": "shell",    "key": "  󰣆 shell" },
        { "type": "uptime",   "key": "  󱎫 uptime" },
        { "type": "memory",   "key": "  󰍛 memory" },
        { "type": "custom", "format": "\u001b[90m╰──────────────────────────────────────╯" },
        { "type": "colors", "symbol": "circle", "paddingLeft": 2 }
    ]
}

fastfetch prints system information next to a logo. This config:

  • logo: a small Arch logo in blue and cyan with padding. Any built-in logo works (fastfetch --print-logos). For a picture, set "type": "kitty" and "source": "~/Pictures/avatar.png"; kitty draws the image (other terminals: "type": "sixel" or "chafa").
  • display: two spaces between key and value, keys in blue, all keys 12 characters wide so values line up.
  • modules: what to show and in what order. The custom lines draw a box with Unicode corners (\u001b[90m is "grey" in ANSI escape codes). Each module gets a Nerd Font icon in its key. colors prints the palette as circles at the end.

Run fastfetch -c ~/.config/fastfetch/config.jsonc to test; fastfetch --list-modules shows the 80-odd modules (GPU, battery, packages, media, weather…).

desktop/cava/config; ~/.config/cava/config: the terminal visualizer, in the theme's colours.
; (The shell's visualizer runs its own cava with its own settings: Part E.)

[general]
framerate = 60
bars = 0                 ; 0 = as many as fit the terminal
bar_width = 2
bar_spacing = 1
sleep_timer = 3          ; stop drawing after 3 s of silence

[input]
method = pipewire
source = auto

[output]
method = noncurses

[color]
; a vertical gradient from the bottom up
gradient = 1
gradient_count = 4
gradient_color_1 = '#7dcfff'
gradient_color_2 = '#7aa2f7'
gradient_color_3 = '#bb9af7'
gradient_color_4 = '#f7768e'

[smoothing]
monstercat = 1           ; smooth "hills" between bars
noise_reduction = 77

cava, the terminal audio visualizer: as many bars as fit, reading from PipeWire, with a four-colour vertical gradient and monstercat smoothing (gentle hills between bars). sleep_timer stops drawing after 3 seconds of silence.
