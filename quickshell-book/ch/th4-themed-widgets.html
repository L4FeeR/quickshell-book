th4Theming 4: Making Widgets Themeable

A theme switcher is only as good as the widgets that follow it. One hard-coded "#1e1e2e" and that widget stays dark while the rest of the shell turns light. This chapter builds four small base widgets that make following the theme automatic, gives the rules that keep a whole shell themeable, and walks through a demo bar that uses every role.

widgets/  TRect  TText  Icon  IconButton  DemoBar

The rules#

  1. Never write a colour in a widget. Write a role: Theme.colors.surface, not "#181825". (The only exception is a theme preview, which shows another theme's colours on purpose.)
  2. Pick roles by purpose, not by look. The active workspace is primary because it's the thing that's selected, not because you like purple there.
  3. Put text on its matching role: text/textMuted on background, surface and surfaceHigh; onPrimary on primary.
  4. Fade colour changes. Give coloured items a Behavior on color. Then switching themes is a smooth 400 ms crossfade instead of a flash.
  5. Derive, don't invent. Need a softer accent? Theme.alpha(Theme.colors.primary, 0.15). A hover colour? Theme.mix(Theme.colors.surface, Theme.colors.text, 0.08). These work in every theme.

Module 1: A rectangle that fades#

theming/widgets/TRect.qmlimport QtQuick

// A Rectangle whose colour changes fade, so switching themes animates instead of snapping.
Rectangle {
    color: "transparent"
    Behavior on color {
        ColorAnimation { duration: 400; easing.type: Easing.OutCubic }
    }
    Behavior on border.color {
        ColorAnimation { duration: 400; easing.type: Easing.OutCubic }
    }
}
Code walkthrough · piece by piece
lines 4–5Transparent by default
Rectangle {
    color: "transparent"

Most rectangles in a shell are containers that get a role colour; starting transparent avoids accidental white boxes.

lines 6–8Fade the fill
Behavior on color {
    ColorAnimation { duration: 400; easing.type: Easing.OutCubic }
}

Whenever color changes (a theme switch, hover, selection), animate to the new colour over 400 ms with OutCubic: fast at first, gentle at the end.

lines 9–11Fade the outline too
Behavior on border.color {
    ColorAnimation { duration: 400; easing.type: Easing.OutCubic }
}

border.color is a separate property and needs its own Behavior.

Module 2: Text that follows the theme#

theming/widgets/TText.qmlimport QtQuick
import qs.services

// Text in the theme's text colour (fading on theme changes).
Text {
    color: Theme.colors.text
    font.family: "Rubik"
    font.pixelSize: 13
    Behavior on color {
        ColorAnimation { duration: 400; easing.type: Easing.OutCubic }
    }
}

Module 3: Icons#

theming/widgets/Icon.qmlimport QtQuick

// A Material Symbols icon; `text` is the icon name.
TText {
    property real fill: 0
    font.family: "Material Symbols Rounded"
    font.pixelSize: 18
    font.variableAxes: ({ "FILL": fill })
}

An icon is just text in the Material Symbols font, so it inherits TText's colour and fade. fill uses the font's variable FILL axis: 0 for outlined, 1 for filled.

Module 4: An icon button#

theming/widgets/IconButton.qmlimport QtQuick
import qs.services

// A round button with an icon. `active` fills it with the theme's primary colour.
TRect {
    id: root

    property alias icon: label.text
    property bool active: false
    property string tooltip: ""
    signal clicked()

    implicitWidth: 30
    implicitHeight: 30
    radius: height / 2
    color: active ? Theme.colors.primary : hover.hovered ? Theme.colors.surfaceHigh : "transparent"

    Icon {
        id: label
        anchors.centerIn: parent
        fill: root.active ? 1 : 0
        color: root.active ? Theme.colors.onPrimary : Theme.colors.text
    }
    HoverHandler { id: hover; cursorShape: Qt.PointingHandCursor }
    TapHandler { onTapped: root.clicked() }
}

Module 5: A bar that shows off the theme#

theming/widgets/DemoBar.qmlimport Quickshell
import Quickshell.Wayland
import QtQuick
import QtQuick.Layouts
import qs.services

// A small bar that uses every colour role, to see a theme at work. It also holds the
// theme controls: previous/next, the light/dark twin, and the picker.
Variants {
    model: Quickshell.screens

    PanelWindow {
        id: bar
        required property ShellScreen modelData

        screen: modelData
        anchors { top: true; left: true; right: true }
        implicitHeight: 44
        color: "transparent"
        WlrLayershell.namespace: "theming-bar"

        TRect {
            anchors.fill: parent
            anchors.margins: 6
            anchors.bottomMargin: 0
            radius: 14
            color: Theme.colors.background
            border.width: 1
            border.color: Theme.colors.border

            RowLayout {
                anchors.fill: parent
                anchors.leftMargin: 8
                anchors.rightMargin: 8
                spacing: 8

                // theme name, on a primary-coloured pill
                TRect {
                    implicitWidth: nameRow.implicitWidth + 24
                    implicitHeight: 28
                    radius: 14
                    color: Theme.colors.primary
                    Row {
                        id: nameRow
                        anchors.centerIn: parent
                        spacing: 6
                        Icon { text: Theme.dark ? "dark_mode" : "light_mode"; fill: 1; color: Theme.colors.onPrimary }

                    }
                }
                TText { text: Theme.theme.family; color: Theme.colors.textMuted }

                Item { Layout.fillWidth: true }

                // the accents, on a surface "group"
                TRect {
                    implicitWidth: swatches.implicitWidth + 20
                    implicitHeight: 28
                    radius: 14
                    color: Theme.colors.surfaceHigh
                    Row {
                        id: swatches
                        anchors.centerIn: parent
                        spacing: 6
                        Repeater {
                            model: ["red", "orange", "yellow", "green", "cyan", "blue", "magenta"]
                            TRect { required property string modelData; width: 14; height: 14; radius: 7; color: Theme.colors[modelData] }
                        }
                    }
                }

                Item { Layout.fillWidth: true }

                TText {
                    text: Qt.formatTime(clock.date, "hh:mm")
                    color: Theme.colors.text
                    SystemClock { id: clock; precision: SystemClock.Minutes }
                }
                IconButton { icon: "chevron_left"; onClicked: Theme.step(-1) }
                IconButton { icon: "chevron_right"; onClicked: Theme.step(1) }
                IconButton { icon: "contrast"; onClicked: Theme.toggleVariant() }
                IconButton { icon: "palette"; active: Ui.pickerOpen; onClicked: Ui.pickerOpen = !Ui.pickerOpen }
            }
        }
    }
}

Converting an existing widget#

Taking a widget from elsewhere in the book (or from your config) and making it themeable is mechanical:

// before
Rectangle {
    color: "#313244"
    Text { text: "CPU"; color: "#cdd6f4" }
    Rectangle { width: parent.width * usage; color: usage > 0.8 ? "#f38ba8" : "#cba6f7" }
}

// after
TRect {
    color: Theme.colors.surfaceHigh
    TText { text: "CPU" }                           // text colour by default
    TRect { width: parent.width * usage; color: usage > 0.8 ? Theme.colors.error : Theme.colors.primary }
}
  1. Replace Rectangle with TRect and Text with TText.
  2. Replace each hex colour with the role that matches its purpose (the role table in Theming 1: Colours, Palettes and Roles).
  3. Search for leftovers: grep -rn '"#' widgets/ should find nothing except intentional previews.
