The Quickshell Book

A complete, beginner-first guide to building your own Linux desktop with Quickshell and QML. You start knowing nothing about Linux ricing, Qt or programming, and finish able to build any bar, panel, launcher, lock screen or widget you can imagine.

How to use this book

If you're new to everything, read Parts I → III in order, type every example, and do the Practice exercises at the end of each chapter before moving on (open the hint only when stuck, the solution only after trying). Keep qs -c playground running in a terminal while you read: Quickshell reloads on every save, so you see each change instantly.

If you know some QML, skim Part II, then start at Part IV (Quickshell concepts).

If you want to build something specific now, jump to Part VI (projects) and use the API Reference as your dictionary: every Quickshell type has a page listing every property, function, signal and enum value, how to get the object, and complete examples.

Navigation

  • Sidebar: every part, chapter and API type. Modules expand to show their types; S marks singletons, E marks enums.
  • Search (/): types, properties, functions, signals, enum values, chapter sections and glossary terms.
  • On this page (right side): headings of the current page.
  • Alt+← / Alt+→: previous / next page.
  • A–Z Index: every entry alphabetically. Cheat Sheet: one-page summary. Whole book: everything on one page, ready to print or save as PDF.

Conventions

  • Code blocks show their file path in the top-right corner. Hover a block to get a copy button.
  • inline code is something you type exactly. Keys are keys to press.
  • Callout boxes: Tip (a good idea), Note (background), Watch out (a common mistake), Danger (could break your session), Try it yourself (exercises), In the wild (how popular rices do it).
  • Links like PanelWindow go to the API reference; links like Bindings: The Heart of QML go to chapters.

About versions

The API reference is generated from the Quickshell source (version 0.3.x), so every property listed exists in that version. Types marked noctalia-qs fork only (the Quickshell.Niri and Quickshell.DWL modules) come from the noctalia-qs fork. If something doesn't exist on your system, run qs --version and check the upstream docs at quickshell.org.
