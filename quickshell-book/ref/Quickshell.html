Quickshell

Quickshell

singleton
Import
import Quickshell
Inherits
Quickshell → QtObject
How to get one
This is a singleton: exactly one exists, created by Quickshell. Use it from anywhere by its name, e.g. Quickshell.processId. Never write Quickshell { }.

Overview#

The Quickshell singleton is your handle on Quickshell itself: the list of screens, your config folder and per-shell data directories, environment variables, launching detached processes, icon lookup, reload control and version checks. You use it in almost every config.

Use it from any file: Quickshell.screens, Quickshell.env("HOME"), Quickshell.execDetached([...]).

Example: using every property and function#

~/.config/quickshell/qs-test/shell.qmlimport Quickshell
import QtQuick
import QtQuick.Layouts

FloatingWindow {
    implicitWidth: 640; implicitHeight: 720
    color: "#1e1e2e"

    component Row2: RowLayout {
        property string k; property string v
        Text { text: parent.k; color: "#a6adc8"; Layout.preferredWidth: 200 }
        Text { text: parent.v; color: "#cdd6f4"; Layout.fillWidth: true; elide: Text.ElideMiddle }
    }

    ColumnLayout {
        anchors { fill: parent; margins: 16 }
        spacing: 4
        // ---- identity ----
        Row2 { k: "processId";  v: Quickshell.processId }
        Row2 { k: "instanceId"; v: Quickshell.instanceId }
        Row2 { k: "shellId";    v: Quickshell.shellId }
        Row2 { k: "appId";      v: Quickshell.appId }
        Row2 { k: "launchTime"; v: Qt.formatDateTime(Quickshell.launchTime, "hh:mm:ss") }
        // ---- folders ----
        Row2 { k: "shellDir";  v: Quickshell.shellDir }
        Row2 { k: "dataDir";   v: Quickshell.dataDir }
        Row2 { k: "stateDir";  v: Quickshell.stateDir }
        Row2 { k: "cacheDir";  v: Quickshell.cacheDir }
        Row2 { k: "shellPath('a.png')"; v: Quickshell.shellPath("assets/a.png") }
        Row2 { k: "statePath('x.json')"; v: Quickshell.statePath("x.json") }
        Row2 { k: "workingDirectory"; v: Quickshell.workingDirectory }
        // ---- environment ----
        Row2 { k: "env('HOME')"; v: Quickshell.env("HOME") }
        Row2 { k: "env('NOPE')"; v: String(Quickshell.env("NOPE")) }      // null if unset
        // ---- screens ----
        Row2 { k: "screens"; v: Quickshell.screens.map(s => s.name).join(", ") }
        // ---- icons ----
        Row2 { k: "hasThemeIcon('firefox')"; v: Quickshell.hasThemeIcon("firefox") }
        Image { source: Quickshell.iconPath("firefox", "application-x-executable"); sourceSize: Qt.size(32, 32) }
        // ---- versions ----
        Row2 { k: "hasVersion(0, 2)"; v: Quickshell.hasVersion(0, 2) }
        Row2 { k: "hasQtVersion(6, 8)"; v: Quickshell.hasQtVersion(6, 8) }
        Row2 { k: "watchFiles"; v: Quickshell.watchFiles }

        RowLayout {
            Text { text: "[launch kitty]"; color: "#89b4fa"
                   TapHandler { onTapped: Quickshell.execDetached(["kitty"]) } }
            Text { text: "[soft reload]"; color: "#89b4fa"
                   TapHandler { onTapped: Quickshell.reload(false) } }
            Text { text: "[copy hello]"; color: "#89b4fa"
                   TapHandler { onTapped: Quickshell.clipboardText = "hello" } }
        }
    }

    Connections {
        target: Quickshell
        function onReloadCompleted() { Quickshell.inhibitReloadPopup(); console.log("reloaded") }
        function onReloadFailed(err) { console.warn("reload failed:", err) }
    }
}

Properties#

Every property also emits a <name>Changed signal; handle it with on<Name>Changed (e.g. onProcessIdChanged: …).

NameTypeAccessDescription
processIdintconstant

Quickshell's process id.

instanceIdstringconstant

A unique identifier for this Quickshell instance

shellIdstringconstant

The shell ID, used to differentiate between different shell configurations.

Defaults to a stable value derived from the config path. Can be overridden with //@ pragma ShellId <id> in the root qml file.

appIdstringconstant

The desktop application ID.

Defaults to org.quickshell. Can be overridden with //@ pragma AppId <id> in the root qml file or the QS_APP_ID environment variable.

launchTimedateconstant

The time at which this Quickshell instance was launched.

screenslist<ShellScreen>read-only

All currently connected screens.

This property updates as connected screens change.

Reusing a window on every screen

ShellRoot {
  Variants {
    // see Variants for details
    variants: Quickshell.screens
    PanelWindow {
      property var modelData
      screen: modelData
    }
  }
}

This creates an instance of your window once on every screen. As screens are added or removed your window will be created or destroyed on those screens.

A list of ShellScreen. It updates when monitors are plugged or unplugged, so Variants { model: Quickshell.screens } creates one window per monitor automatically.

shellDirstringconstant

The full path to the root directory of your shell.

The root directory is the folder containing the entrypoint to your shell, often referred to as shell.qml.

configDirstringconstant
Deprecated: Renamed to shellDir for clarity.
shellRootstringconstant
Deprecated: Renamed to shellDir for consistency.
workingDirectorystringread / write

Quickshell's working directory. Defaults to whereever quickshell was launched from.

watchFilesboolread / write

If true then the configuration will be reloaded whenever any files change. Defaults to true.

clipboardTextstringread / write

The system clipboard.

Watch out

Under wayland the clipboard will be empty unless a quickshell window is focused.

On Wayland, reading or writing the clipboard only works while a Quickshell window has keyboard focus. For background use, run wl-copy/wl-paste with Process.

dataDirstringconstant

The per-shell data directory.

Usually ~/.local/share/quickshell/by-shell/<shell-id>

Can be overridden using //@ pragma DataDir $BASE/path in the root qml file, where $BASE corresponds to $XDG_DATA_HOME (usually ~/.local/share).

stateDirstringconstant

The per-shell state directory.

Usually ~/.local/state/quickshell/by-shell/<shell-id>

Can be overridden using //@ pragma StateDir $BASE/path in the root qml file, where $BASE corresponds to $XDG_STATE_HOME (usually ~/.local/state).

cacheDirstringconstant

The per-shell cache directory.

Usually ~/.cache/quickshell/by-shell/<shell-id>

Can be overridden using //@ pragma CacheDir $BASE/path in the root qml file, where $BASE corresponds to $XDG_CACHE_HOME (usually ~/.cache).

Functions#

reload(hard: bool): void

Reload the shell.

hard - perform a hard reload. If this is false, Quickshell will attempt to reuse windows that already exist. If true windows will be recreated.

See Reloadable for more information on what can be reloaded and how.

env(variable: string): var

Returns the string value of an environment variable or null if it is not set.

Returns null if the variable isn't set, so Quickshell.env("SWAYSOCK") !== null tests for Sway.

execDetached(context: ProcessContext): void

Launch a process detached from Quickshell.

The context parameter can either be a list of command arguments or a JS object with the following fields: - command: A list containing the command and all its arguments. See Process.command. - environment: Changes to make to the process environment. See Process.environment. - clearEnvironment: Removes all variables from the environment if true. - workingDirectory: The working directory the command should run in.

This does not run command in a shell. All arguments to the command

must be in separate values in the list, e.g. ["echo", "hello"] and not ["echo hello"].

Additionally, shell scripts must be run by your shell, e.g. ["sh", "script.sh"] instead of ["script.sh"] unless the script has a shebang.

You can use ["sh", "-c", <your command>] to execute your command with

the system shell.

This function is equivalent to Process.startDetached().

Pass a list (["notify-send", "hi"]). The process isn't a child of Quickshell, so it keeps running if your shell reloads or exits. You can't read its output; use Process for that.

iconPath(icon: string): string

Returns a string usable for a Image.source for a given system icon.

Note

By default, icons are loaded from the theme selected by the qt platform theme, which means they should match with all other qt applications on your system.

If you want to use a different icon theme, you can put //@ pragma IconTheme <name> at the top of your root config file or set the QS_ICON_THEME variable to the name of your icon theme.

Three forms: iconPath(name), iconPath(name, true) (returns "" if the icon doesn't exist), iconPath(name, "fallback-name"). The theme comes from //@ pragma IconTheme.

iconPath(icon: string, check: bool): string

Setting the check parameter of iconPath to true will return an empty string if the icon does not exist, instead of an image showing a missing texture.

Three forms: iconPath(name), iconPath(name, true) (returns "" if the icon doesn't exist), iconPath(name, "fallback-name"). The theme comes from //@ pragma IconTheme.

iconPath(icon: string, fallback: string): string

Setting the fallback parameter of iconPath will attempt to load the fallback icon if the requested one could not be loaded.

Three forms: iconPath(name), iconPath(name, true) (returns "" if the icon doesn't exist), iconPath(name, "fallback-name"). The theme comes from //@ pragma IconTheme.

hasThemeIcon(icon: string): bool

Check if specified icon has an available icon in your icon theme

shellPath(path: string): string

Equivalent to ${Quickshell.configDir}/${path}

configPath(path: string): string
Deprecated: Renamed to shellPath() for clarity.
dataPath(path: string): string

Equivalent to ${Quickshell.dataDir}/${path}

statePath(path: string): string

Equivalent to ${Quickshell.stateDir}/${path}

cachePath(path: string): string

Equivalent to ${Quickshell.cacheDir}/${path}

inhibitReloadPopup(): void

When called from reloadCompleted() or reloadFailed(), prevents the default reload popup from displaying.

The popup can also be blocked by setting QS_NO_RELOAD_POPUP=1.

hasVersion(major: int, minor: int, features: list<string>): bool

Check if Quickshell's version is at least major.minor and the listed unreleased features are available. If Quickshell is newer than the given version it is assumed that all unreleased features are present. The unreleased feature list may be omitted.

You can version gate code blocks using Quickshell's preprocessor which

has the same function available.

//@ if hasVersion(0, 3, ["feature"])
...
//@ endif

You can version gate code blocks using Quickshell's preprocessor which

has the same function available.

//@ if hasVersion(6, 10)

//@ endif

Signals#

lastWindowClosed()handler: onLastWindowClosed

Sent when the last window is closed.

To make the application exit when the last window is closed run Qt.quit().

reloadCompleted()handler: onReloadCompleted

The reload sequence has completed successfully.

reloadFailed(errorString: string)handler: onReloadFailed

The reload sequence has failed.

Notes, tips and gotchas#

  • Prefer shellPath() over hard-coded paths so your config works wherever it's installed.
  • The data/state/cache dirs are per shell id (//@ pragma ShellId), so two different shells never overwrite each other's files.
  • configDir, shellRoot and configPath() are deprecated names for shellDir and shellPath().
