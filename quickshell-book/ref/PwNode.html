Quickshell.Services.Pipewire

PwNode

provided by Quickshell

A node in the pipewire connection graph.

Import
import Quickshell.Services.Pipewire
Inherits
PwNode → PwObjectIface
How to get one
You cannot create this type yourself (PwNodes cannot be created directly). Quickshell gives you instances through: Pipewire.defaultAudioSink, Pipewire.defaultAudioSource, Pipewire.nodes, Pipewire.preferredDefaultAudioSink, Pipewire.preferredDefaultAudioSource, PwLink.source, PwLink.target, PwLinkGroup.source, PwLinkGroup.target, PwNodeLinkTracker.node, PwNodePeakMonitor.node.

Overview#

One node in the PipeWire graph: a device (speakers, headphones, microphone) or an application stream (Firefox playing sound). Get them from Pipewire.nodes, Pipewire.defaultAudioSink and friends.

Example: every property#

import Quickshell.Services.Pipewire
import QtQuick

Column {
    readonly property PwNode n: Pipewire.defaultAudioSink
    PwObjectTracker { objects: [n] }
    Text { text: "id " + n?.id + " · name " + n?.name }                // name = node.name (machine id)
    Text { text: "description: " + n?.description }                    // human readable
    Text { text: "nickname: " + n?.nickname }
    Text { text: "isSink " + n?.isSink + " · isStream " + n?.isStream + " · ready " + n?.ready }
    Text { text: "type: " + PwNodeType.toString(n?.type) }
    Text { text: "volume: " + Math.round((n?.audio?.volume ?? 0) * 100) + "%  muted " + n?.audio?.muted }
    Text { text: "app: " + (n?.properties["application.name"] ?? "-") }   // any PipeWire property
    Text { text: "media.class: " + (n?.properties["media.class"] ?? "-") }
}

Properties#

Every property also emits a <name>Changed signal; handle it with on<Name>Changed (e.g. onIdChanged: …).

NameTypeAccessDescription
idintconstant

The pipewire object id of the node.

Mainly useful for debugging. You can inspect the node directly with pw-cli i <id>.

namestringconstant

The node's name, corresponding to the object's node.name property.

descriptionstringconstant

The node's description, corresponding to the object's node.description property.

May be empty. Generally more human readable than name.

nicknamestringconstant

The node's nickname, corresponding to the object's node.nickname property.

May be empty. Generally but not always more human readable than description.

isSinkboolconstant

If true, then the node accepts audio input from other nodes, if false the node outputs audio to other nodes.

isStreamboolconstant

If true then the node is likely to be a program, if false it is likely to be a hardware device.

typePwNodeTypeconstant

The type of this node. Reflects Pipewire's media.class.

propertiesobjectread-only

The property set present on the node, as an object containing key-value pairs. You can inspect this directly with pw-cli i <id>.

A few properties of note, which may or may not be present: - application.name - A suggested human readable name for the node. - application.icon-name - The name of an icon recommended to display for the node. - media.name - A description of the currently playing media. (more likely to be present than media.title and media.artist) - media.title - The title of the currently playing media. - media.artist - The artist of the currently playing media.

Watch out

This property is invalid unless the node is bound using PwObjectTracker.

All PipeWire properties as an object, e.g. application.name, application.icon-name, media.name, node.nick. Inspect them with pw-cli info <id>.

audioPwNodeAudioconstant

Extra information present only if the node sends or receives audio.

The presence or absence of this property can be used to determine if a node manages audio, regardless of if it is bound. If non null, the node is an audio node.

null for nodes without audio. Its values are only valid while the node is bound with PwObjectTracker.

readyboolread-only

True if the node is fully bound and ready to use.

The node may be used before it is fully bound, but some data

may be missing or incorrect.
