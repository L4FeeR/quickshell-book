Quickshell

Region

creatable

A composable region used as a mask.

Import
import Quickshell
Inherits
Region → QtObject
How to get one
You create this type in QML: Region { … }.
Default property
regions — children you write inside Region { } go here

Overview#

A Region describes an area of a window, used for QsWindow.mask (where clicks are accepted), HyprlandWindow.visibleMask and BackgroundEffect.blurRegion. Regions can follow an item's geometry automatically and can be nested and combined.

From the upstream documentation#

See QsWindow.mask.

Example: using every property#

import Quickshell
import QtQuick

PanelWindow {
    anchors { top: true; bottom: true; left: true; right: true }
    exclusionMode: ExclusionMode.Ignore
    color: "transparent"

    mask: Region {
        item: card                                 // follow this item (overrides x/y/width/height)
        shape: RegionShape.Rect                    // Rect (default) or Ellipse
        radius: 20                                 // rounded corners for Rect
        // per-corner overrides:
        topLeftRadius: 20; topRightRadius: 20; bottomLeftRadius: 4; bottomRightRadius: 4

        Region {                                   // child: add a circle button area
            x: 40; y: 40; width: 60; height: 60    // manual geometry
            shape: RegionShape.Ellipse
            intersection: Intersection.Combine     // Combine | Subtract | Intersect | Xor
        }
        Region {                                   // child: cut a hole out of the card
            item: hole
            intersection: Intersection.Subtract
        }
    }

    Rectangle { id: card; x: 200; y: 200; width: 400; height: 250; radius: 20; color: "#1e1e2e"
        Rectangle { id: hole; x: 150; y: 80; width: 100; height: 80; color: "transparent"; border.color: "red" } }
    Rectangle { x: 40; y: 40; width: 60; height: 60; radius: 30; color: "#cba6f7" }
}

Properties#

Every property also emits a <name>Changed signal; handle it with on<Name>Changed (e.g. onShapeChanged: …).

NameTypeAccessDescription
shapeRegionShaperead / write

Defaults to Rect.

intersectionIntersectionread / write

The way this region interacts with its parent region. Defaults to Combine.

itemItemread / write

The item that determines the geometry of the region. item overrides x, y, width and height.

xintread / write

Defaults to 0. Does nothing if item is set.

yintread / write

Defaults to 0. Does nothing if item is set.

widthintread / write

Defaults to 0. Does nothing if item is set.

heightintread / write

Defaults to 0. Does nothing if item is set.

radiusintread / write

Corner radius for rounded rectangles. Only applies when shape is Rect. Defaults to 0.

Acts as the default for topLeftRadius, topRightRadius, bottomLeftRadius, and bottomRightRadius.

topLeftRadiusintread / write

Top-left corner radius. Only applies when shape is Rect.

Defaults to radius, and may be reset by assigning undefined.

topRightRadiusintread / write

Top-right corner radius. Only applies when shape is Rect.

Defaults to radius, and may be reset by assigning undefined.

bottomLeftRadiusintread / write

Bottom-left corner radius. Only applies when shape is Rect.

Defaults to radius, and may be reset by assigning undefined.

bottomRightRadiusintread / write

Bottom-right corner radius. Only applies when shape is Rect.

Defaults to radius, and may be reset by assigning undefined.

regionslist<Region>read-only

Regions to apply on top of this region.

Regions can be nested to create a more complex region. For example this will create a square region with a cutout in the middle.

Region {
  width: 100; height: 100;

  Region {
    x: 50; y: 50;
    width: 50; height: 50;
    intersection: Intersection.Subtract
  }
}

Signals#

changed()handler: onChanged

Triggered when the region's geometry changes.

In some cases the region does not update automatically. In those cases you can emit this signal manually.

Enum values#

Enum CornerOverride — values are written Region.Value.

ValueNumberMeaning
Region.TopLeft0b1
Region.TopRight0b10
Region.BottomLeft0b100
Region.BottomRight0b1000

Notes, tips and gotchas#

  • mask: Region {} (empty) makes a window fully click-through.
  • Regions bound to items update when the item moves or resizes, including during animations.

Where this type appears#

  • BackgroundEffect.blurRegion (property)
  • HyprlandWindow.visibleMask (property)
  • QsWindow.mask (property)
