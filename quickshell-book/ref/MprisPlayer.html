Quickshell.Services.Mpris

MprisPlayer

provided by Quickshell

A media player exposed over MPRIS.

Import
import Quickshell.Services.Mpris
Inherits
MprisPlayer → QtObject
How to get one
You cannot create this type yourself (MprisPlayers can only be acquired from Mpris). Quickshell gives you instances through: Mpris.players.

Overview#

One media player. Read the current track's metadata and playback state, and control playback. Get players from Mpris.players.

From the upstream documentation#

Support for various functionality and general compliance to

the MPRIS specification varies wildly by player. Always check the associated canXyz and xyzSupported properties if available.

The TrackList and Playlist interfaces were not implemented as we could not

find any media players using them to test against.

Example: every property and function#

import Quickshell
import Quickshell.Services.Mpris
import QtQuick
import QtQuick.Controls
import QtQuick.Layouts

FloatingWindow {
    implicitWidth: 560; implicitHeight: 640
    color: "#1e1e2e"
    readonly property MprisPlayer p: Mpris.players.values[0] ?? null

    // position isn't pushed continuously: refresh it while playing
    Timer { running: p?.isPlaying ?? false; interval: 1000; repeat: true; onTriggered: p.positionChanged() }

    ColumnLayout {
        anchors { fill: parent; margins: 14 }
        visible: p !== null
        spacing: 3
        // ---- identity ----
        Text { color: "white"; text: "identity: " + p?.identity + " · desktopEntry: " + p?.desktopEntry + " · dbus: " + p?.dbusName }
        // ---- track ----
        Image { source: p?.trackArtUrl ?? ""; Layout.preferredWidth: 120; Layout.preferredHeight: 120; fillMode: Image.PreserveAspectCrop }
        Text { color: "white"; text: "title: " + (p?.trackTitle || "Unknown title") }
        Text { color: "white"; text: "artist: " + (p?.trackArtist || "Unknown artist") }
        Text { color: "white"; text: "album: " + p?.trackAlbum + " · album artist: " + p?.trackAlbumArtist }
        Text { color: "white"; text: "uniqueId: " + p?.uniqueId + " · metadata keys: " + Object.keys(p?.metadata ?? {}).join(", ") }
        // ---- position ----
        Slider {
            Layout.fillWidth: true
            enabled: (p?.canSeek ?? false) && (p?.positionSupported ?? false)
            from: 0; to: p?.lengthSupported ? p.length : 1
            value: p?.position ?? 0
            onMoved: p.position = value                     // seconds
        }
        Text { color: "white"; text: `position ${p?.position?.toFixed(1)}s / length ${p?.length?.toFixed(1)}s` }
        // ---- state ----
        Text { color: "white"; text: "state: " + MprisPlaybackState.toString(p?.playbackState) + " · isPlaying " + p?.isPlaying }
        Text { color: "white"; text: "loop: " + MprisLoopState.toString(p?.loopState) + " (supported " + p?.loopSupported + ")" }
        Text { color: "white"; text: "shuffle: " + p?.shuffle + " (supported " + p?.shuffleSupported + ")" }
        Text { color: "white"; text: `rate ${p?.rate} (min ${p?.minRate}, max ${p?.maxRate}) · fullscreen ${p?.fullscreen}` }
        Slider { from: 0; to: 1; enabled: p?.volumeSupported ?? false; value: p?.volume ?? 1; onMoved: p.volume = value }
        // ---- capabilities ----
        Text { color: "#a6adc8"; text: `canControl ${p?.canControl} canPlay ${p?.canPlay} canPause ${p?.canPause} canTogglePlaying ${p?.canTogglePlaying}` }
        Text { color: "#a6adc8"; text: `canSeek ${p?.canSeek} canGoNext ${p?.canGoNext} canGoPrevious ${p?.canGoPrevious} canQuit ${p?.canQuit} canRaise ${p?.canRaise} canSetFullscreen ${p?.canSetFullscreen}` }
        Text { color: "#a6adc8"; text: "uri schemes: " + p?.supportedUriSchemes.join(",") + " · mime: " + p?.supportedMimeTypes.length }
        // ---- controls ----
        RowLayout {
            Button { text: "⏮"; enabled: p?.canGoPrevious ?? false; onClicked: p.previous() }
            Button { text: "-10s"; onClicked: p.seek(-10) }
            Button { text: p?.isPlaying ? "⏸" : "▶"; onClicked: p.togglePlaying() }   // or play() / pause()
            Button { text: "⏹"; onClicked: p.stop() }
            Button { text: "+10s"; onClicked: p.seek(10) }
            Button { text: "⏭"; enabled: p?.canGoNext ?? false; onClicked: p.next() }
            Button { text: "raise"; enabled: p?.canRaise ?? false; onClicked: p.raise() }
            Button { text: "quit"; enabled: p?.canQuit ?? false; onClicked: p.quit() }
        }
    }
    Connections { target: p; function onTrackChanged() { console.log("new track:", p.trackTitle) } }
}

Properties#

Every property also emits a <name>Changed signal; handle it with on<Name>Changed (e.g. onCanControlChanged: …).

NameTypeAccessDescription
canControlboolread-onlyNo upstream description.
canPlayboolread-onlyNo upstream description.
canPauseboolread-onlyNo upstream description.
canTogglePlayingboolread-onlyNo upstream description.
canSeekboolread-onlyNo upstream description.
canGoNextboolread-onlyNo upstream description.
canGoPreviousboolread-onlyNo upstream description.
canQuitboolread-onlyNo upstream description.
canRaiseboolread-onlyNo upstream description.
canSetFullscreenboolread-onlyNo upstream description.
identitystringread-only

The human readable name of the media player.

desktopEntrystringread-only

The name of the desktop entry for the media player, or an empty string if not provided.

dbusNamestringconstant

The DBus service name of the player.

positionrealread / write

The current position in the playing track, as seconds, with millisecond precision, or 0 if positionSupported is false.

May only be written to if canSeek and positionSupported are true.

To avoid excessive property updates wasting CPU while position is not

actively monitored, position usually will not update reactively, unless a nonlinear change in position occurs, however reading it will always return the current position.

If you want to actively monitor the position, the simplest way it to emit the positionChanged(s) signal manually for the duration you are monitoring it, Using a FrameAnimation if you need the value to update smoothly, such as on a slider, or a Timer if not, as shown below.

FrameAnimation {
  // only emit the signal when the position is actually changing.
  running: player.playbackState == MprisPlaybackState.Playing
  // emit the positionChanged signal every frame.
  onTriggered: player.positionChanged()
}
Timer {
  // only emit the signal when the position is actually changing.
  running: player.playbackState == MprisPlaybackState.Playing
  // Make sure the position updates at least once per second.
  interval: 1000
  repeat: true
  // emit the positionChanged signal every second.
  onTriggered: player.positionChanged()
}

In seconds. Not updated continuously (for efficiency): call positionChanged() on a Timer while playing to make bindings refresh. Setting it seeks (if canSeek).

positionSupportedboolread-onlyNo upstream description.
lengthrealread-only

The length of the playing track, as seconds, with millisecond precision, or the value of position if lengthSupported is false.

lengthSupportedboolread-onlyNo upstream description.
volumerealread / write

The volume of the playing track from 0.0 to 1.0, or 1.0 if volumeSupported is false.

May only be written to if canControl and volumeSupported are true.

volumeSupportedboolread-onlyNo upstream description.
metadataobjectread-only

Metadata of the current track.

A map of common properties is available here. Do not count on any of them actually being present.

Note that the trackTitle, trackAlbum, trackAlbumArtist, trackArtist and trackArtUrl properties have extra logic to guard against bad players sending weird metadata, and should be used over grabbing the properties directly from the metadata.

uniqueIdintread-only

An opaque identifier for the current track unique within the current player.

This is NOT mpris:trackid as that is sometimes missing or nonunique

in some players.

trackTitlestringread-only

The title of the current track, or "" if none was provided.

Use player.trackTitle || "Unknown Title" to provide a message

when no title is available.

Empty string if the player didn't provide one: p.trackTitle || "Unknown title".

trackArtiststringread-only

The current track's artist, or an "" if none was provided.

Use player.trackArtist || "Unknown Artist" to provide a message

when no artist is available.

trackArtistsstringread-only

[!ERROR] deprecated in favor of trackArtist.

trackAlbumstringread-only

The current track's album, or "" if none was provided.

Use player.trackAlbum || "Unknown Album" to provide a message

when no album is available.

trackAlbumArtiststringread-only

The current track's album artist, or "" if none was provided.

Use player.trackAlbumArtist || "Unknown Album" to provide a message

when no album artist is available.

trackArtUrlstringread-only

The current track's art url, or "" if none was provided.

Can be file://, http(s):// or empty. Images load asynchronously; show a placeholder.

playbackStateMprisPlaybackStateread / write

The playback state of the media player.

  • If canPlay is false, you cannot assign the Playing state.
  • If canPause is false, you cannot assign the Paused state.
  • If canControl is false, you cannot assign the Stopped state. (or any of the others, though their repsective properties will also be false)
isPlayingboolread / write

True if playbackState == MprisPlaybackState.Playing.

Setting this property is equivalent to calling play() or pause(). You cannot set this property if canTogglePlaying is false.

loopStateMprisLoopStateread / write

The loop state of the media player, or None if loopSupported is false.

May only be written to if canControl and loopSupported are true.

loopSupportedboolread-onlyNo upstream description.
raterealread / write

The speed the song is playing at, as a multiplier.

Only values between minRate and maxRate (inclusive) may be written to the property. Additionally, It is recommended that you only write common values such as 0.25, 0.5, 1.0, 2.0 to the property, as media players are free to ignore the value, and are more likely to accept common ones.

minRaterealread-onlyNo upstream description.
maxRaterealread-onlyNo upstream description.
shuffleboolread / write

If the play queue is currently being shuffled, or false if shuffleSupported is false.

May only be written if canControl and shuffleSupported are true.

shuffleSupportedboolread-onlyNo upstream description.
fullscreenboolread / write

If the player is currently shown in fullscreen.

May only be written to if canSetFullscreen is true.

supportedUriSchemeslist<string>read-only

Uri schemes supported by openUri().

supportedMimeTypeslist<string>read-only

Mime types supported by openUri().

Functions#

raise(): void

Bring the media player to the front of the window stack.

May only be called if canRaise is true.

quit(): void

Quit the media player.

May only be called if canQuit is true.

openUri(uri: string): void

Open the given URI in the media player.

Many players will silently ignore this, especially if the uri does not match supportedUriSchemes and supportedMimeTypes.

next(): void

Play the next song.

May only be called if canGoNext is true.

previous(): void

Play the previous song, or go back to the beginning of the current one.

May only be called if canGoPrevious is true.

seek(offset: real): void

Change position by an offset.

Even if positionSupported is false and you cannot set position, this function may work.

May only be called if canSeek is true.

play(): void

Equivalent to setting playbackState to Playing.

pause(): void

Equivalent to setting playbackState to Paused.

stop(): void

Equivalent to setting playbackState to Stopped.

togglePlaying(): void

Equivalent to calling play() if not playing or pause() if playing.

May only be called if canTogglePlaying is true, which is equivalent to canPlay or canPause depending on the current playback state.

Signals#

trackChanged()handler: onTrackChanged

The track has changed.

All track information properties that were sent by the player will be updated immediately following this signal. postTrackChanged will be sent after they update.

Track information properties: uniqueId, metadata, trackTitle, trackArtist, trackAlbum, trackAlbumArtist, trackArtUrl

Some particularly poorly behaved players will update metadata

before indicating the track has changed.

Emitted when the track changes; postTrackChanged comes after all track properties are updated.

postTrackChanged()handler: onPostTrackChanged

Sent after track info related properties have been updated, following trackChanged.

It is not safe to assume all track information is up to date after

this signal is emitted. A large number of players will update track information, particularly trackArtUrl, slightly after this signal.

Where this type appears#

  • Mpris.players (property)
