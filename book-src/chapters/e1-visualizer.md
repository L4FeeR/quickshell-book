# Eye Candy 1: The Audio Visualizer

Bars that jump with the music are the most requested widget in ricing. The audio comes from **cava**, a small program that listens to PipeWire and turns the sound into a spectrum. This chapter runs cava inside the shell and draws three visualizers from its numbers: **bars**, a smooth **wave**, and a **ring** to put around album art.

## Getting the spectrum

cava usually draws bars in a terminal. With **raw output** and the **ascii** format it prints one line per frame instead, each line a list of numbers like `12;40;100;67;…`. The shell reads those lines.

@include eyecandy/services/Cava.qml

::: walk
@ 6-11 | How it works
A singleton, so every visualizer shares one cava process. It only runs while at least one widget is using it.
@ 15-21 | State
The number of bars and frames per second, whether cava is missing, the latest values (0 to 1 each), how many widgets are using it, and `idle` (all zero: nothing is playing).
@ 23-24 | Users
Widgets call `acquire()` when they appear and `release()` when they're destroyed. A visualizer on a hidden panel doesn't keep cava running.
@ 27-48 | cava's config
Generated by the shell, so the bar count and frame rate come from the properties. The important parts: input from **PipeWire** (`source = auto` follows your default output), output **raw** to standard output, **ascii** numbers from 0 to 100, separated by character 59 (`;`). `autosens` adjusts sensitivity to the volume, `monstercat` smooths the bars into hills, `noise_reduction` makes them less jittery. `sleep_timer = 1` makes cava stop printing after a second of silence.
@ 50-54 | Running it
Only while used. The script checks that cava exists (exit code 127 if not), writes the config to a file in the runtime folder (the text passed as an argument, never pasted into the command), and replaces itself with cava.
@ 55-63 | One line, one frame
`SplitParser` calls `onRead` for every line cava prints. Split at `;`, convert each number, scale 0–100 to 0–1, and publish the new array. At 60 frames a second, this is the only work per frame.
@ 65-71 | When it stops
Exit code 127 means cava isn't installed: remember that and don't retry. In any case, drop the bars to zero.
:::

> [!NOTE] A built-in alternative
> Some Quickshell builds (the noctalia fork) have a `PwAudioSpectrum` type that computes the spectrum inside Quickshell. Upstream Quickshell 0.3 doesn't, so cava is the portable choice; lyne-dots and Caelestia use it too.

## Bars

@include eyecandy/widgets/VisualizerBars.qml

::: walk
@ 11-16 | Options
Mirrored bars grow both ways from the middle (a waveform look). Two colours make a gradient across the bars. Silent bars stay as small dots (`minHeight`), so the widget never disappears.
@ 18-19 | Using the service
Start cava when the widget appears, stop it when it goes.
@ 21-26 | One bar per value
Each bar reads its value by index. Widths share the available space minus the gaps.
@ 28-32 | Size and place
Height follows the value. Normal bars stand on the bottom edge; mirrored bars are centred. Full rounding makes each bar a capsule.
@ 33-36 | Colour and smoothing
`Qt.tint` blends the two colours by the bar's position: blue on the left, purple on the right. cava already smooths; a 50 ms animation hides the remaining frame steps.
:::

## A smooth wave

@include eyecandy/widgets/VisualizerWave.qml

::: walk
@ 18-23 | Points
One point per value: spread across the width, higher for louder (90% of the height at most).
@ 27-37 | A smooth path
An SVG path string: start at the bottom left, rise to the first point, then a **cubic curve** to each next point. The trick for smoothness: both control points sit at the horizontal midpoint between two points, at the heights of each end. Curves then meet with matching slopes, so the line flows instead of zig-zagging. Finally down to the bottom right and close.
@ 39-47 | Drawing it
A `Shape` with one `ShapePath` that draws the SVG path: a 2 px line and a translucent fill below it. The path is rebuilt every frame; Qt's curve renderer handles that easily for 32 points.
:::

## A ring

@include eyecandy/widgets/VisualizerRing.qml

::: walk
@ 10-14 | Geometry
`radius` is the inner circle where bars start (leave room for the cover); `maxLength` is how far they can reach, up to the item's edge.
@ 16 | Twice the bars
cava's bars go once around half the circle and mirrored around the other half, so the ring is symmetric: bass at the top and bottom meets nicely instead of a jump from loud to quiet at one point.
@ 23-32 | One rotated item per bar
Each bar sits on an item placed at the centre and **rotated** to its angle. Rotating the item rotates everything on it, so there's no trigonometry.
@ 34-41 | The bar
Placed just above the centre, from the inner radius outward (`y` is negative: up), with its length from the value. Because its parent is rotated, "up" is a different direction for each bar.
:::

Put a cover in the middle with a round clip ([[ch:e3-now-playing]] and [[ch:e4-music-rice]] do):

```qml
Item {
    width: 380; height: 380
    VisualizerRing { anchors.fill: parent; radius: 120 }
    ClippingRectangle {                     // Quickshell.Widgets: clips to the round shape
        anchors.centerIn: parent; width: 220; height: 220; radius: 110
        Image { anchors.fill: parent; source: Player.artUrl; fillMode: Image.PreserveAspectCrop }
    }
}
```

## Performance

Visualizers redraw up to 60 times a second, so a few habits matter:

- **Run cava only while visible**: the `acquire`/`release` pattern. Put visualizers on panels that unload when closed (`LazyLoader`), and they stop by themselves.
- **Fewer bars** in small places: 32 is plenty for a bar, 64 at most for a big desktop widget.
- **Lower the frame rate** on laptops: `Cava.framerate = 30` halves the work and still looks fluid.
- cava's `sleep_timer` already stops the frames during silence.

::: exercise warm | In your bar
Put a 60 × 18 `VisualizerBars { mirrored: true }` in your bar, next to the clock.
:::

::: exercise practice | Peak dots
Add a small dot above each bar that jumps to the bar's top and then falls slowly, like a classic hi-fi display.
--- hint
Give each bar a `property real peak`; when `value` is higher, set `peak = value`; a `Timer` every 50 ms lowers it by 0.02.
:::

Detect bass hits (the average of the first four bars jumping above 0.8) and briefly flash your bar's border in the accent.
:::
