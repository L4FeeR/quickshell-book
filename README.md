# The Quickshell Book

A complete, beginner-first guide to building your own Linux desktop shell with [Quickshell](https://quickshell.org) and QML: from your first property to a full rice (bar, launcher, notifications, lock screen, overview, dock and more).

- **Read it:** open [`quickshell-book/index.html`](quickshell-book/index.html) in a browser (works offline).
- **Contents:** 79 chapters, a reference page for each of Quickshell's 157 types (every property, function, signal and enum, with examples), 19 build-along projects, a glossary and an A–Z index.
- **Sources and rebuilding:** see [`book-src/README.md`](book-src/README.md).

`quickshell-guide.html` is an earlier single-page version.
